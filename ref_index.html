平衡常數的定義與表示法

⚖️ 化學平衡基本概念

可逆反應：化學反應中，正反應與逆反應同時進行，稱為可逆反應。

平衡狀態：在封閉系統中，當正反應速率等於逆反應速率，各物質濃度不再隨時間改變，稱為達到化學平衡。

$\text{aA} + \text{bB} \rightleftharpoons \text{cC} + \text{dD}$

平衡常數（Equilibrium Constant）：

$$K_c = \underbrace{\frac{k_f}{k_r}}_{\text{定義}} = \underbrace{\frac{[\text{C}]^c[\text{D}]^d}{[\text{A}]^a[\text{B}]^b}}_{\text{表示法}}$$

Guldberg 和 Waage（1864）：提出質量作用定律（Law of Mass Action），用以描述化學平衡時各物質間的定量關係。

化學平衡的定義與特性

🔁 可逆反應與平衡

1. 可逆反應：化學反應中，正反應（→）與逆反應（←）同時進行的反應，以 $\rightleftharpoons$ 表示。

2. 平衡狀態：在封閉系統中，正反應速率 $R_f$ 等於逆反應速率 $R_r$，各物質濃度不再隨時間改變：

$R_f = R_r$（正逆反應速率相等）

3. 化學平衡式：若可逆反應達到正逆反應速率相等時，即為化學平衡式。速率比值 $R_f/R_r$ 為常數，在一定溫度下不變。

4. 平衡是動態平衡（Dynamic Equilibrium）：外觀靜止，實際上正逆反應持續進行，只是速率相同，淨變化為零。

📋 平衡狀態的特性

特性 1 ─ 動態性
平衡是動態平衡，正逆反應同時不斷進行；各物質濃度雖不變，但微觀上仍有反應發生。
特性 2 ─ 可達性
可逆反應在封閉系統中，無論從正方向或逆方向開始，只要條件（溫度等）相同，最終均可達到相同的平衡態。
特性 3 ─ 恆定性
平衡時各物質濃度（或壓力）保持不變，溫度一定時平衡常數 $K$ 為定值。
特性 4 ─ 可逆性
改變條件（溫度、濃度、壓力）可使平衡移動，在新條件下達到新的平衡。

達到平衡的判斷：當各物質濃度、壓力不再隨時間改變；或正逆反應速率相等時，即達到平衡。

濃度平衡常數 $K_c$ 的表示法

質量作用定律（Law of Mass Action）

$\text{a}\text{A} + \text{b}\text{B} \rightleftharpoons \text{c}\text{C} + \text{d}\text{D}$
→
$K_c = \dfrac{[\text{C}]^c[\text{D}]^d}{[\text{A}]^a[\text{B}]^b}$

📌 書寫規則

分子生成物濃度乘積（各自的係數次方）

分母反應物濃度乘積（各自的係數次方）

注意：固體（s）和純液體（l）的濃度視為常數，不寫入 $K_c$ 表示式。

單位：$K_c$ 以 mol/L（M） 為濃度單位。

📐 典型範例

1 均相氣體反應：
$\text{N}_2(\text{g}) + 3\text{H}_2(\text{g}) \rightleftharpoons 2\text{NH}_3(\text{g})$
$K_c = \dfrac{[\text{NH}_3]^2}{[\text{N}_2][\text{H}_2]^3}$
2 異相平衡（含固體）：
$\text{CaCO}_3(\text{s}) \rightleftharpoons \text{CaO}(\text{s}) + \text{CO}_2(\text{g})$
$K_c = [\text{CO}_2]$

（固體不計入）

⚠️ 重要注意事項

$K_c$ 的值只與溫度有關：

  • 溫度不變 → $K_c$ 不變
  • 改變濃度、壓力 → $K_c$ 不變
  • 加入催化劑 → $K_c$ 不變
  • 改變溫度 → $K_c$ 改變

書寫方向影響 $K_c$ 值：

若正反應 $K_c = K$，則逆反應 $K_c' = \dfrac{1}{K}$

反應係數乘以 $n$：

若係數全乘以 $n$，則新的 $K_c' = (K_c)^n$

📐 書寫方向影響 $K_c$ 值的導證

以同一個可逆反應，分別寫出正方向（A+B→C+D）與逆方向（C+D→A+B）的平衡常數表示式，並觀察兩者關係。

① 正方向反應
$$\text{A} + \text{B} \rightleftharpoons \text{C} + \text{D}$$
依質量作用定律：
$$K_{\text{正}} = \frac{[\text{C}][\text{D}]}{[\text{A}][\text{B}]}$$
② 逆方向反應
$$\text{C} + \text{D} \rightleftharpoons \text{A} + \text{B}$$
依質量作用定律：
$$K_{\text{逆}} = \frac{[\text{A}][\text{B}]}{[\text{C}][\text{D}]}$$
🔗 兩者關係推導：
$$K_{\text{正}} \times K_{\text{逆}} = \frac{[\text{C}][\text{D}]}{[\text{A}][\text{B}]} \times \frac{[\text{A}][\text{B}]}{[\text{C}][\text{D}]} = 1$$
$$\therefore K_{\text{逆}} = \frac{1}{K_{\text{正}}}$$

💡 結論：同一反應，逆方向的 $K_c$ 為正方向 $K_c$ 的倒數。

📐 反應係數乘以 $n$ 影響 $K_c$ 值的導證

以同一個可逆反應，對原始反應的係數全部乘以 $n$，觀察 $K_c$ 的變化。

① 原始反應
$$a\text{A} + b\text{B} \rightleftharpoons c\text{C} + d\text{D}$$
平衡常數：
$$K_c = \frac{[\text{C}]^c[\text{D}]^d}{[\text{A}]^a[\text{B}]^b}$$
② 係數全乘以 $n$
$$na\text{A} + nb\text{B} \rightleftharpoons nc\text{C} + nd\text{D}$$
新的平衡常數：
$$K_c' = \frac{[\text{C}]^{nc}[\text{D}]^{nd}}{[\text{A}]^{na}[\text{B}]^{nb}}$$
🔗 兩者關係推導：
$$K_c' = \frac{[\text{C}]^{nc}[\text{D}]^{nd}}{[\text{A}]^{na}[\text{B}]^{nb}} = \left(\frac{[\text{C}]^c[\text{D}]^d}{[\text{A}]^a[\text{B}]^b}\right)^n = (K_c)^n$$
$$\therefore K_c' = (K_c)^n$$

💡 結論：係數全乘以 $n$，新的 $K_c$ 為原來的 $n$ 次方。

壓力平衡常數 $K_p$ 的表示法

氣體反應的壓力表示法

對於氣相反應，可用各氣體的分壓（atm）來表示平衡常數，稱為 $K_p$：

$\text{a}\text{A}(\text{g}) + \text{b}\text{B}(\text{g}) \rightleftharpoons \text{c}\text{C}(\text{g}) + \text{d}\text{D}(\text{g})$
$K_p = \dfrac{P_C^c \cdot P_D^d}{P_A^a \cdot P_B^b}$

$K_p$ 與 $K_c$ 的關係：

$K_p = K_c \cdot (RT)^{\Delta n}$

其中：

  • $R = 0.082$ L·atm/(mol·K)
  • $T$：絕對溫度（K）
  • $\Delta n = (c+d) - (a+b)$（氣態產物 − 反應物係數差）

當 $\Delta n = 0$ 時：$K_p = K_c$（兩者相等，如 $2\text{HI} \rightleftharpoons \text{H}_2 + \text{I}_2$）

🔢 $K_p$ ↔ $K_c$ 換算範例

例題：在 727°C（= 1000 K）時，$\text{N}_2(\text{g}) + 3\text{H}_2(\text{g}) \rightleftharpoons 2\text{NH}_3(\text{g})$

已知 $K_c = 6.0 \times 10^{-2}$，求 $K_p$。

1 計算 $\Delta n$：

$\Delta n = 2 - (1+3) = 2 - 4 = -2$

2 代入公式：
$K_p = K_c \cdot (RT)^{\Delta n}$
$= 6.0 \times 10^{-2} \times (0.082 \times 1000)^{-2}$
$= 6.0 \times 10^{-2} \times (82)^{-2}$
$= 6.0 \times 10^{-2} \times \dfrac{1}{6724}$
3 結果：
$K_p \approx 8.9 \times 10^{-6}$ atm$^{-2}$

$K_p$ 的特性：同樣只與溫度有關，固體和純液體不計入 $K_p$（分壓視為常數不列入）。

📐 $K_p = K_c \cdot (RT)^{\Delta n}$ 的導證

從理想氣體定律出發，逐步推導 $K_p$ 與 $K_c$ 之間的關係式。

1 由理想氣體建立關係
$PV = nRT \Rightarrow [X] = n/V$ 為莫耳濃度
$\displaystyle P_X = \frac{n}{V} \cdot RT = [X] \cdot RT$
2 寫出 $K_p$ 的定義式
$\displaystyle K_p = \frac{P_C^{\,c} \cdot P_D^{\,d}}{P_A^{\,a} \cdot P_B^{\,b}}$
3 代入 $P_X = [X] \cdot RT$
$\displaystyle K_p = \frac{([\text{C}]\!\cdot\! RT)^c \cdot ([\text{D}]\!\cdot\! RT)^d}{([\text{A}]\!\cdot\! RT)^a \cdot ([\text{B}]\!\cdot\! RT)^b}$
4 分離濃度項與 $(RT)$ 項
$\displaystyle K_p = \underbrace{\frac{[\text{C}]^c [\text{D}]^d}{[\text{A}]^a [\text{B}]^b}}_{=\,K_c} \times \underbrace{(RT)^{c+d-(a+b)}}_{=(RT)^{\Delta n}}$
5 定義 $\Delta n$
$\Delta n =$ 氣態產物係數和 − 反應物係數和
$\displaystyle \Delta n = (c+d) - (a+b)$
$\displaystyle \therefore\quad K_p = K_c \cdot (RT)^{\Delta n}$
$\Delta n > 0$
$K_p > K_c$
$\Delta n = 0$
$K_p = K_c$
$\Delta n < 0$
$K_p < K_c$

💡 固體與純液體的分壓視為常數，不列入 $K_p$。

方程式相加減與平衡常數的關係

四、當兩個反應式相加（或相減），得第三反應式，則第三反應式之平衡常數為該兩反應式平衡常數之積（或商）。

例：
$(1) \quad 2\text{O}_{2(g)} + 4\text{NO}_{(g)} \rightleftharpoons 4\text{NO}_{2(g)}$
之平衡常數為 $\displaystyle K_1 = \frac{[\text{NO}_2]^4}{[\text{O}_2]^2[\text{NO}]^4}$
$(2) \quad 4\text{NO}_{(g)} + 2\text{Cl}_{2(g)} \rightleftharpoons 4\text{NOCl}_{(g)}$
之平衡常數為 $\displaystyle K_2 = \frac{[\text{NOCl}]^4}{[\text{NO}]^4[\text{Cl}_2]^2}$
則 $\quad 4\text{NO}_{2(g)} + 2\text{Cl}_{2(g)} \rightleftharpoons 4\text{NOCl}_{(g)} + 2\text{O}_{2(g)}$
之平衡常數為 $K_3 = ?$
解析：
將方程式 -(1) + (2) 或 (2) - (1)，可得第三反應式：
$\color{#f87171}{4\text{NO}_{2(g)}} + \color{#60a5fa}{\cancel{4\text{NO}_{(g)}} + 2\text{Cl}_{2(g)}} \rightleftharpoons \color{#f87171}{2\text{O}_{2(g)} + \cancel{4\text{NO}_{(g)}}} + \color{#60a5fa}{4\text{NOCl}_{(g)}}$
（紅色部分來自逆反應 1，藍色部分來自反應 2）
由 $\text{反應式}(3) = \text{反應式}(2) - \text{反應式}(1)$，可得平衡常數關係為：
$\displaystyle K_3 = \frac{\color{#f87171}{[\text{O}_2]^2} \color{#60a5fa}{[\text{NOCl}]^4} \color{#f87171}{\cancel{[\text{NO}]^4}}}{\color{#f87171}{[\text{NO}_2]^4} \color{#60a5fa}{[\text{Cl}_2]^2} \color{#60a5fa}{\cancel{[\text{NO}]^4}}} = \color{#60a5fa}{K_2} \times \color{#f87171}{\frac{1}{K_1}}$

均相平衡與異相平衡

🧪 均相平衡（Homogeneous Equilibrium）

反應體系中所有物種同相（全為氣態，或全溶於同一溶劑），$K_c$ 中需寫入所有物種。

例1
$\text{N}_2(\text{g}) + 3\text{H}_2(\text{g}) \rightleftharpoons 2\text{NH}_3(\text{g})$
$K_c = \dfrac{[\text{NH}_3]^2}{[\text{N}_2][\text{H}_2]^3}$
例2
$2\text{SO}_2(\text{g}) + \text{O}_2(\text{g}) \rightleftharpoons 2\text{SO}_3(\text{g})$
$K_c = \dfrac{[\text{SO}_3]^2}{[\text{SO}_2]^2[\text{O}_2]}$
例3
$\text{H}_2(\text{g}) + \text{I}_2(\text{g}) \rightleftharpoons 2\text{HI}(\text{g})$
$K_c = \dfrac{[\text{HI}]^2}{[\text{H}_2][\text{I}_2]}$
例4
$\text{CH}_3\text{COOH}_{(l)} + \text{CH}_3\text{OH}_{(l)} \rightleftharpoons {\text{CH}_3\text{COOCH}_3}_{(l)} + \text{H}_2\text{O}_{(l)}$
$K_c = \dfrac{[\text{CH}_3\text{COOCH}_3][\text{H}_2\text{O}]}{[\text{CH}_3\text{COOH}][\text{CH}_3\text{OH}]}$
*此為酯化反應特殊例子，水為生成物且不為溶劑時，需列入 $K_c$ 表示式。

🧪 異相平衡（Heterogeneous Equilibrium）

反應體系中含有不同相的物種（固態、液態、氣態）。純固體（s）和純液體（l）的濃度視為常數，不列入 $K_c$。

例1
$\text{CaCO}_3(\text{s}) \rightleftharpoons \text{CaO}(\text{s}) + \text{CO}_2(\text{g})$
（CaCO₃ 和 CaO 均為固體，不計入）
$K_c = [\text{CO}_2]$
例2
$\text{C}(\text{s}) + \text{H}_2\text{O}(\text{g}) \rightleftharpoons \text{CO}(\text{g}) + \text{H}_2(\text{g})$
$K_c = \dfrac{[\text{CO}][\text{H}_2]}{[\text{H}_2\text{O}]}$
例3
$\text{Zn}(\text{s}) + 2\text{HCl}(\text{aq}) \rightleftharpoons \text{ZnCl}_2(\text{aq}) + \text{H}_2(\text{g})$
$K_c = \dfrac{[\text{ZnCl}_2][\text{H}_2]}{[\text{HCl}]^2}$

常見誤區：水（H₂O）作為溶劑時（稀溶液中），其濃度近似常數，不列入 $K_c$；但作為氣態反應物/產物時，需列入。

平衡常數、濃度(壓力)與解離度的關係

1. 分解率（解離度 $\alpha$）
$\displaystyle \alpha = \frac{\text{分解莫耳數}}{\text{原有莫耳數}} \times 100\%$
📝 範例推導
$\text{A}_{(g)} \rightleftharpoons \text{B}_{(g)} + \text{C}_{(g)}$，若達平衡時分解率為 $\alpha$，總壓為 $P$，試用 $\alpha$ 表示莫耳分率、平均分子量、分壓及 $K_p$、$K_c$。
一、建立 ICE 表（莫耳數）
莫耳數 $\text{A}_{(g)}$ $\rightleftharpoons$ $\text{B}_{(g)}$ $+$ $\text{C}_{(g)}$
初 $1$$0$$0$
中 $-\alpha$$+\alpha$$+\alpha$
平 $1-\alpha$$\alpha$$\alpha$
平衡總莫耳數 $= \mathbf{1+\alpha}$
二、各成分莫耳分率 ($X$)
  • $X_A = \dfrac{1-\alpha}{1+\alpha}$
  • $X_B = \dfrac{\alpha}{1+\alpha}$
  • $X_C = \dfrac{\alpha}{1+\alpha}$
三、各成分分壓 ($P_i$)
  • $P_A = P \cdot \dfrac{1-\alpha}{1+\alpha}$
  • $P_B = P \cdot \dfrac{\alpha}{1+\alpha}$
  • $P_C = P \cdot \dfrac{\alpha}{1+\alpha}$
四、平衡常數 $K_p$ 與 $K_c$
由分壓計算 $K_p$：
$\displaystyle K_p = \frac{P_B \cdot P_C}{P_A} = \frac{\left(\frac{\alpha}{1+\alpha}P\right)^2}{\frac{1-\alpha}{1+\alpha}P} = \frac{\alpha^2}{1-\alpha^2} P$
反應 $\Delta n = 1$，故 $K_p = K_c(RT)^1$：
$\displaystyle K_c = K_p (RT)^{-1} = \frac{\alpha^2 P}{(1-\alpha^2)RT}$
五、平均分子量 ($\overline{M}$)
A 分解成 B 和 C $\Rightarrow M_A = M_B + M_C$
$\displaystyle \overline{M} = M_A X_A + M_B X_B + M_C X_C$
$\displaystyle \overline{M} = \frac{M_A(1-\alpha) + (M_B+M_C)\alpha}{1+\alpha}$
$\displaystyle \overline{M} = \frac{M_A - M_A\alpha + M_A\alpha}{1+\alpha} = \frac{M_A}{1+\alpha}$

$K_c$ 大小的意義與反應趨勢

$K_c \gg 1$

平衡偏向正方向（生成物）；生成物濃度遠大於反應物

$K_c \approx 1$

平衡時反應物與生成物濃度相近；正逆方向程度相當

$K_c \ll 1$

平衡偏向逆方向（反應物）；反應物濃度遠大於生成物

📊 反應商 Q 與平衡的關係

反應商（Reaction Quotient）$Q_c$：在任意時刻，用與 $K_c$ 相同的表示式計算得到的值。
$Q_c < K_c$ 反應物濃度相對偏高，正反應自發進行（反應向右移動）
$Q_c = K_c$ 系統已達平衡狀態，無淨反應方向
$Q_c > K_c$ 生成物濃度相對偏高，逆反應自發進行（反應向左移動）
記憶要訣：利用 $Q_c$ 判斷方向，$Q$ 比 $K$ 小代表還沒到終點（向右走）。

六、平衡常數 K 值愈大，則反應愈接近完全（幾乎都變成產物，反應物剩下極少），但無法表示反應速率的快慢。

→ 遇此類問題時，作法都是先沉澱（完全反應），
  再解離（考慮平衡常數）

💡 範例詳解

答案：(B)(D)(E)

分析：

先由理想氣體方程式計算，若要維持 $190\text{ mmHg}$ 的平衡壓力，需要多少莫耳的 $\text{CO}_2$：

$PV = nRT$
$\Rightarrow \left(\dfrac{190}{760}\text{ atm}\right) \times 8.8\text{ L} = n_{\text{CO}_2} \times 0.082 \times (273 + 800)\text{ K}$
$\Rightarrow 0.25 \times 8.8 = n_{\text{CO}_2} \times 0.082 \times 1073$
$\Rightarrow 2.2 \approx n_{\text{CO}_2} \times 88$
$\Rightarrow n_{\text{CO}_2} = 0.025\text{ mol}$

欲達平衡，系統中必須有 $0.025\text{ mol}$ 的 $\text{CO}_2$，且固體（$\text{CaCO}_3$ 和 $\text{CaO}$）必須同時存在。我們先將各選項換算為初始莫耳數（式量：$\text{CaCO}_3=100$，$\text{CO}_2=44$，$\text{CaO}=56$）：

(A) $\text{CaCO}_3: \dfrac{1}{100}=0.01\text{ mol}$，$\text{CO}_2: \dfrac{0.44}{44}=0.01\text{ mol}$
$\text{CaCO}_{3(\text{s})}$ $\rightleftharpoons$ $\text{CaO}_{(\text{s})}$ + $\text{CO}_{2(\text{g})}$
初： $0.01$ $0$ $0.01$

說明：即使 $\text{CaCO}_3$ 全部分解，$\text{CO}_2$ 最多只能產生 $0.01 + 0.01 = 0.02\text{ mol} < 0.025\text{ mol}$，無法達到平衡所需的 $0.025\text{ mol}$ $\text{CO}_2$ 壓力。因此無法達平衡。

(B) $\text{CO}_2: \dfrac{4.4}{44}=0.1\text{ mol}$，$\text{CaO}: \dfrac{5.6}{56}=0.1\text{ mol}$
$\text{CaCO}_{3(\text{s})}$ $\rightleftharpoons$ $\text{CaO}_{(\text{s})}$ + $\text{CO}_{2(\text{g})}$
初： $0$ $0.1$ $0.1$
反應： $+0.075$ $-0.075$ $-0.075$
當量： $0.075$ $0.025$ $0.025$

說明：$\text{CO}_2$ 超過 $0.025\text{ mol}$，反應向左進行。消耗 $0.1 - 0.025 = 0.075\text{ mol}$ 的 $\text{CO}_2$ 與 $\text{CaO}$。此時 $\text{CaO}$ 剩下 $0.1 - 0.075 = 0.025\text{ mol}$，並生成 $0.075\text{ mol}$ 的 $\text{CaCO}_3$。三者皆存在，可達平衡。

(C) $\text{CO}_2: \dfrac{4.4}{44}=0.1\text{ mol}$，$\text{CaO}: \dfrac{0.56}{56}=0.01\text{ mol}$
$\text{CaCO}_{3(\text{s})}$ $\rightleftharpoons$ $\text{CaO}_{(\text{s})}$ + $\text{CO}_{2(\text{g})}$
初： $0$ $0.01$ $0.1$

說明：反應向左進行，但 $\text{CaO}$ 只有 $0.01\text{ mol}$，即使 $\text{CaO}$ 全部用完，也只能消耗 $0.01\text{ mol}$ 的 $\text{CO}_2$，$\text{CO}_2$ 仍剩下 $0.09\text{ mol} > 0.025\text{ mol}$。無法消耗足夠的 $\text{CO}_2$ 至平衡值，無法達平衡。

(D) $\text{CaCO}_3: \dfrac{3}{100}=0.03\text{ mol}$
$\text{CaCO}_{3(\text{s})}$ $\rightleftharpoons$ $\text{CaO}_{(\text{s})}$ + $\text{CO}_{2(\text{g})}$
初： $0.03$ $0$ $0$
反應： $-0.025$ $+0.025$ $+0.025$
當量： $0.005$ $0.025$ $0.025$

說明：反應向右進行，分解產生 $0.025\text{ mol}$ 的 $\text{CO}_2$ 時，需消耗 $0.025\text{ mol}$ 的 $\text{CaCO}_3$。由於初莫耳數 $0.03 > 0.025$，$\text{CaCO}_3$ 不會耗盡（還剩 $0.005\text{ mol}$），三者皆存在，可達平衡。

(E) $\text{CaCO}_3: 0.03\text{ mol}$，$\text{CaO}: 0.1\text{ mol}$
$\text{CaCO}_{3(\text{s})}$ $\rightleftharpoons$ $\text{CaO}_{(\text{s})}$ + $\text{CO}_{2(\text{g})}$
初： $0.03$ $0.1$ $0$
反應： $-0.025$ $+0.025$ $+0.025$
當量： $0.005$ $0.125$ $0.025$

說明：反應向右進行，同 (D) $\text{CaCO}_3$ 不會耗盡，且原本就有 $\text{CaO}$，反應後 $\text{CaO}$ 會變得更多。三者皆存在，可達平衡。

💡 範例詳解

答案：(C)

分析：

第一階段（求平衡常數 $K_c$）：

$\text{CO}_{(\text{g})}$ + $\text{H}_2\text{O}_{(\text{g})}$ $\rightleftharpoons$ $\text{CO}_{2(\text{g})}$ + $\text{H}_{2(\text{g})}$
初濃度 (M) $0.01$$0.01$$0$$0$
反應量 $-0.005$$-0.005$$+0.005$$+0.005$
平衡一 $0.005$$0.005$$0.005$$0.005$
$K_c = \dfrac{[\text{CO}_2][\text{H}_2]}{[\text{CO}][\text{H}_2\text{O}]} = \dfrac{0.005 \times 0.005}{0.005 \times 0.005} = 1$

第二階段（加入 $0.02\text{ mol H}_2\text{O}_{(\text{g})}$）：

體積為 $1\text{ L}$，故加入後 $\text{H}_2\text{O}_{(\text{g})}$ 之新初始濃度為 $0.005 + 0.02 = 0.025\text{ M}$，反應向右移動。設改變量為 $x$：

$\text{CO}_{(\text{g})}$ + $\text{H}_2\text{O}_{(\text{g})}$ $\rightleftharpoons$ $\text{CO}_{2(\text{g})}$ + $\text{H}_{2(\text{g})}$
新初始 $0.005$$0.025$$0.005$$0.005$
反應量 $-x$$-x$$+x$$+x$
新平衡 $0.005-x$$0.025-x$$0.005+x$$0.005+x$
$K_c = 1 = \dfrac{(0.005+x)(0.005+x)}{(0.005-x)(0.025-x)}$
$\Rightarrow (0.005-x)(0.025-x) = (0.005+x)^2$
$\Rightarrow 1.25\times 10^{-4} - 0.03x + x^2 = 2.5\times 10^{-5} + 0.01x + x^2$
$\Rightarrow 1.0\times 10^{-4} = 0.04x$
$\Rightarrow x = 0.0025\text{ M}$

因此新平衡時：
$[\text{CO}_2] = 0.005 + 0.0025 = 0.0075\text{ M}$
$[\text{CO}] = 0.005 - 0.0025 = 0.0025\text{ M}$

💡 範例詳解

答案：(A)(B)(E)

分析：

先從表格推求反應方程式。濃度變化量 $\Delta$ 為：
$\Delta\text{A} = 0.05 - 0.1 = -0.05$
$\Delta\text{B} = 0.05 - 0.2 = -0.15$
$\Delta\text{C} = 0.1 - 0 = +0.1$

變化量之比即為係數比 $\Rightarrow |\Delta\text{A}| : |\Delta\text{B}| : |\Delta\text{C}| = 0.05 : 0.15 : 0.1 = 1 : 3 : 2$。
反應物減少、產物增加，故反應方程式為： $\text{A} + 3\text{B} \rightleftharpoons 2\text{C}$

(A) 若有 1mol A 與 3mol B 完全反應，則可生成 2mol C

說明：正確。由推求出之方程式 $\text{A} + 3\text{B} \rightleftharpoons 2\text{C}$，可知反應莫耳數比為 $1:3:2$。

(B) 若平衡反應式為 $\dfrac{1}{2}\text{A} + \dfrac{3}{2}\text{B} \rightleftharpoons \text{C}$，則其在 25℃ 之濃度平衡常數為 40

說明：正確。代入平衡濃度 $[\text{A}]=0.05$, $[\text{B}]=0.05$, $[\text{C}]=0.1$：
$K = \dfrac{[\text{C}]}{[\text{A}]^{1/2}[\text{B}]^{3/2}} = \dfrac{0.1}{(0.05)^{1/2}(0.05)^{3/2}} = \dfrac{0.1}{(0.05)^{2}} = \dfrac{0.1}{0.0025} = 40$。

(C) 此一反應平衡時，B 氣體之分壓為 A 之 3 倍

說明：錯誤。平衡時 $[\text{A}] = 0.05\text{ M}$，$[\text{B}] = 0.05\text{ M}$，濃度相等，故分壓也相等。

(D) 此一反應平衡時，氣體 C 之莫耳分率為 1/3

說明：錯誤。平衡時總濃度 $= 0.05 + 0.05 + 0.1 = 0.2\text{ M}$。氣體 C 的莫耳分率 $= \dfrac{0.1}{0.2} = \dfrac{1}{2}$。

(E) 此一反應平衡時，系統之總壓力為 4.9 atm

說明：正確。由理想氣體方程式 $P = C_{\text{total}}RT$：
$P_{\text{total}} = 0.2 \times 0.082 \times (273 + 25) = 0.2 \times 0.082 \times 298 = 4.8872 \approx 4.9\text{ atm}$。
