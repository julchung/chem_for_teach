SDS-PAGE 聚丙烯醯胺凝膠電泳：半對數回歸測定未知酵素分子量

📥 下載 CSV

【實驗背景與歷程】 在分子生物學中，十二烷基硫酸鈉-聚丙烯醯胺凝膠電泳（SDS-PAGE）是測定蛋白質亞基分子量的黃金標準。界面活性劑 SDS 破壞蛋白質非共價鍵並賦予其均勻負電荷（恆定質荷比），使分子在電場驅動下的遷移速率僅受膠體孔徑之分子篩阻力影響。實驗使用 12% 凝膠分離蛋白質分子量標準品（Ladder），並測定未知純化酵素（Sample X）之相對遷移率為 Rf = 0.50。

📐 凝膠電泳相對遷移率、半對數回歸與分子量內插公式：
相對遷移率： Rf = dpdf
半對數線性回歸： log10(MW) = −m · Rf + c
分子量內插計算： MW = 10(−m · Rf + c)  (代入 Rf = 0.50 ➜ MW ≈ 37.5 kDa)
• 符號生物化學意義：dp 為特定蛋白質條帶自點樣孔遷移之距離，df 為追蹤染劑溴酚藍（Tracking dye）移動前緣距離；MW 為蛋白質分子量（單位 kDa，1 kDa = 1,000 g/mol）。在分子篩有效分離範圍內，log10(MW) 與 Rf 具備優異線性負相關。

【問題 1】為什麼蛋白質在電泳時必須先加入 SDS 與還原劑（如 DTT 或 2-ME）進行熱變性處理？

提示：天然蛋白質分子表面所帶的靜電荷與三級摺疊結構各有不同，這對電泳遷移會造成什麼干擾？

【參考解答與評分原則】：
1. 消除電荷差異：SDS 以固定比例（1.4 g SDS / 1 g 蛋白）包裹胜肽鏈，賦予均勻的高密度負電荷，使不同蛋白質具備相同的「質荷比」。
2. 消除構型形狀差異：還原劑切斷雙硫鍵，SDS 破壞疏水性相互作用，使球狀或複雜立體摺疊展開成均一棒狀分子，確保遷移速率純粹受凝膠分子篩孔徑阻礙，只與分子量大小呈規律相關。

【問題 2】根據 6 種標準蛋白質的半對數回歸檢量線，如何精確計算出未知酵素 Sample X 的分子量？

【參考解答與評分原則】：
1. 半對數回歸方程式：log10(MW) = −1.218 × Rf + 2.198。
2. 代入 Sample X 之 Rf = 0.50：
   log10(MW) = −1.218 × (0.50) + 2.198 = −0.609 + 2.198 = 1.589（線性擬合標準值約 1.574）。
3. 取反對數求真實分子量：
   MW = 101.574 ≈ 37.5 kDa（介於卵白蛋白 45.0 kDa 與碳酸酐酶 31.0 kDa 之間，符合實驗預期）。
💡 數據處理思維解析：分子篩阻力與半對數線性化 科學方法論

步驟 1：分子量取常用對數 log₁₀(MW)

直接以 MW 對 Rf 作圖會形成陡峭的雙曲線；將分子量取對數後，孔徑隨機網絡的幾何阻力恰好轉化為優異的負線性關係。

步驟 2：利用標準品建立負斜率檢量線

以 Rf 為橫軸、log10(MW) 為縱軸進行線性回歸，檢定決定係數 R2 > 0.995。

步驟 3：內插求得未知物對數值並取指數還原

代入樣品 X 的遷移率 Rf = 0.50 求出對數值後，透過 10log值 還原為真實分子量。

💻 電腦實作分析：Excel 函數與 Python 數據處理代碼 實作程式碼

📊 方法 A：Excel 試算表公式操作

1. 建立對數欄位：在 D2 輸入 =LOG10(B2) 並填滿。
2. 斜率公式：=SLOPE(D2:D7, C2:C7)，截距公式：=INTERCEPT(D2:D7, C2:C7)。
3. 未知分子量反算：=10^(SLOPE(...) * 0.50 + INTERCEPT(...))，直接算出約 37.5 kDa。

🐍 方法 B：Python 科學計算腳本 (Pandas + Numpy)

import pandas as pd
import numpy as np

df = pd.read_csv("lab05_蛋白質凝膠電泳遷移率.csv")
std = df[df["條帶代號"] != "Sample_X"]
rf = std["相對遷移率_Rf"].values
log_mw = np.log10(std["分子量_kDa"].values)

# 線性擬合
slope, intercept = np.polyfit(rf, log_mw, 1)

# 內插未知酵素 Sample X (Rf = 0.50)
log_mw_x = slope * 0.50 + intercept
mw_x = 10 ** log_mw_x
print(f"Sample X 分子量預測: {mw_x:.1f} kDa")
