光電子能譜法：鋁原子逐級游離能 (IE₁~IE₈) 階躍與對數作圖分析

📥 下載 CSV

【實驗背景與歷程】 在原子結構研究中，逐級游離能（Successive Ionization Energies）是直接揭示電子殼層排布的最強實驗證據。實驗透過高能 X 射線光電子能譜儀（XPS），逐步逐顆游離氣態鋁原子（Al(g)）核外的各個電子，依序測定將第 1 顆至第 8 顆電子移至無窮遠處所需之游離能（IE1 至 IE8）。

📐 逐級游離能定義、對數轉換與階躍判讀公式：
第 n 級游離反應式： Al(n−1)+(g) ⟶ Aln+(g) + e−  (ΔH = IEn > 0)
對數坐標轉換： y = log10(IEn)
主殼層階躍比值： Rn = IEn+1IEn  (R3 = 115802745 ≈ 4.22 倍)
• 物理化學原理：IEn 單位為 kJ/mol。當移除第 1~3 顆電子時（3p¹、3s²），處於最外層價電子殼層；游離第 4 顆電子時，必須打破內層完整的氖（Ne）核心八隅體核心殼層（2p⁶），有效核電荷大幅增加且遮蔽效應劇減，因而發生跳躍式暴增（4.22 倍）。

✍️ 課堂探究思考與非選作圖檢核 問題討論

【問題 1】為什麼在原始線性坐標系下，IE₁、IE₂、IE₃ 的數值差異幾乎被完全壓縮而無法辨識？為何對數轉換能解決此問題？

提示：當縱軸必須容納 30,000 kJ/mol 時，578 與 1,817 在同一比例尺下的高度佔比是多少？

【參考解答與評分原則】：
1. 原始坐標壓縮失真：當最大值達 27,465 kJ/mol 時，若以線性比例尺作圖，IE1 = 578 kJ/mol 僅佔縱軸總長度的 1.9%，在前三級的細微差異（3p 與 3s 軌域能階差）完全被視覺掩蓋壓縮為一條貼近底部的直線。
2. 對數轉換的威力：取常用對數 log10(IE) 後，數值區間平緩壓縮至 2.76 ～ 4.44。對數坐標的本質是「反映數量級變化」，使得前三級價電子間的遞增與 IE4 突破階躍同時清晰可見。

【問題 2】由 IE₁ ～ IE₈ 的數值倍率突變，如何嚴密推論鋁原子的最外層價電子數及主族分類？

【參考解答與評分原則】：
1. 倍率突變檢驗：
• IE2 / IE1 = 1817 / 578 = 3.14×
• IE3 / IE2 = 2745 / 1817 = 1.51×
• IE4 / IE3 = 11577 / 2745 = 4.22×（發生最大量級暴增）
• IE5 / IE4 = 14842 / 11577 = 1.28×
2. 物理化學推論：前 3 顆電子移除所需能量相對較小，表示其位於最外層主量子數 n = 3 的 M 殼層；至第 4 顆電子時，必須打破填滿的 n = 2（L 殼層，電子組態 2s2 2p6），有效核電荷極大且主半徑急遽縮小，因而需要額外巨大的能量。
3. 結論：最外層價電子數為 3，屬於元素週期表第 13 族（IIIA 族）。
💡 數據處理思維解析：大跨度數據之對數作圖技巧 科學方法論

步驟 1：建立常用對數欄位 log₁₀(Y)

當縱軸數據跨越 2～3 個數量級以上時，直接做線性圖必失真。先將各數值取常用對數 log10，將數百至數萬的跨度均勻化。

步驟 2：計算相鄰比值定位階躍轉折

計算相鄰兩項之比值 Rn = IEn / IEn−1，搜尋大於 3.5～4 倍的異常突躍點，該階躍點前之項數即代表最外層價電子數。

步驟 3：結合柱狀/階梯圖呈現層次感

在半對數坐標下繪製柱狀圖或階梯折線圖，並以色彩標記不同主殼層，視覺清晰度遠勝傳統線性折線。

💻 電腦實作分析：Excel 函數與 Python 數據處理代碼 實作程式碼

📊 方法 A：Excel 試算表公式操作

1. 建立對數欄位：在 C2 輸入 =LOG10(B2) 並向下填滿。
2. 建立比值欄位：在 D3 輸入 =B3/B2 並向下填滿。
3. 插入圖表時，選取縱坐標軸 ➜ 按右鍵「坐標軸格式」➜ 勾選「對數刻度（基底 10）」。

🐍 方法 B：Python 科學計算腳本 (Matplotlib 半對數圖)

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

df = pd.read_csv("lab03_逐級游離能量度階躍.csv")
n = df["游離級數_n"].values
ie = df["游離能_kJ_mol"].values

# 計算相鄰倍率
ratio = np.zeros(len(ie))
ratio[1:] = ie[1:] / ie[:-1]
print("倍率清單:", [f"{r:.2f}x" for r in ratio[1:]])

# 繪製半對數圖表
plt.figure(figsize=(7, 4))
plt.semilogy(n, ie, marker='o', color='#c084fc', linewidth=2.5)
plt.axvline(x=3.5, color='#f43f5e', linestyle='--', label='殼層突破 (IE4/IE3 = 4.22x)')
plt.xlabel("Ionization Stage n")
plt.ylabel("IE (kJ/mol) [Log Scale]")
plt.title("Al Successive Ionization Energies")
plt.grid(True, which="both", alpha=0.3)
plt.legend()
plt.show()
