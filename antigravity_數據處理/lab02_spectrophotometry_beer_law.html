紫外-可見分光光度法：比爾-朗伯吸光度定律與高濃度非線性偏離

【實驗背景與歷程】在環境水質監測中，測定工業廢水中重金屬銅離子（Cu2+）含量常採用分光光度法。 研究者配製一系列已知精確濃度的硫酸銅（CuSO4）標準溶液，以光徑 b = 1.00 cm 的石英比色槽，在最大吸收波長 λ = 810 nm 下測量各溶液之透光率 T 與吸光度 A。 同時對未知含銅工業廢水樣品（Sample X）進行相同條件的光度測量，測得吸光度 AX = 0.812。

相關公式：

✍️ 課堂探究思考與非選作圖檢核 問題討論

【問題 1】為什麼濃度 0.1500 M 的點明顯偏離了線性回歸線向下方彎曲？在建立檢量線時應如何處置？

提示：比爾定律的推導是建立在「稀薄溶液」的假設上，當溶質濃度過高時，分子間距與溶液折射率會發生什麼改變？

【參考解答與評分原則】：
1. 比爾定律的物理極限：比爾定律是描述稀薄溶液（通常 c < 0.01～0.05 M）吸光行為的極限定律。當吸光物種濃度過高時，鄰近吸光分子與離子之間的靜電交互作用與電荷分布重疊，導致分子的莫耳吸光係數 ε 發生改變；且高濃度下溶液折射率不再是常數，造成實測吸光度呈現「負偏離」（低於理論線性值）。
2. 儀器雜散光限制：高吸光度（A > 1.5）時透光率 T < 3%，儀器內部雜散光的影響顯著上升，造成光電感測失真。
3. 數據處理處置：建立分析檢量線時，必須明確界定「線性動態範圍（Linear Dynamic Range）」，剔除超出線性範圍的高濃度偏離點，僅以 0.00～0.10 M 區間進行線性擬合。

【問題 2】根據正確的線性回歸直線方程式，計算出未知工業廢水樣品 X 的精確銅離子莫耳濃度？

【參考解答與評分原則】：
1. 檢量線回歸方程式：使用前 6 組點（0.00 ～ 0.10 M）擬合得到：
A = 12.00 · C + 0.001   (R2 = 0.9999)
莫耳吸光係數 ε = 12.00 M−1cm−1。
2. 代入未知樣品吸光度：AX = 0.812，
CX = (0.812 − 0.001) / 12.00 ≈ 0.0676 M ≈ 0.0677 M
3. 有效性驗證：0.0677 M 落在 0.00～0.10 M 之線性動態區間內，內插計算極具信度。
💡 數據處理思維解析：如何評估檢量線的線性動態範圍？ 科學方法論

步驟 1：作散佈圖並肉眼檢查高濃度偏離

直接觀察散佈圖，前 6 組點（0 ～ 0.10 M）幾乎共線，而最後一點（0.15 M, 1.538）明顯下垂偏離預期值（理論預期應約 1.80）。

步驟 2：截取有效線性區間回歸

剔除 0.15 M 點，對 0 ～ 0.10 M 進行回歸，斜率為 12.00，R2 = 0.9999。若盲目將全部點做回歸，斜率會被拉低至 10.66（R2 = 0.985），造成嚴重系統偏誤。

步驟 3：內插求值與動態範圍檢查

樣品 X 吸光度為 0.812，落於 0.720 ～ 0.958 之間，屬於極度安全的內插區域，求得 CX = 0.0677 M。

💻 電腦實作分析：Excel 函數與 Python 數據處理代碼 實作程式碼

📊 方法 A：Excel 試算表公式操作

1. 篩選 C ≤ 0.10 M 的數據範圍進行擬合。
2. 斜率公式：=SLOPE(D2:D7, B2:B7) 得 12.00。
3. 內插廢水樣品 X：=(0.812 - INTERCEPT(D2:D7, B2:B7)) / SLOPE(D2:D7, B2:B7) 得 0.0677 M。

🐍 方法 B：Python 科學計算腳本 (Pandas + Numpy)

import pandas as pd
import numpy as np

df = pd.read_csv("lab02_分光光度法吸光度檢量線.csv")
# 篩選標準品且濃度 <= 0.10 M 的線性區間
linear_df = df[(df["樣品類型"] == "標準品") & (df["濃度_M"] <= 0.10)]
c = linear_df["濃度_M"].values
a = linear_df["實測吸光度_A"].values

slope, intercept = np.polyfit(c, a, 1)
# 內插未知廢水 X (A = 0.812)
c_x = (0.812 - intercept) / slope
print(f"檢量線方程: A = {slope:.2f} * C + {intercept:.4f}")
print(f"廢水樣品 X 濃度: {c_x:.4f} M")
