【實驗背景與歷程】 在化學定量分析中，濁度計（Turbidimeter）常藉由測量懸浮固體微粒的散射光濁度（NTU）來監測沉澱生成反應。實驗者在錐形瓶中預先置入 10.0 mL 未知濃度之氯化鋇（BaCl2）溶液，以滴定管逐次加入 0.050 M 之硫酸鈉（Na2SO4）標準溶液，充分攪拌反應後測量溶液之散射光濁度。

📐 沉澱化學計量、當量點莫耳守恆與未知濃度反推公式：
沉澱淨離子反應： Ba2+(aq) + SO42−(aq) ⟶ BaSO4(s) ↓  (反應比 1 : 1)
當量轉折點守恆： MBa · VBa = MSO4 · Veq
未知初濃度計算： MBa = MSO4 · VeqVBa = 0.050 M × 10.0 mL10.0 mL = 0.050 M
• 限量試劑轉折機理解析：當量轉折點（Veq = 10.0 mL）前，Ba2+ 過量，SO42− 為限量試劑，每滴入一滴皆轉化為沉澱，濁度呈正比線性攀升；當量點後，Ba2+ 已全數反應耗盡轉為限量試劑，沉澱總量達到飽和平台（約 710 NTU），後續過量加入之 Na2SO4 溶液不再增加沉澱。

【問題 1】為何本實驗數據絕對不能使用全域單一直線回歸？請從「限量試劑」與「沉澱平衡」說明其本質。

提示：當量點前與當量點後，溶液中誰是過量試劑、誰是限量試劑？兩階段的物理化學斜率是否相同？

【參考解答與評分原則】：
1. 前後兩階段物理機制截然不同：
• 當量點前（V ≤ 10 mL）：Ba2+ 過量，SO42− 為限量試劑，每滴入一滴皆轉化為沉澱，濁度呈正比線性攀升（斜率約 +70.8 NTU/mL）。
• 當量點後（V ≥ 10 mL）：Ba2+ 已耗盡轉為限量試劑，過量的硫酸根無法再產生沉澱，濁度進入飽和平台（斜率近 0）。
2. 數據處理原則：具有結構性機理突變的實驗，必須採用「分段折線回歸（Piecewise Linear Fitting）」求交點，強行套用全域單一直線會破壞限量試劑的科學意義。

【問題 2】由兩段回歸線之交點 (10.0 mL, 710 NTU)，如何嚴密推算出原氯化鋇溶液之初濃度？

【參考解答與評分原則】：
1. 當量點體積：由上升線與平台線聯立交點得知當量體積 Veq = 10.0 mL。
2. 莫耳數計量平衡：
n(SO42−) = 0.050 M × 10.0 mL = 0.50 mmol。
依沉澱反應計量比 1 : 1，n(Ba2+) = 0.50 mmol。
3. 求初始莫耳濃度：
C(BaCl2) = 0.50 mmol / 10.0 mL = 0.050 M
💡 數據處理思維解析：分段折線回歸與轉折點定位法 科學方法論

步驟 1：依據反應分組數據數列

將數據拆分為數列 1（V ≤ 10 mL 上升區）與數列 2（V ≥ 10 mL 平台區），分別進行各自的最佳配適回歸。

步驟 2：聯立方程式求解交點坐標

上升線 y = m1x + c1，平台線 y = m2x + c2。交點當量體積為 Veq = (c2 − c1) / (m1 − m2)。

步驟 3：化學計量初濃度計算

將求得的當量轉折點體積 Veq = 10.0 mL 代入莫耳計量守恆：MBa = (0.050 M × 10.0 mL) / 10.0 mL = 0.050 M，直接精準求出未知待測液初濃度。

💻 電腦實作分析：Excel 函數與 Python 數據處理代碼 實作程式碼

📊 方法 A：Excel 試算表公式操作

1. 前段斜率：=SLOPE(B2:B7, A2:A7)，截距：=INTERCEPT(B2:B7, A2:A7)。
2. 後段平台：=SLOPE(B7:B11, A7:A11)，截距：=INTERCEPT(B7:B11, A7:A11)。
3. 交點體積：=(截距2 - 截距1) / (斜率1 - 斜率2)。

🐍 方法 B：Python 科學計算腳本 (Numpy 分段擬合)

import numpy as np
import pandas as pd

df = pd.read_csv("lab04_鋇鹽沉澱滴定濁度轉折.csv")
v = df["滴入Na2SO4體積_mL"].values
ntu = df["實測濁度_NTU"].values

# 前段與後段擬合
m1, c1 = np.polyfit(v[:6], ntu[:6], 1)
m2, c2 = np.polyfit(v[5:], ntu[5:], 1)

# 解聯立交點
v_eq = (c2 - c1) / (m1 - m2)
c_ba = (0.050 * v_eq) / 10.0
print(f"化學當量點體積: {v_eq:.2f} mL, BaCl2 初濃度: {c_ba:.4f} M")
