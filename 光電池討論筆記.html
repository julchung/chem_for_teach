題目背景與光電池裝置說明

題目描述一個光電池（photoelectrochemical cell），其組成如下：

半電池電極溶液端點
左側銀棒（鑲有氯化銀）1 M KCl 水溶液A
右側白金絲（Pt）氯化亞銅（CuCl）溶液B

照光後發生的光化學反應

AgCl(s) ──hν──→ Ag(s) + Cl(AgCl) （氯原子暫時吸附在 AgCl 表面，記為 Cl(AgCl)）

題目給定的半反應標準還原電位

#半反應E°（V）
①AgCl(s) + e⁻ → Ag(s) + Cl(aq)⁻+0.22
②Cu(aq)²⁺ + e⁻ → Cu(aq)⁺+0.15
③Cl(AgCl) + e⁻ → Cl(aq)⁻+3.80
④Cu(aq)⁺ + e⁻ → Cu(s)+0.52
⑤Ag(aq)⁺ + e⁻ → Ag(s)+0.79
🔑 關鍵觀察
Cl(AgCl) 的還原電位高達 +3.80 V，是極強的氧化劑， 照光後產生的 Cl(AgCl) 將主導電化學反應方向。
2

照光時 AB 兩端電壓計算

步驟一：判斷正負極

照光後，Cl(AgCl) 是最強氧化劑（E° = +3.80 V）， 優先在左側 A 極（Ag 棒）被還原 → A 端為陰極（正極）。

右側 B 端（Pt 白金絲）發生氧化反應 → B 端為陽極（負極）。

電極位置反應類型半反應E°
A 端 正極 左（Ag 棒） 陰極（還原） Cl(AgCl) + e⁻ → Cl(aq)⁻ +3.80 V
B 端 負極 右（Pt 絲） 陽極（氧化） Cu(aq)⁺ → Cu(aq)²⁺ + e⁻ 逆 +0.15 V

步驟二：計算電池電動勢

E電池 = E°陰極 − E°陽極 = 3.80 − 0.15 = 3.65 V
✦ VAB = VA − VB = +3.65 V
A 端為正（+），B 端為負（−），電流由 A 流向外電路至 B
3

停止照光後逆反應是否自發？

停止照光後，不再產生 Cl(AgCl)。若要透過電化學逆反應回復（電池反向放電）， 需考慮以下半反應：

電極逆向半反應E°
B 端（陰極） Cu(aq)²⁺ + e⁻ → Cu(aq)⁺ +0.15 V
A 端（陽極） Ag(s) + Cl⁻ → AgCl(s) + e⁻（氧化） −0.22 V
E逆 = E°陰極 − E°陽極（還原） = 0.15 − 0.22 = −0.07 V < 0
❌ 電化學逆反應不自發
E < 0 → ΔG = −nFE > 0 → 非自發反應
光電池在電化學上是不可逆的，無法像一般充電電池般逆向放電。

那為何題目說停光後會「立即回復」？

機制是否發生說明
光化學重組
Cl(AgCl) + Ag → AgCl		 ✅ 自發 Cl 活性極強，直接與鄰近 Ag 重組
電化學逆反應
（放電方向相反）		 ❌ 不自發 E = −0.07 V，ΔG > 0
💡 結論
系統回復初始 AgCl 狀態，靠的是光化學途徑（Cl 與 Ag 直接重組）， 而非電化學逆反應。停光 → Cl(AgCl) 失去光能支撐 → 立即與 Ag 重組 → AgCl 回復。
4

變色鏡片如何達成可逆反應？

變色鏡片（光致變色鏡片）表面上與題目光電池極為相似， 但兩者能否可逆的關鍵差異在於反應介質的物理限制。

核心差異：產物能不能「逃跑」

題目光電池玻璃變色鏡片
介質 液態電解質溶液 固態玻璃基質
Cl 的去向 擴散進溶液中成為 Cl⁻，遠離 Ag 被困在 AgCl 晶粒附近，無法移動
Cu²⁺ 的去向 在另一極生成，產物分離 Cu²⁺ 留在晶粒附近（固態限制）
逆反應難易 ❌ 不自發（E = −0.07 V） ✅ 熱力學可行（固態重組）

玻璃變色鏡片的完整機制

【照光變暗】 AgCl(s) ──hν──→ Ag(s) + Cl(AgCl) → Cl 吸附在 AgCl 晶粒表面 → Ag⁰ 聚集成奈米銀團簇（黑色）→ 鏡片變暗 【停光恢復（熱力學自發）】 Cl(AgCl) + Ag(s) ──熱能──→ AgCl(s) → Cl 未逃離，立即與鄰近 Ag 重組 → AgCl 再生，銀團簇消失 → 鏡片恢復透明
🔑 關鍵：固態空間限制（Spatial Confinement）
AgCl 微晶被嵌在玻璃網絡中，Cl 原子根本無法擴散遠離， 永遠待在 Ag 旁邊。停光後，熱振動能量就足以驅動 Cl + Ag → AgCl 的重組。
5

變色鏡片是否含有氯化亞銅（CuCl）？

⚠️ 令人驚訝的答案
傳統玻璃型光致變色鏡片（如 Corning Photogray） 確實含有 CuCl！與題目光電池成分幾乎相同。

傳統玻璃變色鏡片的成分

成分角色
AgCl / AgBr 微晶主要感光物質
CuCl（Cu⁺）電洞捕捉劑（增感劑）
SiO₂、Al₂O₃、B₂O₃玻璃基質（提供空間限制）

Cu⁺ 的功能說明

【無 Cu⁺ 的情況】 AgCl + hν → [e⁻ + h⁺] → e⁻ 與 h⁺ 立即復合 → 白白放熱，Ag⁰ 很少形成 → 變暗效率極差 【有 Cu⁺ 的情況】 AgCl + hν → [e⁻ + h⁺] h⁺ 被 Cu⁺ 捕捉： Cu⁺ + h⁺ → Cu²⁺ （阻止立即復合） e⁻ 還原銀離子： Ag⁺ + e⁻ → Ag⁰ （銀原子大量形成） Ag⁰ 聚集成銀團簇 → 鏡片迅速有效變暗 ✅

與題目光電池的對比

題目光電池玻璃變色鏡片
AgCl✅✅
CuCl✅✅
Cu²⁺ 的命運隨溶液遠離被困在固態，與 Ag⁰ 相鄰
電化學逆反應❌ 不自發無電路，不走電化學途徑
化學重組逆反應✅（題目說立即回復）✅（主要逆反應途徑）

現代塑膠變色鏡片（Transitions 等品牌）

🌀 完全不同的機制
採用有機光致變色化合物（螺吡喃、萘吡喃）嵌入塑膠， 靠分子構型改變（開環↔閉環）變色，完全不含 AgCl 或 CuCl。
螺吡喃（無色，閉環）──hν──→ 開環型（有色） 開環型 ──熱能/可見光──→ 螺吡喃（無色，閉環）✅ 可逆

AgCl 光解：兩種描述的統一

學習過程中，常見到 AgCl 光解的兩種寫法：

化學描述： AgCl(s) + hν → Ag(s) + Cl(AgCl)
固態物理描述： AgCl + hν → Ag⁺ + e⁻（電子電洞對）
⚠️ 重要釐清
這不是兩個同時競爭的反應——它們是同一個反應在不同層次的描述！

完整的反應步驟順序

步驟① AgCl 吸收光子（hν） 步驟② 在晶格中瞬間產生「電子-電洞對」（極短暫的中間態） e⁻（導帶）＋ h⁺（價帶） 步驟③ （兩者同時發生） e⁻ 遷移到 Ag⁺ 位置： Ag⁺ + e⁻ → Ag⁰ h⁺ 遷移到 Cl⁻ 位置： Cl⁻ + h⁺ → Cl⁰ 步驟④ 淨結果（化學描述）： AgCl + hν → Ag⁰ + Cl(AgCl) ↑ 這正是「化學描述」所寫的反應

兩種描述的對應關係

描述方式適用情境重點
化學描述
（Ag + Cl 生成）		 討論最終產物
討論逆反應重組		 說明宏觀化學變化
固態物理描述
（電子電洞對）		 解釋 Cu⁺ 的增感作用
解釋光電效率		 說明微觀機制
✅ 正確理解
「電子電洞對」是中間過渡態，「Ag⁰ 和 Cl(AgCl) 的生成」是最終結果。 兩種描述都正確，只是描述的層次不同。Cu⁺ 的角色是在步驟③捕捉電洞， 防止 e⁻ 與 h⁺ 復合，使 Ag⁰ 能夠大量累積。

總結與重點整理

🎯 核心計算結果

情況反應E°自發？
照光（正向） Cl(AgCl)還原 / Cu⁺氧化 +3.65 V ✅ 自發，VAB=+3.65V
停光（電化學逆向） Cu²⁺還原 / Ag氧化 −0.07 V ❌ 不自發

🔬 三種系統的比較

系統含 AgCl含 CuCl逆反應途徑可逆性
題目光電池 ✅ ✅ 光化學重組（Cl 未離太遠） 有限可逆
玻璃變色鏡片 ✅ ✅ 熱驅動重組（固態限制） ✅ 可逆
塑膠變色鏡片 ❌ ❌ 分子構型開環↔閉環 ✅ 可逆

💡 最重要的概念

①
電化學可逆性的關鍵不只是 E° 的正負，更在於產物是否被分離。
②
固態介質的「空間限制」讓 AgCl 系統能在停光後自發重組，這是變色鏡片的核心原理。
③
Cu⁺ 是「電洞捕捉劑」，阻止光生電子電洞對立即復合，讓銀原子能有效累積形成銀團簇。
④
AgCl 光解的「化學描述」與「固態物理描述」是同一過程的不同層次，並非兩個競爭反應。
🏁 光電池照光時 VAB = +3.65 V（A 正 B 負）
停光後電化學逆反應 E = −0.07 V，不自發
