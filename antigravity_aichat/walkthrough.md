# 🚀 AI 化學伴讀系統 - 功能更新紀錄

我們已成功將系統的「開發階段 1」與「開發階段 2」實作完畢，並對網頁程式碼進行了全面升級。

## 🛠️ 本次更新重點

### 1. 📐 介面鎖定與優化 (2:1 比例)
*   **鎖定比例**：利用 `flex: 2 0 0` 與 `flex: 1 0 0` 將網頁左側展示區與右側聊天區的寬度硬性限制在 $2:1$ 的黃金比例，且加入 `box-sizing: border-box`，完全防止了內容載入時版面不規則跳動或擠壓的 bug。

### 2. 📑 左側「當前講義」與「歷史板書」分頁系統
*   **動態分頁**：左側展示區新增了分頁切換按鈕。
    *   **當前講義**：展示 AI 針對當下提問產生的最新 HTML 圖文/SVG。
    *   **歷史板書**：每一次生成的新講義都會自動存入歷史紀錄，學生隨時可以切換到「歷史板書」分頁翻閱先前的板書內容。

### 3. 🌐 動態 Ollama 主機連線與模型清單載入
*   **主機設定**：右側 header 新增了 Ollama 主機網址輸入框（預設 `http://localhost:11434`），方便您切換本機與區網 IP。
*   **模型載入**：網頁載入時會自動向 Ollama 發送 `/api/tags` 請求，並將您本機已下載的所有模型（如 `llama3.2-vision:11b`、`qwen2.5:7b` 等）動態載入到下拉選單中供您自由切換，免去手動修改程式碼的麻煩。

### 4. ⚡ 串流 API 對接與打字機效果 (Streaming)
*   **串流生成**：實作了 `fetch` 的 `ReadableStream` 讀取邏輯。AI 在生成回答時，會以流暢的**打字機效果（Streaming）**即時在右側對話泡泡中吐出文字，大幅提升使用者的等待體驗。
*   **結構化解析**：利用正則表達式在串流期間即時攔截並解碼 `"chat"` 欄位的內容；並在串流結束後自動解析 JSON，將詳細的教學資料動態渲染到邊欄。

### 5. 🤖 三步驟多智能體接力協作 (Multi-Agent Agentic Workflow)
我們已經完成了核心的**多模型/多智能體分工邏輯**，透過單一視覺模型（如 `llama3.2-vision:11b`）分飾三角，免去模型切換卡頓的同時，實現高度複雜的接力流程：
1.  **第一步 Router (分流器)**：快速判斷使用者輸入。如果是普通問候，則立刻進入一般對話；如果是學術性問題，則引導啟動教學協作鏈。
2.  **第二步 Reasoner (推理大腦)**：針對學術化學提問進行深度的繁體中文學術解說與公式推導，並以 Streaming 即時呈現在右側聊天室。
3.  **第三步 Visualizer (繪圖師)**：接收第二步大腦的詳解，將其轉換為極具設計感的 HTML 講義，並要求 AI **使用內建 SVG 代碼動態繪製化學相關的圖表與曲線**，渲染於左側展示區。
