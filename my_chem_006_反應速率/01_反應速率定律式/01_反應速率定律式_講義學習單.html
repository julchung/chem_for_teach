一、反應速率的定義、表示法與化學計量關係 微觀意義 · 割線與切線斜率 · 計量數比
概念 1 反應速率的巨觀定義與微觀意涵

1. 定義：單位時間內，反應物濃度的消耗減少量，或生成物濃度的生成增加量。

2. 常用單位：溶液反應以體積莫耳濃度每秒表示（$\text{M/s}$ 或 $\text{M}\cdot\text{min}^{-1}$）；氣相反應可以分壓隨時間變化表示（$\text{atm/s}$、$\text{mmHg/min}$）。

3. 平均速率 vs 瞬時速率：

  • 平均速率 ($\bar{r}$)：一段時間間隔 $\Delta t$ 內的濃度變化，幾何意義為濃度－時間曲線之割線斜率：$\bar{r} = -\frac{\Delta [A]}{\Delta t} = \frac{\Delta [C]}{\Delta t}$。
  • 瞬時速率 ($r$)：時間間隔趨近於零時的極限值，幾何意義為該時刻濃度－時間曲線之切線斜率：$r = \lim_{\Delta t \to 0} \left(-\frac{\Delta [A]}{\Delta t}\right) = -\frac{d[A]}{dt}$。
概念 2 各成分反應速率與化學反應計量數比

對於一般化學反應：$aA + bB \longrightarrow cC + dD$，在同一反應容器（定容）中：

  • 各成分物質的消耗或生成莫耳數變化量比，嚴格等於化學計量係數比：$\Delta n_A : \Delta n_B : \Delta n_C : \Delta n_D = a : b : c : d$。
  • 各物質的反應速率比等於其化學計量係數比：$r_A : r_B : r_C : r_D = a : b : c : d$。
  • 統一定義之整體反應速率 ($r$)：以係數歸一化，使各物種算得之整體反應速率數值相同且恆為正值： $$r = -\frac{1}{a}\frac{\Delta [A]}{\Delta t} = -\frac{1}{b}\frac{\Delta [B]}{\Delta t} = \frac{1}{c}\frac{\Delta [C]}{\Delta t} = \frac{1}{d}\frac{\Delta [D]}{\Delta t}$$
重要觀念警示：純固體或純液體之濃度為定值，其消耗或生成通常以「莫耳數改變率 ($\text{mol/s}$)」或「質量改變率 ($\text{g/s}$)」表示，不宜使用體積莫耳濃度 ($\text{M/s}$)。

二、速率定律式、反應級數與速率常數 $k$ 的物理本質 速率定律式 · 反應級數意義 · 速率常數 $k$ 影響因子與單位
概念 1 速率定律式 (Rate Law) 與反應級數

1. 通式：對於均相反應 $aA + bB \longrightarrow \text{產物}$，其反應速率常可表示為反應物濃度的冪次函數： $$r = k[A]^m[B]^n$$

2. 反應級數之微觀與巨觀規則：

  • $m$ 稱為對反應物 $A$ 的反應級數；$n$ 稱為對反應物 $B$ 的反應級數；$(m+n)$ 稱為總反應級數。
  • 極重要鐵律：反應級數 $m, n$ 必須由實驗測定，絕不能直接引用平衡方程式的化學計量數 $a, b$（僅在已知為「一步完成之基元反應」時才相等）。
  • 級數數值特徵：可為正整數（$0, 1, 2$）、負數（負級數代表該物質具有抑制或阻滯效應）、分數（如自由基鏈反應常見 $1/2$ 級）。
概念 2 速率常數 $k$ (Rate Constant) 的物理本質與因次推導

1. 速率常數 $k$ 的物理意義：代表當各反應物濃度均為 $1\text{ M}$ 時的反應速率，反映反應進行之固有難易度。

2. 影響 $k$ 值的控制因子：

  • 決定 $k$ 值的因子：反應物本性、反應溫度、催化劑。
  • 與 $k$ 值完全無關的因子：反應物濃度、系統體積、系統壓力（改變濃度只改變反應速率 $r$，不改變 $k$ 值！）。

3. 速率常數 $k$ 的因次單位推導：若反應總級數為 $N = m + n$，濃度單位為 $\text{M}$，時間為 $\text{s}$： $$[r] = [k][\text{M}]^N \implies [k] = \frac{\text{M}\cdot\text{s}^{-1}}{\text{M}^N} = \mathbf{\text{M}^{1-N}\cdot\text{s}^{-1}} = \mathbf{\left(\frac{\text{L}}{\text{mol}}\right)^{N-1}\cdot\text{s}^{-1}}$$

總反應級數 ($N$) 速率定律式形式 速率常數 $k$ 的單位（$\text{M, s}$） 常用工程/大考單位形式
$0$ 級反應 $r = k$ $\text{M}\cdot\text{s}^{-1}$ $\text{mol}\cdot\text{L}^{-1}\cdot\text{s}^{-1}$
$1$ 級反應 $r = k[A]$ $\text{s}^{-1}$ $\text{s}^{-1}$ 或 $\text{min}^{-1}$（與濃度單位無關！）
$2$ 級反應 $r = k[A]^2$ 或 $k[A][B]$ $\text{M}^{-1}\cdot\text{s}^{-1}$ $\text{L}\cdot\text{mol}^{-1}\cdot\text{s}^{-1}$
$3$ 級反應 $r = k[A]^2[B]$ $\text{M}^{-2}\cdot\text{s}^{-1}$ $\text{L}^2\cdot\text{mol}^{-2}\cdot\text{s}^{-1}$

三、測定速率定律式的實驗方法：初始速率法與連串濃度追蹤 控制變因法 · 初始速率法步階求解 · 連串數據差比判定
概念 1 初始速率法 (Method of Initial Rates) 解題演算法

1. 為何必須測定「初始速率」？

  • 反應剛開始瞬間，產物濃度接近於零，可徹底忽略逆反應或產物干擾。
  • 反應物濃度尚未顯著消耗，可用已知的初始配製濃度 $[A]_0, [B]_0$ 精確代入定律式。

2. 三步解題演算法（Control of Variables）：

  • 步驟 1（求對 A 級數 $m$）：尋找 $[B]_0$ 相同之兩組實驗（如組 1 與組 2），消去 $k$ 與 $[B]_0^n$： $$\frac{r_1}{r_2} = \frac{k[A]_1^m [B]_1^n}{k[A]_2^m [B]_2^n} = \left(\frac{[A]_1}{[A]_2}\right)^m \implies \text{解出 } m$$
  • 步驟 2（求對 B 級數 $n$）：同理固定 $[A]_0$，比較不同 $[B]_0$ 之兩組初速率求出 $n$。
  • 步驟 3（求速率常數 $k$ 與單位）：任選一組數據（通常選第 1 組），將數值與單位完整代入 $k = \frac{r_1}{[A]_1^m [B]_1^n}$。
概念 2 連續濃度追蹤法（等差數列 vs 等比數列判別法）

若實驗固定其他反應物濃度，單獨追蹤某一反應物隨時間之連續濃度數據：

  • 等時間間隔 $\Delta t$ 內，濃度減少量 $\Delta [A]$ 為定值（呈等差數列） $\implies$ 零級反應（速率與濃度無關，消耗速率恆定）。
  • 等時間間隔 $\Delta t$ 內，濃度剩餘比值 $\frac{[A]_{t+\Delta t}}{[A]_t}$ 為定值（呈等比數列） $\implies$ 一級反應（速率與濃度成正比，半生期恆定）。

  • 系統總壓 $P = (P_0 - x) + bx + cx = P_0 + (b+c-1)x \implies x = \frac{P - P_0}{b+c-1}$。
  • 反應物殘餘分壓：$P_A = P_0 - x = P_0 - \frac{P - P_0}{b+c-1}$。將實驗測得之總壓 $P$ 即可完全轉為反應物分壓 $P_A$！
概念 2 連續半生期比值速判反應級數法則

  • 二級反應：$t_{1/2} = \frac{1}{k[A]_0} \implies$ 連續半生期逐次加倍：$t_{1/2(1)} : t_{1/2(2)} : t_{1/2(3)} = 1 : 2 : 4$。
