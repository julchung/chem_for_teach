電解質的解離 (Dissociation)

解離的概念

電解質在水中溶解時，會分解成陽離子、陰離子的過程稱為 解離。

$AB \rightleftharpoons A^+ + B^-$

強弱電解質

  • 強電解質：完全解離 ($\alpha \approx 100\%$ )。
    例如：強酸 ($HCl$), 強鹼 ($NaOH$), 大多數鹽類 ($NaCl$)
  • 弱電解質：部分解離 ($\alpha \ll 100\%$ )，達平衡狀態。
    例如：弱酸 ($CH_3COOH$), 弱鹼 ($NH_3$)

小知識：解離度 ($\alpha$)

$$ \alpha = \frac{\text{已解離莫耳數}}{\text{原始莫耳數}} \times 100\% $$

水的自解離與 $K_w$

$$ \begin{alignat}{2} H_2O_{(l)} + H_2O_{(l)} &\rightleftharpoons H_3O^+_{(aq)} &&+ OH^-_{(aq)} \\ H_2O_{(l)} &\rightleftharpoons H^+_{(aq)} &&+ OH^-_{(aq)} \end{alignat} $$

水的離子積常數 ($K_w$)

在 $25^\circ C$ 時：

$K_w = [H^+][OH^-] = 1.0 \times 10^{-14}$

重要觀念：

  • 為吸熱反應：$K_w$ 隨溫度升高而增大（吸熱反應）。
  • 在任何水溶液中，$[H^+][OH^-]$ 的乘積在該溫度下恆為 $K_w$。

pH 與 pOH

定義與公式

  • $pH = -\log[H^+]$
  • $pOH = -\log[OH^-]$
  • $pH + pOH = pK_w = 14$ ($25^\circ C$)

若 $[H^+] = 10^{-pH}$

若 $[OH^-] = 10^{-pOH}$

(若 $[H^+] = a \times 10^{-b}$ 時，$pH = b - \log a$)

酸鹼性判斷 ($25^\circ C$)

酸鹼性$[H^+]$ 與 $[OH^-]$pH 值
中性$[H^+] = [OH^-]$$pH = 7$
酸性$[H^+] > [OH^-]$$pH < 7$
鹼性$[H^+] < [OH^-]$$pH > 7$

範例

Q1.

在 $80^\circ C$ 時有一未知水溶液，測得 $pH=7$，試問該水溶液是酸性、中性還是鹼性？

Q2.

1. $[H^+] = 3 \times 10^{-5}$，則 $pH = ?$

2. $pH = 10.7$，則 $[H^+] = ?$

Q1 詳解

答案：鹼性

因為在 $80^\circ C$ 時，水的離子積常數 $K_w > 10^{-14}$（約為 $2.5 \times 10^{-13}$）。

此時中性水溶液的 $pH = -\log(\sqrt{K_w}) \approx 6.3$。

該未知水溶液 $pH = 7$，大於中性時的 $pH = 6.3$（這表示 $[H^+] < [OH^-]$），故呈現鹼性。

Q2 詳解

1. $[H^+] = 3 \times 10^{-5}$

$pH = -\log(3 \times 10^{-5})$
$= 5 - \log 3 $
$\approx 5 - 0.477 $
$= \mathbf{4.523}$

2. $pH = 10.7$

$[H^+] = 10^{-10.7}$
$= 10^{-11} \times 10^{0.3} $
$\approx \mathbf{2 \times 10^{-11} M}$

酸解離常數 ($K_a$)

單質子酸解離

$HA \rightleftharpoons H^+ + A^-$

$K_a = \frac{[H^+][A^-]}{[HA]}$

實例：醋酸 ($CH_3COOH$)

$CH_3COOH \rightleftharpoons CH_3COO^- + H^+$

$K_a = \frac{[CH_3COO^-][H^+]}{[CH_3COOH]}$

多步解離 (以磷酸為例)

$$ \begin{alignat}{2} H_3PO_4 &\rightleftharpoons H^+ + H_2PO_4^- \quad && K_{a1} = \frac{[H^+][H_2PO_4^-]}{[H_3PO_4]} \\[1ex] H_2PO_4^- &\rightleftharpoons H^+ + HPO_4^{2-} \quad && K_{a2} = \frac{[H^+][HPO_4^{2-}]}{[H_2PO_4^-]} \\[1ex] HPO_4^{2-} &\rightleftharpoons H^+ + PO_4^{3-} \quad && K_{a3} = \frac{[H^+][PO_4^{3-}]}{[HPO_4^{2-}]} \end{alignat} $$

規律：$K_{a1} \gg K_{a2} \gg K_{a3}$

鹼解離常數 ($K_b$)

鹼解離反應

$B + H_2O \rightleftharpoons BH^+ + OH^-$

$K_b = \frac{[BH^+][OH^-]}{[B]}$

當 $K_b$ 越大，鹼性越強。

實例：氨水 ($NH_3$)

$NH_3 + H_2O \rightleftharpoons NH_4^+ + OH^-$

$K_b = \frac{[NH_4^+][OH^-]}{[NH_3]}$

$NH_3$ 是常見的弱鹼實例。

注意：強酸強鹼在水中「完全解離」，不討論 $K_a$/$K_b$，只有弱酸弱鹼才需要使用平衡常數計算 pH。

共軛酸鹼對的解離與水解

數學推導 ($CH_3COOH/CH_3COO^-$)

1. 醋酸解離：$CH_3COOH \rightleftharpoons CH_3COO^- + H^+$

$K_a = \frac{[CH_3COO^-][H^+]}{[CH_3COOH]}$

2. 醋酸根水解：$CH_3COO^- + H_2O \rightleftharpoons CH_3COOH + OH^-$

$K_b = \frac{[CH_3COOH][OH^-]}{[CH_3COO^-]}$

3. 證明：將 $K_b$ 分子分母同乘 $[H^+]$

$K_b = \frac{[CH_3COOH][OH^-]}{[CH_3COO^-]} \times \frac{\color{red}{[H^+]}}{\color{red}{[H^+]}}$

4. 得到結論：

$K_b = \frac{1}{K_a} \times K_w \implies K_b = \frac{K_w}{K_a}$

數學關係與結論

$K_a \times K_b = K_w$

對於一對共軛酸鹼對：

  • 強度呈 反比（一強配一弱）
  • 弱酸的共軛鹼亦為弱鹼。
  • 強酸的共軛鹼不具鹼性（極弱）。
  • 在 $25^\circ C$ 時，$pK_a + pK_b = 14$

鹽類的水解

鹽類的離子與水反應，產生 $H^+$ 或 $OH^-$，稱為 水解。

鹽的解離：
$AB_{(aq)} \rightarrow A^+_{(aq)} + B^-_{(aq)}$
陽離子的水解：
$A^+_{(aq)} + H_2O_{(l)} \rightleftharpoons A_{(aq)} + H_3O^+_{(aq)}$
$K_a = \frac{[A][H_3O^+]}{[A^+]}$
陰離子的水解：
$B^-_{(aq)} + H_2O_{(l)} \rightleftharpoons HB_{(aq)} + OH^-_{(aq)}$
$K_b = \frac{[HB][OH^-]}{[B^-]}$
鹽類類型 組成來源 實例 水溶液性質 說明
中性鹽 強酸 + 強鹼 $NaCl, KNO_3$ 中性 ($pH=7$) 離子不水解
酸性鹽 強酸 + 弱鹼 $NH_4Cl, CuCl_2$ 酸性 ($pH<7$) 陽離子水解
鹼性鹽 弱酸 + 強鹼 $CH_3COONa, NaF$ 鹼性 ($pH>7$) 陰離子水解
弱酸弱鹼鹽 弱酸 + 弱鹼 $NH_4F, NH_4CN$ 視 $K_a, K_b$ 而定 陰陽離子均水解

強酸弱鹼鹽 (酸性)

以氯化銨為例：$NH_4Cl$

1. 完全解離：

$NH_4Cl \rightarrow NH_4^+ + Cl^-$

2. 水解反應：(陽離子水解)

$NH_4^+ + H_2O \rightleftharpoons NH_3 + H_3O^+$

產生 $H_3O^+$，使水溶液呈酸性。

計算範例

已知 $25^\circ C$ 時 $NH_3$ 的 $K_b$ 為 $1.8 \times 10^{-5}$，現在有一杯 $25^\circ C$, $0.1M$ 的 $NH_4Cl_{(aq)}$，試問該水溶液的 pH 值為多少？

$NH_4Cl$ 計算詳解

Step 1. 求出 $NH_4^+$ 的 $K_a$：

$K_a = \frac{K_w}{K_b} = \frac{1.0 \times 10^{-14}}{1.8 \times 10^{-5}} \approx 5.56 \times 10^{-10}$

Step 2. 計算 $[H^+]$：

因為 $K_a$ 很小，代入近似公式：
$[H^+] = \sqrt{C \cdot K_a} = \sqrt{0.1 \times (5.56 \times 10^{-10}) }$
$= \sqrt{55.6 \times 10^{-12}} \approx 7.45 \times 10^{-6} M$

Step 3. 求出 $pH$：

$pH = -\log(7.45 \times 10^{-6}) = 6 - \log 7.45 \approx \mathbf{5.13}$

結論：溶液呈酸性。

強鹼弱酸鹽 (鹼性)

以醋酸鈉為例：$CH_3COONa$

1. 完全解離：

$CH_3COONa \rightarrow Na^+ + CH_3COO^-$

2. 水解反應：(陰離子水解)

$CH_3COO^- + H_2O \rightleftharpoons CH_3COOH + OH^-$

產生 $OH^-$，使水溶液呈鹼性。

計算範例

已知 $25^\circ C$ 時 $CH_3COOH$ 的 $K_a$ 為 $1.8 \times 10^{-5}$，現在有一杯 $25^\circ C$, $0.1M$ 的 $CH_3COONa_{(aq)}$，試問該水溶液的 pH 值為多少？

$CH_3COONa$ 計算詳解

Step 1. 求出 $CH_3COO^-$ 的 $K_b$：

$K_b = \frac{K_w}{K_a} = \frac{1.0 \times 10^{-14}}{1.8 \times 10^{-5}} \approx 5.56 \times 10^{-10}$

Step 2. 計算 $[OH^-]$：

因為 $K_b$ 很小，代入近似公式：
$[OH^-] = \sqrt{C \cdot K_b} = \sqrt{0.1 \times (5.56 \times 10^{-10}) }$
$= \sqrt{55.6 \times 10^{-12}} \approx 7.45 \times 10^{-6} M$

Step 3. 求出 $pOH$ 與 $pH$：

$pOH = -\log(7.45 \times 10^{-6}) = 6 - \log 7.45 \approx 5.13$

$pH = 14 - pOH = 14 - 5.13 = \mathbf{8.87}$

結論：溶液呈鹼性。

酸式鹽 (Acidic Salts) 的酸鹼性

多元酸中氫離子未完全解離所形成的鹽類，其酸鹼性取決於「解離」與「水解」的競爭。

$NaHSO_4$ (硫酸氫鈉)

因 $HSO_4^-$ 為強酸陰離子，不水解，僅會解離：

$HSO_4^- \rightarrow H^+ + SO_4^{2-}$

結論：呈酸性

$NaHSO_3$ (亞硫酸氫鈉)

解離與水解的競爭：

1. 解離：$HSO_3^- \rightleftharpoons H^+ + SO_3^{2-}$ ($K_{a2}$)

2. 水解：$HSO_3^- + H_2O \rightleftharpoons H_2SO_3 + OH^-$ ($K_b$)

比較後發現：解離 > 水解

結論：呈酸性

$NaHCO_3$ (碳酸氫鈉)

存在兩種平衡：

1. 解離：$HCO_3^- \rightleftharpoons H^+ + CO_3^{2-}$ ($K_{a2}$)

2. 水解：$HCO_3^- + H_2O \rightleftharpoons H_2CO_3 + OH^-$ ($K_h$)

比較後發現：水解 > 解離

結論：呈鹼性

常見酸性酸式鹽：$NaHSO_4, NaH_2PO_4, NaHSO_3$

常見鹼性酸式鹽：$NaHCO_3, Na_2HPO_4, NaHS$

先由理想氣體方程式計算，若要維持 $190\text{ mmHg}$ 的平衡壓力，需要多少莫耳的 $\text{CO}_2$：

$PV = nRT$
$\Rightarrow \left(\dfrac{190}{760}\text{ atm}\right) \times 8.8\text{ L} = n_{\text{CO}_2} \times 0.082 \times (273 + 800)\text{ K}$
$\Rightarrow 0.25 \times 8.8 = n_{\text{CO}_2} \times 0.082 \times 1073$
$\Rightarrow 2.2 \approx n_{\text{CO}_2} \times 88$
$\Rightarrow n_{\text{CO}_2} = 0.025\text{ mol}$

欲達平衡，系統中必須有 $0.025\text{ mol}$ 的 $\text{CO}_2$，且固體（$\text{CaCO}_3$ 和 $\text{CaO}$）必須同時存在。我們先將各選項換算為初始莫耳數（式量：$\text{CaCO}_3=100$，$\text{CO}_2=44$，$\text{CaO}=56$）：

(A) $\text{CaCO}_3: \dfrac{1}{100}=0.01\text{ mol}$，$\text{CO}_2: \dfrac{0.44}{44}=0.01\text{ mol}$
$\text{CaCO}_{3(\text{s})}$ $\rightleftharpoons$ $\text{CaO}_{(\text{s})}$ + $\text{CO}_{2(\text{g})}$
初： $0.01$ $0$ $0.01$

說明：即使 $\text{CaCO}_3$ 全部分解，$\text{CO}_2$ 最多只能產生 $0.01 + 0.01 = 0.02\text{ mol} < 0.025\text{ mol}$，無法達到平衡所需的 $0.025\text{ mol}$ $\text{CO}_2$ 壓力。因此無法達平衡。

(B) $\text{CO}_2: \dfrac{4.4}{44}=0.1\text{ mol}$，$\text{CaO}: \dfrac{5.6}{56}=0.1\text{ mol}$
$\text{CaCO}_{3(\text{s})}$ $\rightleftharpoons$ $\text{CaO}_{(\text{s})}$ + $\text{CO}_{2(\text{g})}$
初： $0$ $0.1$ $0.1$
反應： $+0.075$ $-0.075$ $-0.075$
當量： $0.075$ $0.025$ $0.025$

說明：$\text{CO}_2$ 超過 $0.025\text{ mol}$，反應向左進行。消耗 $0.1 - 0.025 = 0.075\text{ mol}$ 的 $\text{CO}_2$ 與 $\text{CaO}$。此時 $\text{CaO}$ 剩下 $0.1 - 0.075 = 0.025\text{ mol}$，並生成 $0.075\text{ mol}$ 的 $\text{CaCO}_3$。三者皆存在，可達平衡。

(C) $\text{CO}_2: \dfrac{4.4}{44}=0.1\text{ mol}$，$\text{CaO}: \dfrac{0.56}{56}=0.01\text{ mol}$
$\text{CaCO}_{3(\text{s})}$ $\rightleftharpoons$ $\text{CaO}_{(\text{s})}$ + $\text{CO}_{2(\text{g})}$

說明：反應向左進行，但 $\text{CaO}$ 只有 $0.01\text{ mol}$，即使 $\text{CaO}$ 全部用完，也只能消耗 $0.01\text{ mol}$ 的 $\text{CO}_2$，$\text{CO}_2$ 仍剩下 $0.09\text{ mol} > 0.025\text{ mol}$。無法消耗足夠的 $\text{CO}_2$ 至平衡值，無法達平衡。

(D) $\text{CaCO}_3: \dfrac{3}{100}=0.03\text{ mol}$
$\text{CaCO}_{3(\text{s})}$ $\rightleftharpoons$ $\text{CaO}_{(\text{s})}$ + $\text{CO}_{2(\text{g})}$
初： $0.03$ $0$ $0$
反應： $-0.025$ $+0.025$ $+0.025$
當量： $0.005$ $0.025$ $0.025$

說明：反應向右進行，分解產生 $0.025\text{ mol}$ 的 $\text{CO}_2$ 時，需消耗 $0.025\text{ mol}$ 的 $\text{CaCO}_3$。由於初莫耳數 $0.03 > 0.025$，$\text{CaCO}_3$ 不會耗盡（還剩 $0.005\text{ mol}$），三者皆存在，可達平衡。

(E) $\text{CaCO}_3: 0.03\text{ mol}$，$\text{CaO}: 0.1\text{ mol}$
$\text{CaCO}_{3(\text{s})}$ $\rightleftharpoons$ $\text{CaO}_{(\text{s})}$ + $\text{CO}_{2(\text{g})}$

反應： $-0.025$ $+0.025$ $+0.025$

說明：反應向右進行，同 (D) $\text{CaCO}_3$ 不會耗盡，且原本就有 $\text{CaO}$，反應後 $\text{CaO}$ 會變得更多。三者皆存在，可達平衡。

答案：(C)

分析：

第一階段（求平衡常數 $K_c$）：

$\text{CO}_{(\text{g})}$ + $\text{H}_2\text{O}_{(\text{g})}$ $\rightleftharpoons$ $\text{CO}_{2(\text{g})}$ + $\text{H}_{2(\text{g})}$
初濃度 (M) $0.01$$0.01$$0$$0$
反應量 $-0.005$$-0.005$$+0.005$$+0.005$
平衡一 $0.005$$0.005$$0.005$$0.005$
$K_c = \dfrac{[\text{CO}_2][\text{H}_2]}{[\text{CO}][\text{H}_2\text{O}]} = \dfrac{0.005 \times 0.005}{0.005 \times 0.005} = 1$

第二階段（加入 $0.02\text{ mol H}_2\text{O}_{(\text{g})}$）：

體積為 $1\text{ L}$，故加入後 $\text{H}_2\text{O}_{(\text{g})}$ 之新初始濃度為 $0.005 + 0.02 = 0.025\text{ M}$，反應向右移動。設改變量為 $x$：

$\text{CO}_{(\text{g})}$ + $\text{H}_2\text{O}_{(\text{g})}$ $\rightleftharpoons$ $\text{CO}_{2(\text{g})}$ + $\text{H}_{2(\text{g})}$
新初始 $0.005$$0.025$$0.005$$0.005$
反應量 $-x$$-x$$+x$$+x$
新平衡 $0.005-x$$0.025-x$$0.005+x$$0.005+x$
$K_c = 1 = \dfrac{(0.005+x)(0.005+x)}{(0.005-x)(0.025-x)}$
$\Rightarrow (0.005-x)(0.025-x) = (0.005+x)^2$
$\Rightarrow 1.25\times 10^{-4} - 0.03x + x^2 = 2.5\times 10^{-5} + 0.01x + x^2$
$\Rightarrow 1.0\times 10^{-4} = 0.04x$
$\Rightarrow x = 0.0025\text{ M}$

因此新平衡時：
$[\text{CO}_2] = 0.005 + 0.0025 = 0.0075\text{ M}$
$[\text{CO}] = 0.005 - 0.0025 = 0.0025\text{ M}$

答案：(A)(B)(E)

分析：

先從表格推求反應方程式。濃度變化量 $\Delta$ 為：
$\Delta\text{A} = 0.05 - 0.1 = -0.05$
$\Delta\text{B} = 0.05 - 0.2 = -0.15$
$\Delta\text{C} = 0.1 - 0 = +0.1$

變化量之比即為係數比 $\Rightarrow |\Delta\text{A}| : |\Delta\text{B}| : |\Delta\text{C}| = 0.05 : 0.15 : 0.1 = 1 : 3 : 2$。
反應物減少、產物增加，故反應方程式為： $\text{A} + 3\text{B} \rightleftharpoons 2\text{C}$

(A) 若有 1mol A 與 3mol B 完全反應，則可生成 2mol C

說明：正確。由推求出之方程式 $\text{A} + 3\text{B} \rightleftharpoons 2\text{C}$，可知反應莫耳數比為 $1:3:2$。

(B) 若平衡反應式為 $\dfrac{1}{2}\text{A} + \dfrac{3}{2}\text{B} \rightleftharpoons \text{C}$，則其在 25℃ 之濃度平衡常數為 40

說明：正確。代入平衡濃度 $[\text{A}]=0.05$, $[\text{B}]=0.05$, $[\text{C}]=0.1$：
$K = \dfrac{[\text{C}]}{[\text{A}]^{1/2}[\text{B}]^{3/2}} = \dfrac{0.1}{(0.05)^{1/2}(0.05)^{3/2}} = \dfrac{0.1}{(0.05)^{2}} = \dfrac{0.1}{0.0025} = 40$。

(C) 此一反應平衡時，B 氣體之分壓為 A 之 3 倍

說明：錯誤。平衡時 $[\text{A}] = 0.05\text{ M}$，$[\text{B}] = 0.05\text{ M}$，濃度相等，故分壓也相等。

(D) 此一反應平衡時，氣體 C 之莫耳分率為 1/3

說明：錯誤。平衡時總濃度 $= 0.05 + 0.05 + 0.1 = 0.2\text{ M}$。氣體 C 的莫耳分率 $= \dfrac{0.1}{0.2} = \dfrac{1}{2}$。

(E) 此一反應平衡時，系統之總壓力為 4.9 atm

說明：正確。由理想氣體方程式 $P = C_{\text{total}}RT$：
$P_{\text{total}} = 0.2 \times 0.082 \times (273 + 25) = 0.2 \times 0.082 \times 298 = 4.8872 \approx 4.9\text{ atm}$。
