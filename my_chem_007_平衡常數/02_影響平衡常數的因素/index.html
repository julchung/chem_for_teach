勒沙特略原理 (Le Chatelier's Principle)

⚖️ 核心定義

勒沙特略原理：在平衡系中，若加入影響平衡的因子，則該反應將向抵消此因子的方向移動，直至在新條件下達到新平衡。

系統受外界刺激 $\rightarrow$ 系統自我調適以減弱刺激

💡 類比：平衡系統就像一個彈簧——你施加壓力，它就反抗壓力；加熱，它就吸收熱量。

注意：平衡移動後，$K$ 值未必改變——只有溫度改變才會改變 $K$ 值！

📌 影響平衡的因子總覽

① 濃度效應
增減反應物或生成物的濃度。
K 值不變
② 壓力（體積）效應
改變氣相反應的壓力或容器體積。
K 值不變
③ 溫度效應
升高或降低反應溫度。
K 值改變！
④ 催化劑
同時加速正、逆反應，縮短達平衡時間。
K 值不變，平衡不移動

濃度效應對平衡的影響

🧪 濃度效應引導教學

(1) 增大反應物濃度，或降低生成物濃度，平衡向右移動。

反應 $2\text{A} \rightleftharpoons 3\text{B}$，達平衡後再加入少量的 A 破壞平衡，則：

  1. 瞬間 $Q = \frac{[\text{B}]^3_{原平衡}}{[\text{A}]^2_{瞬間}}$ < $K = \frac{[\text{B}]^3_{原平衡}}{[\text{A}]^2_{原平衡}}$ (>, <, =)
  2. 此時瞬間正反應速率 > 瞬間逆反應速率 (>, <, =)
  3. 反應向 右 進行達到新平衡 (向左/向右/不移動)
  4. 達新平衡時，新平衡常數 = 原平衡常數 (>, <, =)
  5. 且達新平衡時，反應物 $[\text{A}]_{新平衡}$ > $[\text{A}]_{原平衡}$
  6. 生成物 $[\text{B}]_{新平衡}$ > $[\text{B}]_{原平衡}$ (增加或減少)
註：濃度變化量比 $\Delta[\text{A}] : \Delta[\text{B}] = 2 : 3$

當 $[\text{A}]$ 瞬間增加，則正反應速率 $r_f$ 也隨之瞬間激增。

(2) 增大生成物濃度，或降低反應物濃度，平衡向左移動。

  1. 瞬間 $Q = \frac{[\text{B}]^3_{原平衡}}{[\text{A}]^2_{瞬間}}$ > $K = \frac{[\text{B}]^3_{原平衡}}{[\text{A}]^2_{原平衡}}$ (>, <, =)

  4. 達新平衡時，新平衡常數 = 原平衡常數 (>, <, =)
  5. 且達新平衡時，反應物 $[\text{A}]_{新平衡}$ < $[\text{A}]_{原平衡}$
  6. 生成物 $[\text{B}]_{新平衡}$ < $[\text{B}]_{原平衡}$ (增加或減少)

🧪 更多濃度改變規律

減少反應物：瞬間 $Q > K$，逆反應速率 > 正反應速率，平衡向左移動。

加入生成物：$Q > K$，平衡向左移動。

加入固相/純液相物種：濃度視為定值，不影響平衡！
例如：加入 $\text{AgCl}(s)$ 不改變 $\text{AgCl}$ 溶解平衡。

📊 稀釋與解離平衡

水溶液稀釋：等比例降低所有物種濃度，相當於體積擴大，$Q < K$，平衡向粒子數較多的一方移動。

例：$\text{CH}_3\text{COOH}(aq) \rightleftharpoons \text{H}^+(aq) + \text{CH}_3\text{COO}^-(aq)$

加水稀釋 → 平衡向右移動 → 解離度上升，但各離子的絕對濃度仍下降。

⚠️ 注意：達到新平衡時，平衡常數 $K$ 不改變（溫度不變）。

範例：AgCl 飽和溶液

$\text{AgCl}(s) \rightleftharpoons \text{Ag}^+(aq) + \text{Cl}^-(aq)$
  • 加 AgCl(s) → 不影響平衡
  • 加 AgNO₃ → [Ag⁺]增加 → 平衡向左 → [Cl⁻]降低
  • 加水 → 稀釋 → 平衡向右 → 溶解度增加
  • 加氨水 → Ag⁺ 與 NH₃ 結合 → [Ag⁺]降低 → 平衡向右

✨ 改變壓力與體積的小總結

係數和相等的反應：改變壓力/體積不影響平衡位置。例：$\text{H}_2 + \text{I}_2 \rightleftharpoons 2\text{HI}$（1+1=2）。

⚠️ 注意：溫度不變的情況下，不論壓力、體積如何改變，$K$ 值始終不變。

💡 判斷快速步驟

  1. 確認氣態各物種的係數和（左：$\sum a$，右：$\sum b$）
  2. 增壓 (壓縮體積) → 向係數和較小方移動
  3. 減壓 (擴大體積) → 向係數和較大方移動
  4. $\sum a = \sum b$ → 壓力改變不影響平衡

溫度效應

🌡️ 溫度改變與平衡移動

升高溫度：平衡向吸熱方向移動（把多餘的熱量用掉）。

降低溫度：平衡向放熱方向移動（產生更多熱量以補充不足）。

$\text{A}(g) \rightleftharpoons \text{B}(g) + \text{熱}$（放熱反應，$\Delta H < 0$）
升高溫度 $\Rightarrow$ 向左移（逆反應方向為吸熱）
降低溫度 $\Rightarrow$ 向右移

💡 注意：升溫後，正逆反應速率皆增大，但吸熱方向增大更顯著，所以平衡移向吸熱方向。

📈 溫度對平衡常數 K 的影響

吸熱反應 ($\Delta H > 0$)
升高溫度 → 平衡向右 → 生成物增加 → K 值變大
降低溫度 → K 值變小
放熱反應 ($\Delta H < 0$)
升高溫度 → 平衡向左 → 反應物增加 → K 值變小
降低溫度 → K 值變大

🔑 核心：只有溫度改變才會改變 $K$ 值！濃度、壓力、催化劑皆不影響 $K$。

範例：$\text{N}_2\text{O}_4(g) \rightleftharpoons 2\text{NO}_2(g)$，$\Delta H > 0$（吸熱）
升溫 → $K$ 增大 → $\text{NO}_2$ 濃度增加，顏色變深棕。

🌡️ 溫度效應教學範例

反應 $2\text{A}_{(g)} \rightleftharpoons 3\text{B}_{(g)}$，$\Delta H < 0$， 達平衡後再升高溫度，破壞平衡，則：

  1. 瞬間 $r'_{正(瞬間)} = m\,r_{正(原平衡)}$；$r'_{逆(瞬間)} = n\,r_{逆(原平衡)}$
    且 $m$ > $1$；$n$ > $1$；$m$ < $n$ (>, <, =)
  2. 此時瞬間正反應速率 < 瞬間逆反應速率 (>, <, =)
  3. 反應向 左 達到新平衡 (向左或向右或不移動)
  4. 反應物 $[\text{A}]$ ↑ ，生成物 $[\text{B}]$ ↓ (增加或減少)
  5. 達新平衡時，新平衡常數 < 原平衡常數 (>, <, =)

💡 升溫後，正逆速率皆增大，但放熱反應中逆反應（吸熱方向）增幅更大（$n > m$），故平衡向左移，$K$ 值減小。

📙 溫度效應總整理

放熱反應 ($\Delta H < 0$)

升高溫度 → 平衡向左 → $K$ 變小；降低溫度 → 平衡向右 → $K$ 變大。

吸熱反應 ($\Delta H > 0$)

升高溫度 → 平衡向右 → $K$ 變大；降低溫度 → 平衡向左 → $K$ 變小。

關鍵：溫度改變時，瞬間 $Q = K_{原}$，但新平衡常數 $K_{新}$ 會隨溫度改變。

💡 速率變化規律

升溫時：$K_{新} = m\,K_{原}$，
當 $m < 1$ 時為放熱反應，當 $m > 1$ 時為吸熱反應。

記住：濃度/壓力改變會改變 $Q$，但溫度改變會改變 $K$。

升/降溫後，平衡移向吸熱/放熱方向，該方向速率常數增幅（$m$ 或 $n$）相對較大。

催化劑對平衡的影響

⚡ 催化劑的作用機制

催化劑降低反應的活化能，使正反應與逆反應速率等比例增大，從而加速達到平衡，但不改變平衡的位置。

⚡ 催化劑效應教學範例

反應 $2\text{A}_{(g)} \rightleftharpoons 3\text{B}_{(g)}$，$\Delta H < 0$， 達平衡後再加入催化劑，破壞平衡，則：

  2. 此時瞬間正反應速率 = 瞬間逆反應速率 (>, <, =)
  3. 反應 不移動 達到新平衡 (向左或向右或不移動)
  4. 反應物 $[\text{A}]$ 不變 ，生成物 $[\text{B}]$ 不變 (增加或減少)

勒沙特略原理的應用：哈柏法製氨

🏭 反應式與理論最佳條件

$\text{N}_2(g) + 3\text{H}_2(g) \rightleftharpoons 2\text{NH}_3(g) \quad \Delta H = -92 \text{ kJ}$

理論上有利於 NH₃ 生成的條件：

  • 低溫：放熱反應，低溫使 $K$ 值增大，有利生成。
  • 高壓：左邊係數和 $1+3=4 > 2$，增壓使平衡右移。
  • 過量 N₂ 或 H₂：增加反應物濃度，促進生成 NH₃。
  • 及時移走 NH₃：降低生成物濃度，使平衡持續右移。

⚙️ 工業實際操作的折衷

🌡️ 溫度：中等溫度約 400–500°C
理論上低溫有利，但反應速率太慢，工業上採取折衷溫度兼顧速率與產率。
🎈 壓力：高壓約 200–300 atm
高壓有利生成，但高壓設備成本高，故採折衷壓力。在此條件下約 30% 的反應物轉換為 NH₃。
⚡ 催化劑：鐵粉（摻 K₂O + Al₂O₃）
在中等溫度下加快達到平衡，不改變產率，但讓工業製程在實際上可行。

💡 生成的 NH₃ 被加壓液化分離後，剩餘的 N₂ 和 H₂ 再送回反應器循環利用，提高整體產率。

正確答案： (B)(E)

【圖形特徵：正逆速率「等量同時上升」且馬上維持平衡】

這代表操作對正逆反應影響完全對稱，不改變平衡狀態。

  • (A) ✗ 升溫：正逆速率皆增加，但增幅不同（因反應熱非零，正逆活化能不等），速率線會分岔，出現平衡移動的過程。
  • (B) ✓ 催化劑：等比例降低正逆活化能 → 正逆速率「等倍率同步增加」→ 兩線同步跳高後立即黏合，不改變平衡。符合圖形！
  • (C) ✗ 擴大體積：濃度下降 → 正逆速率都瞬間下降，方向相反。
  • (D) ✗ 加入 H₂：只有正反應速率 R₁ 瞬間上升，逆反應速率不變，兩線先分岔後才趨近。
  • (E) ✓ 壓縮體積：所有氣體濃度等比例增大 → 正逆速率同步上升。又因 $\text{H}_2 + \text{I}_2 \rightleftharpoons 2\text{HI}$ 兩邊係數和相等（$1+1=2$）→ 壓力不影響平衡。正逆速率上升幅度完全相同，立即黏合。符合圖形！
