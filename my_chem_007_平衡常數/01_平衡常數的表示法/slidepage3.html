平衡常數的動力學導證

由反應機構探討正逆反應速率，推導平衡常數 $K$。點擊下方頁籤切換不同反應類型。

📈 位能圖 (單峰)

⏱️ 速率變化圖

📝 反應方程式

總反應 (一步驟基元反應)：

$2\text{A} \rightleftharpoons \text{B}$

（反應物粒子直接有效碰撞越過活化能障礙生成產物）

🔍 動力學導證過程

正反應速率定律式：$R_f = k_f[\text{A}]^2$
逆反應速率定律式：$R_r = k_r[\text{B}]$

化學平衡時，正反應速率等於逆反應速率 ($R_f = R_r$)：

$k_f[\text{A}]^2 = k_r[\text{B}]$

$K_c = \dfrac{k_f}{k_r} = \dfrac{[\text{B}]}{[\text{A}]^2}$

📈 位能圖 (雙峰)

⏱️ 速率變化圖 (總體)

📝 分步驟方程式

總反應： $2\text{A} + \text{B} \rightleftharpoons \text{D} + \text{E}$
步驟 1 (慢)： $2\text{A} \rightleftharpoons \text{D} + \text{X}$ $K_1 = \dfrac{[\text{D}][\text{X}]}{[\text{A}]^2}$
步驟 2 (快)： $\text{X} + \text{B} \rightleftharpoons \text{E}$ $K_2 = \dfrac{[\text{E}]}{[\text{X}][\text{B}]}$

🔍 動力學導證過程

達到平衡時，各分步驟均達動態平衡：

$K_1 \times K_2 = \left( \dfrac{[\text{D}][\text{X}]}{[\text{A}]^2} \right) \times \left( \dfrac{[\text{E}]}{[\text{X}][\text{B}]} \right)$

消去中間產物 $\text{X}$，得總平衡常數：

$K_c = K_1 \times K_2 = \dfrac{[\text{D}][\text{E}]}{[\text{A}]^2[\text{B}]}$

📈 位能圖 (三峰加催化劑)

⏱️ 速率變化圖 (加催化劑)

📝 分步驟方程式

總反應： $2\text{A} + \text{B} \rightleftharpoons \text{D} + \text{E}$ (Z 為催化劑)
步驟 1： $\text{A} + \text{Z} \rightleftharpoons \text{AZ} + \text{D}$ $K_1 = \dfrac{[\text{AZ}][\text{D}]}{[\text{A}][\text{Z}]}$
步驟 2： $\text{AZ} + \text{A} \rightleftharpoons \text{A}_2\text{Z}$ $K_2 = \dfrac{[\text{A}_2\text{Z}]}{[\text{AZ}][\text{A}]}$
步驟 3： $\text{A}_2\text{Z} + \text{B} \rightleftharpoons \text{Z} + \text{E}$ $K_3 = \dfrac{[\text{Z}][\text{E}]}{[\text{A}_2\text{Z}][\text{B}]}$

🔍 動力學導證過程

各步驟平衡常數相乘，消去中間產物 $\text{AZ}$、$\text{A}_2\text{Z}$ 及催化劑 $\text{Z}$：

$K_1 \times K_2 \times K_3 = \left(\dfrac{[\text{AZ}][\text{D}]}{[\text{A}][\text{Z}]}\right) \left(\dfrac{[\text{A}_2\text{Z}]}{[\text{AZ}][\text{A}]}\right) \left(\dfrac{[\text{Z}][\text{E}]}{[\text{A}_2\text{Z}][\text{B}]}\right)$
$K_c = \dfrac{[\text{D}][\text{E}]}{[\text{A}]^2[\text{B}]}$

💡 結論：平衡常數與反應機構途徑無關，亦不受催化劑影響。
