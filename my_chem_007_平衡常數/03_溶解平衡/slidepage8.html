範例 6

兩種微溶氫氧化物同時飽和同離子計算

在 $25^\circ\text{C}$ 時，設 $Mg(OH)_2$ 之 $K_{sp}$ 值為 $K_1$，$Ca(OH)_2$ 之 $K_{sp}$ 值為 $K_2$，今同時將上述兩種氫氧化物溶於水，而達成飽和時，溶液中 $[OH^-] = ?$

(A) $\sqrt{\dfrac{K_1 + K_2}{2}}$
(B) $\sqrt{\dfrac{K_1 + K_2}{4}}$
(C) $\dfrac{\sqrt[3]{K_1} + \sqrt[3]{K_2}}{2}$
(D) $\sqrt[3]{2(K_1 + K_2)}$
(E) $\sqrt[3]{\dfrac{K_1 + K_2}{2}}$

💡 範例解析

正確答案： (D)

1. 列出兩鹽解離方程式與離子濃度關係：

$Mg(OH)_2 \rightleftharpoons Mg^{2+} + 2OH^-$ （設解離出 $[Mg^{2+}] = x\ M$）

$Ca(OH)_2 \rightleftharpoons Ca^{2+} + 2OH^-$ （設解離出 $[Ca^{2+}] = y\ M$）

由電荷守恆或化學計量，溶液中共有的總氫氧根濃度：

$[OH^-] = 2x + 2y = 2(x + y) \Rightarrow x + y = \dfrac{[OH^-]}{2}$

2. 代入兩者的溶度積定義式：

$K_1 = [Mg^{2+}][OH^-]^2 = x \cdot [OH^-]^2$

$K_2 = [Ca^{2+}][OH^-]^2 = y \cdot [OH^-]^2$

3. 兩式相加求解 $[OH^-]$：

$K_1 + K_2 = (x + y) \cdot [OH^-]^2$

將 $x + y = \dfrac{[OH^-]}{2}$ 代入：

$K_1 + K_2 = \dfrac{[OH^-]}{2} \cdot [OH^-]^2 = \dfrac{[OH^-]^3}{2}$

$[OH^-]^3 = 2(K_1 + K_2) \Rightarrow [OH^-] = \mathbf{\sqrt[3]{2(K_1 + K_2)}}$。選 (D)。
