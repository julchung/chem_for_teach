7-3 溶解平衡 · 溶解度積 (Ksp) 核心觀念

⚖️ 核心定義

溶解度積 ($K_{sp}$)：微溶性電解質，在定溫下達飽和溶液時，其離子濃度次方乘積稱為溶解度積。

通式：$\mathrm{A}_x\mathrm{B}_y(s) \rightleftharpoons x\,\mathrm{A}^{y+}(aq) + y\,\mathrm{B}^{x-}(aq)$

💡 平衡常數式： $K_{sp} = [\mathrm{A}^{y+}]^x \, [\mathrm{B}^{x-}]^y$

重要性質：$K_{sp}$ 是一種平衡常數，只隨溫度與溶質種類改變！純水、加入共同離子、改變容積均不改變 $K_{sp}$ 之值。

📌 注意事項：固體純溶質之濃度視為常數，不列入 $K_{sp}$ 表達式中；溶液必須達到飽和平衡狀態方可適用。

📌 溶解度 ($s$) 與 $K_{sp}$ 的關係

① AB 型微溶鹽（1 : 1 鹽）
$K_{sp} = (s)(s) = s^2$ $\Rightarrow$ $s = \sqrt{K_{sp}}$
例：$\mathrm{AgCl}(s) \rightleftharpoons \mathrm{Ag}^+ + \mathrm{Cl}^-$ 若溶解度為 $s$，則 $[\mathrm{Ag}^+] = s,\; [\mathrm{Cl}^-] = s$
② $\mathrm{AB_2}$ 或 $\mathrm{A_2B}$ 型微溶鹽（1 : 2 鹽）
$K_{sp} = (s)(2s)^2 = 4s^3$ $\Rightarrow$ $s = \sqrt[3]{\dfrac{K_{sp}}{4}}$
例：$\mathrm{CaF}_2(s) \rightleftharpoons \mathrm{Ca}^{2+} + 2\mathrm{F}^-$ 或 $\mathrm{Ag}_2\mathrm{CrO}_4(s) \rightleftharpoons 2\mathrm{Ag}^+ + \mathrm{CrO}_4^{2-}$ 若溶解度為 $s$，則 $[\mathrm{Ca}^{2+}] = s,\; [\mathrm{F}^-] = 2s$
③ $\mathrm{AB_3}$ 或 $\mathrm{A_3B}$ 型微溶鹽（1 : 3 鹽）
$K_{sp} = (s)(3s)^3 = 27s^4$ $\Rightarrow$ $s = \sqrt[4]{\dfrac{K_{sp}}{27}}$
例：$\mathrm{Al(OH)}_3(s) \rightleftharpoons \mathrm{Al}^{3+} + 3\mathrm{OH}^-$ 若溶解度為 $s$，則 $[\mathrm{Al}^{3+}] = s,\; [\mathrm{OH}^-] = 3s$
④ $\mathrm{A_2B_3}$ 或 $\mathrm{A_3B_2}$ 型微溶鹽（2 : 3 鹽）
$K_{sp} = (3s)^3(2s)^2 = 108s^5$ $\Rightarrow$ $s = \sqrt[5]{\dfrac{K_{sp}}{108}}$
例：$\mathrm{Ca}_3(\mathrm{PO}_4)_2(s) \rightleftharpoons 3\mathrm{Ca}^{2+} + 2\mathrm{PO}_4^{3-}$ 若溶解度為 $s$，則 $[\mathrm{Ca}^{2+}] = 3s,\; [\mathrm{PO}_4^{3-}] = 2s$
