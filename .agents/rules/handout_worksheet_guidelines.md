# 課堂講義學習單（A4 版面）公版規格與排版規範

本規範適用於全站所有章節小節（如 2-5、2-6 及後續單元）之「講義學習單」HTML 檔案生成與維護。任何新建或修改學習單時必須嚴格遵守以下準則：

## 1. 核心頁面架構（標準 11 頁配置）
* **觀念頁（第 1～4 頁）**：
  * 依小節 `slidepage*.html` 順序整合概念、定律、公式盒與 SVG 向量圖形。
  * 每頁底部包含「隨堂觀念自我檢核」欄位。
* **經典範例頁（第 5～7 頁，共 3 頁）**：
  * **每頁固定上下兩題範例**（Page 5: 範例 1&2，Page 6: 範例 3&4，Page 7: 範例 5&6）。
  * **禁止重複標題**：去除上方多餘的「六、範例 X...」等大分類條，直接以淺藍 `經典範例 X` 開始，節省高度。
  * 結構：左側題目與子題、右側 SVG 向量分析圖、下方手寫演算虛線與答案填寫表格。
* **單元檢核練習題頁（第 8～10 頁，共 3 頁）**：
  * 來源為該小節之 `quiz.html` / `question_bank.json`。
  * **完全去除連連看**，僅收錄選擇題。
  * 分頁：第 8 頁（練習 1～4）、第 9 頁（練習 5～8）、第 10 頁（練習 9～10 ＋ 課堂推導手寫筆記大專區）。
  * **刪除底部空白答案格**：頁尾不留多餘的空白答案表格。
* **解答速查頁（第 11 頁，最後一頁）**：
  * 全 10 題標準解答矩陣表（雙欄 5 列，含題號、答案、核心考點）。
  * **不放長篇詳解**，附核心公式提點與學生自主學習評量檢核欄。

## 2. 大標題層級與編號規範
* 觀念頁依序為 `一、`、`二、`、`三、`、`四、`。
* **練習題頁延續大標題五**：
  * 第 8 頁：`五、單元檢核練習：題庫精選練習 1~4`
  * 第 9 頁：`五、單元檢核練習（續）：題庫精選練習 5~8`
  * 第 10 頁：`五、單元檢核練習（續）：題庫精選練習 9~10 ＆ 課堂運算手寫專區`
  * **禁止出現大標題六、七**。
* **答案速查頁固定為大標題六**：
  * 第 11 頁：`六、單元檢核練習題 · 參考答案速查表（不需詳解）`。

## 3. 排版與字元細節
* **去除贅字**：「隨堂觀念自我檢核」標題旁嚴禁出現「即時理解填空」字樣。
* **公式同行呈現**：所有數學式、化學式、單位式使用 `white-space: nowrap`，禁止在符號中間被換行切斷。
* **題號懸掛縮排**：所有編號（如 `(1)`、`(2)`）下方文字一律採用 `.q-item-indent`（編號固定寬度，第二行內文對齊第一行起始處，不縮到數字下方）。
* **SVG 圖文分離**：向量圖形內文字與座標軸、曲線徹底分離，避免圖形與說明卡片重疊。

## 4. 列印相容性與零空白頁防護（Zero Blank Pages）
* **頁面高度限制**：
  * `@page { size: A4 portrait; margin: 10mm 12mm 10mm 12mm; }`
  * 列印樣式（`@media print`）：
    ```css
    .concept-page {
        page-break-after: always !important;
        break-after: page !important;
        page-break-inside: avoid !important;
        break-inside: avoid !important;
        height: auto !important;
        min-height: auto !important;
        max-height: none !important;
        overflow: visible !important;
    }
    .concept-page:last-child {
        page-break-after: auto !important;
        break-after: auto !important;
    }
    ```
  * **禁止在 print 樣式下對 `.concept-page` 設置固定 `height: 275mm`**，避免不同印表機邊界導致溢出切出多餘空白夾頁。
  * 螢幕模式（`@media screen`）以 A4 擬真卡片置中呈現，方便閱讀檢核。
  * 使用 `tools/safe_test_page_heights.js` 驗證所有頁面高度（基準 1039px，0 overflow）。
