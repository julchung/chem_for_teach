法拉第電解定律 (Faraday's Laws of Electrolysis)

電解的基本概念

電解：外加電壓，強迫非自發 ($E^0_{cell} < 0$) 的氧化還原反應發生。

法拉第第一定律

電解時，電極上析出（或溶解）的物質質量，與通入的電量成正比：

$\Delta W \propto Q$

法拉第第二定律

相同電量下，各電極析出物質的量（mol）之比，等於其式量 / 得失電子數之比：

$\Delta W \propto \frac{M}{n}$（當量）

法拉第常數 $F = 96500 \text{ C/mol}$，即每莫耳電子攜帶的電量。

核心計算公式

合併兩大定律，得通用計算公式：

$$\Delta W = \frac{M}{n} \times \frac{Q}{F} = \frac{M}{n} \times \frac{I \cdot t}{F}$$
符號意義單位
$\Delta W$析出或溶解的質量g
$M$物質的式量（原子量）g/mol
$n$得失電子數（離子價數）—
$Q = I \cdot t$電量 = 電流 × 時間C
$F$法拉第常數96500 C/mol

💡 技巧：串聯電路各槽通過的電量相同，析出物質的莫耳當量 $\frac{\Delta W \cdot n}{M}$ 也相同！

水溶液之電解通則

影響電解產物的因素

  • 外加電壓大小不同，發生反應的物種不同。
  • 電極種類不同（惰性 vs 活性），反應不同。
  • 電解質種類與濃度影響各離子的優先反應順序。

⚡ 陽極的特例（非惰性電極）

若陽極為活性金屬（非 C 棒、Au、Pt），則陽極金屬本身優先氧化溶解：

$M_{(s)} \rightarrow M^{n+}_{(aq)} + ne^-$

例：電鍍時銅陽極溶解提供 $Cu^{2+}$。

水的電解半反應

+

陽極（Anode）氧化：

$2H_2O_{(l)} \rightarrow O_{2(g)} + 4H^+_{(aq)} + 4e^-$

陽極附近 $H^+$ 增加 → 溶液呈酸性

－

陰極（Cathode）還原：

$2H_2O_{(l)} + 2e^- \rightarrow H_{2(g)} + 2OH^-_{(aq)}$

陰極附近 $OH^-$ 增加 → 溶液呈鹼性

判斷陰陽極電解產物的優先順序 (使用惰性電極)

+

陽極 — 誰先被氧化？（失去電子的能力由弱到強）

失電子能力由弱到強排列，右側優先在陽極反應：

$F^-$ < $SO_4^{2-}$ < $NO_3^-$ < $H_2O$ < $Cl^-$（濃） < $Br^-$ < $I^-$

⚠️ 若電解液含 $F^-$, $SO_4^{2-}$, $NO_3^-$ 等難以失電子的陰離子，則水優先氧化，陽極生成 $O_2$ 與 $H^+$。

氯離子 $2Cl^- \rightarrow Cl_2 + 2e^-$
溴離子 $2Br^- \rightarrow Br_2 + 2e^-$
碘離子 $2I^- \rightarrow I_2 + 2e^-$ ( 註：$I_2 + I^- \rightarrow I_3^-$ )
－

陰極 — 誰先被還原？（得到電子的能力由弱到強）

得電子能力由弱到強排列，右側優先在陰極反應（與金屬活性序相反）：

$K^+$ < $Ca^{2+}$ < $Na^+$ < $Mg^{2+}$ < $Al^{3+}$ < $H_2O$ < $Zn^{2+}$ < $Fe^{2+}$ < $Cu^{2+}$ < $Ag^+$

💡 若電解液含第 1A、2A 族離子或 $Al^{3+}$ 等難以得電子的陽離子，則水優先還原，陰極生成 $H_2$ 與 $OH^-$。

電解液陽極產物陰極產物備註
$CuSO_4(aq)$$O_2$ (水氧化)$Cu$$Cu^{2+}$易還原
$NaCl(aq)$ 濃$Cl_2$$H_2$鹼氯工業
$NaCl(aq)$ 稀$O_2$$H_2$水優先
$AgNO_3(aq)$$O_2$$Ag$$Ag^+$易還原

🧪 電解碘化鉀 (KI) 濃溶液

反應方程式

陽極 (+)：
$2I^-_{(aq)} \rightarrow I_{2(s)} + 2e^-$
（但 $I_{2(s)} + I^-_{(aq)} \rightarrow I_{3(aq)}^-$，溶液呈棕色）

陰極 (-)：
$2H_2O_{(l)} + 2e^- \rightarrow H_{2(g)} + 2OH^-_{(aq)}$
（產生 $OH^-$，可使酚酞指示劑變粉紅色）

全反應：
$2KI_{(aq)} + 2H_2O_{(l)} \rightarrow I_{2(s)} + 2K^+_{(aq)} + 2OH^-_{(aq)} + H_{2(g)}$

⚠️ 實驗重點補充

  • 萃取：取陽極液加入 $CCl_4$ (密度 > 1) 萃取，下層會呈紫色 ($I_2$)。
  • 混合產物：若陰陽極產物混合，會發生自身氧化還原：
    $3I_2 + 6OH^- \rightarrow 5I^- + IO_3^- + 3H_2O$
  • 沉澱：取陰極液 ($OH^-$) 滴入 $FeCl_3(aq)$，生紅褐色沉澱：
    $Fe^{3+} + 3OH^- \rightarrow Fe(OH)_{3(s)} \downarrow$

例題詳解

答案：(A)(B)

解析：

  • (A) 正確。陰極水還原產生 $H_2$（無色氣體）。
  • (B) 正確。陽極產生 $I_2$，並溶於 $I^-$ 形成 $I_3^-$（棕色）。
  • (C) 錯誤。陽極發生氧化反應，不會產生鉀金屬，且 $K^+$ 難還原。
  • (D) 錯誤。陰極產生 $OH^-$，加入酚酞指示劑應呈粉紅色。
  • (E) 錯誤。應為取陰極溶液（含 $OH^-$）加入 $FeCl_3$ 才會產生 $Fe(OH)_3 \downarrow$ 紅褐色沉澱。

電解的應用：鹼氯工業

電解熔融氯化鈉（當式法）

以熔融 $NaCl$ 為電解質（無水），加入 $CaCl_2$ 降低熔點至約 $600°C$。

+陽極（氧化）：

$2Cl^- \rightarrow Cl_{2(g)} + 2e^-$

－陰極（還原）：

$Na^+ + e^- \rightarrow Na_{(l)}$

重點：電解熔融鹽，陰極得到金屬，陽極得到非金屬。

電解濃食鹽水（鹼氯工業）

工業上最重要的電解應用，同時產生三種重要工業原料：

$Cl_2$ + $H_2$ + $NaOH$

陽極：$2Cl^-_{(aq)} \rightarrow Cl_{2(g)} + 2e^-$

陰極：$2H_2O_{(l)} + 2e^- \rightarrow H_{2(g)} + 2OH^-_{(aq)}$

總反應：$2NaCl + 2H_2O \xrightarrow{電解} Cl_2\uparrow + H_2\uparrow + 2NaOH$

⚠️ 使用隔膜法或離子交換膜法防止 $Cl_2$ 與 $OH^-$ 混合發生反應：
$Cl_2 + 2OH^- \rightarrow Cl^- + ClO^- + H_2O$（漂白水）

電解的應用：製鋁與銅精製

⚡ 鋁的電解製法（霍耳–埃魯法）

以冰晶石 $Na_3AlF_6$ 為助熔劑，將 $Al_2O_3$ 熔點降至 $1000°C$ 以下。

$2Al_2O_{3(l)} \xrightarrow{\text{電解}, Na_3AlF_6} 4Al_{(l)} + 3O_{2(g)}$

  • 兩極均使用石墨棒（碳棒）。
  • 陽極：$O^{2-}$ 放電生成 $O_2$，高溫下 $O_2$ 與碳棒反應生成 $CO_2$，故陽極需定期更換。
  • 液態鋁（密度大）沉積於槽底抽出。

🔍 鋁的製造需要消耗大量電能（約 13 度電 /kg），
因此鋁的回收再製非常重要！

🔧 銅的電解精鍊

利用電解將粗銅提純為純銅（純度可達 99.99%）。

陽極（粗銅溶解）：

$Cu_{(粗)} \rightarrow Cu^{2+} + 2e^-$

比 Cu 活潑的 Zn, Fe 也溶解；比 Cu 不活潑的 Au, Ag 沉底→形成陽極泥。

陰極（純銅析出）：

$Cu^{2+} + 2e^- \rightarrow Cu_{(純)}$

✅ 精鍊過程中 $[Cu^{2+}]$ 幾乎不變，溶液顏色恆定，陰極質量增加 = 陽極質量減少。

電鍍（Electroplating）與陰極保護法

🎨 電鍍原理

通電使溶液中的金屬離子在被鍍物上析出，形成均勻金屬薄膜。

電鍍三大要素

  1. 陽極（+）：接擬鍍金屬（提供 $M^{n+}$）
  2. 陰極（−）：接被鍍物體（析出金屬）
  3. 電鍍液：含擬鍍金屬的離子

🛡️ 陰極保護法

將欲保護的金屬作為陰極，使其不被氧化腐蝕。有兩種方式：

① 犧牲陽極法（Sacrificial Anode）

連接一塊活性更大的金屬（如 Zn、Mg），使其優先氧化（犧牲），保護主體金屬。

  • 白鐵（鍍鋅鐵）：鋅先腐蝕保護鐵，即使鍍層刮傷仍有效。
  • 船殼、地下管線掛接鋅塊或鎂塊。

② 外加電流法

以直流電源將保護金屬接於負極（陰極），強制電子流入，防止金屬氧化。

常用於海上鑽油平台、船隻、橋梁等大型設施。

⚠️ 相較於白鐵（鍍鋅）vs 馬口鐵（鍍錫）

  • 白鐵（Zn 包鐵）：鋅活潑，刮傷後仍保護鐵（Zn先腐蝕）。
  • 馬口鐵（Sn 包鐵）：錫不活潑，刮傷後鐵反而先腐蝕。

Q1. 電解產物判斷

以白金為正負兩電極，電解下列水溶液，電解初始時，哪些溶液的陰極主要產物為氫氣？

(A) $0.1M$ 硫酸銅水溶液
(B) $0.1M$ 硝酸銀水溶液
(C) $0.1M$ 碘化鉀水溶液
(D) 飽和食鹽水
(E) 稀硫酸溶液

Q1 詳解

答案：(C)(D)(E)

解析：陰極為還原反應，得電子能力強者優先：
$Ag^+ > Cu^{2+} > H^+ > H_2O \gg Na^+, K^+$

(A) $CuSO_4$：$Cu^{2+}$ 比水易還原 → 陰極生 $Cu$

(B) $AgNO_3$：$Ag^+$ 最易還原 → 陰極生 $Ag$

(C) $KI$：$K^+$ 難還原，水優先 → 陰極生 $H_2$ ✓

(D) $NaCl(aq)$：$Na^+$ 難還原，水優先 → 陰極生 $H_2$ ✓

(E) 稀 $H_2SO_4$：$H^+$ 比水易還原 → 陰極生 $H_2$ ✓

Q2. 法拉第計算

以 $3A$ 電流電解 $CuSO_4(aq)$，經過 $3 \times 10^3$ 秒後，
(a) 陰極析出銅的質量為多少克？
(b) 若同時以相同電流串聯電解 $AgNO_3(aq)$，陰極析出銀的質量為多少克？

（$Cu$ 原子量 64，$Ag$ 原子量 108，$F = 96500\text{ C/mol}$）

Q4 詳解

答案：(A)(B)(D)(E)

解析：電解 $NaOH(aq)$ 相當於電解水（$2H_2O \rightarrow 2H_2 + O_2$）。

STP 下氣體總莫耳數 $= \frac{8.4}{22.4} = 0.375\text{ mol}$

依化學計量比，$H_2$ 佔 $\frac{2}{3}$，$O_2$ 佔 $\frac{1}{3}$：
$n(H_2) = 0.375 \times \frac{2}{3} = 0.25\text{ mol} \Rightarrow 0.25 \times 2 = \mathbf{0.5\text{ g}}$ (D)✓

消耗電量 $n(e^-) = n(H_2) \times 2 = 0.5\text{ mol} \Rightarrow \mathbf{0.5\text{ F}}$ (A)✓

消耗水量 $n(H_2O) = 0.25\text{ mol} \Rightarrow 0.25 \times 18 = \mathbf{4.5\text{ g}}$ (E)✓

原 $NaOH$ 質量 $= 109 \times 10\% = \mathbf{10.9\text{ g}}$ (C)✕，並非10克

電解後總重量 $= 109 - 4.5 = 104.5\text{ g}$
電解後濃度 $= \frac{10.9}{104.5} \times 100\% \approx \mathbf{10.4\%}$ (B)✓

Q3. 電量與析出質量

於電解實驗中，某生於 $2.0M$ 的硫酸銅溶液，插入二純銅片分別做為正、負極，經過一段時間的直流電後，其中一電極析出了物質 $1.6$ 克。試問所通過的電量可能為多少庫侖？
（原子量：$O=16$，$S=32$，$Cu=64$）

(A) $9650$
(B) $4825$
(C) $2412$
(D) $1206$

Q3 詳解

答案：(B)

解析：以純銅電極電解硫酸銅溶液，為銅的電解精鍊。

  • 陽極：$Cu \rightarrow Cu^{2+} + 2e^-$
  • 陰極：$Cu^{2+} + 2e^- \rightarrow Cu$

析出物質為銅（$Cu$），質量 $W = 1.6\text{ g}$

莫耳數 $n(Cu) = \frac{1.6}{64} = 0.025\text{ mol}$

轉移電子莫耳數 $n(e^-) = 0.025 \times 2 = 0.05\text{ mol}$

所需電量 $Q = 0.05 \times 96500 = \mathbf{4825\text{ C}}$
