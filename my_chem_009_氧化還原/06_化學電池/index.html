化學電池的原理

什麼是電池？

電池是利用自發性的氧化還原反應，將化學能轉換為電能的裝置。

陽極 (Anode) / 負極 (－)

  • 發生氧化反應（失去電子）。
  • 電子由陽極流出。
  • 常為活性較大、易失去電子的金屬（如：鋅、鉛）。

陰極 (Cathode) / 正極 (＋)

  • 發生還原反應（得到電子）。
  • 電子流入陰極。
  • 常為活性較小或惰性電極搭配強氧化劑。

電池分類

一次電池

無法充電，反應不可逆。例如：乾電池、鹼性電池。

二次電池

可以充電重複使用，反應可逆。例如：鉛蓄電池、鋰離子電池。

乾電池 (勒克朗舍電池)

基本構造與反應

  • 陽極(－)： 鋅筒 ($Zn$)
  • 陰極(＋)： 碳棒(石墨) 與 二氧化錳 ($MnO_2$)
  • 電解液： $NH_4Cl$ (酸性糊狀物) + $ZnCl_2$
陽極：$Zn \rightarrow Zn^{2+} + 2e^-$
陰極：$2NH_4^+ + 2e^- \rightarrow H_2 + 2NH_3$
全反應：$Zn + 2NH_4^+ + 2MnO_2 \rightarrow Zn^{2+} + Mn_2O_3 + H_2O + 2NH_3$

特點與化學作用

  • 極化： 陰極產生 $H_2(g)$ 附著碳棒妨礙反應。
  • 去極劑： 利用 $MnO_2$ 氧化除去氫氣：
    $H_2 + 2MnO_2 \rightarrow H_2O + Mn_2O_3$
  • $ZnCl_2$ 功用： 吸收 $NH_3$ 形成錯離子 $Zn(NH_3)_2^{2+}$，並依據 $\Delta T_f = K_f \cdot C_m \cdot i$ 降低冰點，維持電壓穩定。

內部構造與放電動畫

鹼性電池

基本構造 (一次電池)

為傳統乾電池的改良版，主要差在電解液改為鹼性。

  • 陽極(－)： 鋅 ($Zn$)
  • 陰極(＋)： 二氧化錳 ($MnO_2$)，以碳棒為電極。
  • 電解液： 氫氧化鉀 ($KOH$) (鹼性)
  • 電壓： 約 1.54 V

反應式

陽極：$Zn + 2OH^- \rightarrow ZnO + H_2O + 2e^-$

陰極：$2MnO_2 + H_2O + 2e^- \rightarrow Mn_2O_3 + 2OH^-$

全反應：$Zn + 2MnO_2 \rightarrow ZnO + Mn_2O_3$

優點 (與碳鋅電池比較)

  • 電壓穩定： 由於放電時 $KOH$ 濃度幾乎不變，因此電壓維持平穩，適合大耗電量設備。
  • 壽命更長： 內部電阻小，容量比普通乾電池大數倍。
  • 不漏電、耐寒佳： 鹼性液體不易腐蝕鋅外殼。
  • 尺寸規格與氧化劑、還原劑皆與乾電池相同。

鉛蓄電池 (二次電池)

放電反應 (自發性)

全反應：$Pb_{(s)} + PbO_{2(s)} + 2H_2SO_{4(aq)} \rightarrow 2PbSO_{4(s)} + 2H_2O_{(l)}$
  • 放電時，兩極皆生成白色的硫酸鉛 ($PbSO_4$)。
  • 電解液變淡： 消耗 $H_2SO_4$ 生成水，密度與濃度下降。

每轉移 2 莫耳電子時：

  • 電極：
    • 陽極 $Pb \rightarrow PbSO_4$ (結合 $SO_4^{2-}$)，增重 96 公克
    • 陰極 $PbO_2 \rightarrow PbSO_4$ (相當於結合 $SO_2$)，增重 64 公克
    • 兩極總共增重 160g
  • 電解液：
    • 減少了 2 mol $H_2SO_4$ ($98 \times 2 = 196g$)
    • 增加了 2 mol $H_2O$ ($18 \times 2 = 36g$)
    • 電解液總共損失 160g
  • 放電時，硫酸溶液比重變小，由比重的變化量可了解放電情形。
  • （當電解液的濃度降至 14.7% 時，就必須充電）

充電反應 (需直流電)

全反應：$2PbSO_{4(s)} + 2H_2O_{(l)} \rightarrow Pb_{(s)} + PbO_{2(s)} + 2H_2SO_{4(aq)}$
  • 強制電流逆向流入，兩極的 $PbSO_4$ 恢復為 $Pb$ 和 $PbO_2$。
  • 電解液生成 $H_2SO_4$，濃度上升。

基本構造

  • 陽極(－)： 鉛 ($Pb$)
  • 陰極(＋)： 二氧化鉛 ($PbO_2$)
  • 電解液： 稀硫酸 ($H_2SO_4$)
  • 電壓： 單槽約 2.0 V

其他常見電池

氧化銀電池 (水銀電池替代品)

體積小，電壓穩定，常做為手錶、計算機的鈕扣電池。

  • 陽極(－)：鋅 ($Zn$)
  • 陰極(＋)：氧化銀 ($Ag_2O$)
  • 電解液：$KOH$ 或 $NaOH$ 鹼性溶液
全反應：$Zn + Ag_2O + H_2O \rightarrow Zn(OH)_2 + 2Ag$

鎳鎘與鎳氫電池 (二次電池)

鎳鎘電池 (Ni-Cd)： 有記憶效應，且含重金屬鎘，會汙染環境，已漸淘汰。

  • 陽極(－)：鎘 ($Cd$)
  • 陰極(＋)：氫氧化氧鎳 ($NiO(OH)$)

鎳氫電池 (Ni-MH)： 以儲氫合金取代有毒的鎘，容量更高，無明顯記憶效應，環保且普及。

  • 陽極(－)：儲氫合金 ($MH$)
  • 陰極(＋)：氫氧化氧鎳 ($NiO(OH)$)

鋰電池系列

鋰電池 (一次電池)

鋰是電位最低、最輕的金屬，因此電壓高（約3V）、能量密度極大。

  • 陽極： 鋰金屬。
  • 陰極： 常用 $MnO_2$ 或 $SOCl_2$。
  • 特點： 鋰遇到水會產生激烈反應，故必須使用非水溶劑（有機溶劑）作為電解液。
  • 壽命極長，常用於主機板 CMOS 或起搏器。

鋰離子電池 (Li-ion)

目前最廣泛使用的二次電池（手機、筆電）。

  • 陽極： 嵌有鋰的石墨 ($Li_xC_6$)。
  • 陰極： 鋰鈷氧化物 ($LiCoO_2$) 等。
  • 原理： 充放電過程中，鋰離子 ($Li^+$) 在兩極的層狀結構中來回嵌入與脫出，被稱為「搖椅式電池」。
  • 安全度較高，不含易燃的純鋰金屬。

鋰聚合物電池 (Li-polymer)

鋰離子電池的改良升級版。

  • 電解質： 以高分子聚合物凝膠取代了液態有機溶劑。
  • 優點： 沒有漏液問題，安全性更高。
  • 可將電池做成非常薄，或是配合設備形狀任意塑形。
  • 目前輕薄型電子產品（平板、手機）的主要配置。

燃料電池 (Fuel Cells)

氫氧燃料電池

直接將化學能轉換為電能，轉換效率極高 (可達 80%)，且產物只有水，無汙染。

  • 陽極(－) 燃料： 氫氣 ($H_2$)
  • 陰極(＋) 氧化劑： 氧氣 ($O_2$)
  • 電解液： $KOH_{(aq)}$ (或高分子質子交換膜)
  • 電極材質： 多孔性碳棒，表面常鍍有鉑 ($Pt$) 催化劑。
(以 $KOH$ 鹼性電解液為例)
陽極： $H_2 + 2OH^- \rightarrow 2H_2O + 2e^-$
陰極： $O_2 + 2H_2O + 4e^- \rightarrow 4OH^-$
全反應： $2H_2 + O_2 \rightarrow 2H_2O$

只要持續提供氫氣與氧氣，就能不斷發電。曾應用於阿波羅太空船。

甲醇燃料電池

由於氫氣的儲存與運送較困難，科學家也開發了使用甲醇 ($CH_3OH$) 或天然氣的燃料電池。

  • 陽極(－) 燃料： 甲醇 ($CH_3OH$)
  • 陰極(＋) 氧化劑： 氧氣 ($O_2$)
(以酸性環境為例)
陽極： $CH_3OH + H_2O \rightarrow CO_2 + 6H^+ + 6e^-$
陰極： $\frac{3}{2}O_2 + 6H^+ + 6e^- \rightarrow 3H_2O$
全反應： $CH_3OH + \frac{3}{2}O_2 \rightarrow CO_2 + 2H_2O$
(亦可將係數同乘2：$2CH_3OH + 3O_2 \rightarrow 2CO_2 + 4H_2O$)

優缺點： 燃料容易取得且安全，但在反應過程中依然會產生些許二氧化碳排放，且鉑催化劑成本高昂。

光電池 (補充) & 展望總結

氯化銀光電池 (大考補充)

光電池是利用光能直接驅動電子流動，產生電壓的裝置。組成如下圖：

構造： 左側半電池裝有 $1M$ $KCl$ 及鑲有 $AgCl$ 的銀棒；右側裝有 $CuCl$ 及白金絲 ($Pt$)。
原理： 受光照射時，$AgCl$ 轉變成 $Ag$ 與 $Cl$。氯原子會暫時吸附在氯化銀上 ($Cl_{(AgCl)}$)，成為極強的氧化劑。移去光源則回復初始狀態。

已知還原半反應：
$AgCl_{(s)} + e^- \rightarrow Ag_{(s)} + Cl^-_{(aq)}$ $E^\circ = 0.22V$
$Cu^{2+}_{(aq)} + e^- \rightarrow Cu^+_{(aq)}$ $E^\circ = 0.15V$
$Cl_{(AgCl)} + e^- \rightarrow Cl^-_{(aq)}$ $E^\circ = 3.80V$
$Cu^+_{(aq)} + e^- \rightarrow Cu_{(s)}$ $E^\circ = 0.52V$
$Ag^+_{(aq)} + e^- \rightarrow Ag_{(s)}$ $E^\circ = 0.79V$
陰極 (Ag棒)： $Cl_{(AgCl)}$ 發生的還原反應驅動了電池。
陽極 (Pt絲)： $Cu^+$ 則被迫發生氧化反應 ($Cu^+ \rightarrow Cu^{2+} + e^-$)。

二氧化鈦奈米光電池 (DSSC) 原理：

又稱「染料敏化太陽能電池」，利用染料吸收光能，再由奈米 $TiO_2$ 傳遞電子：

  • 光激發： 染料($S$)受光躍遷為激發態:
    $S + 光能 \rightarrow S^*$
  • 注電子： 激發態染料注入 $TiO_2$:
    $S^* \rightarrow S^+ + e^-$
  • 染還原： 電解液還原染料:
    $2S^+ + 3I^- \rightarrow 2S + I_3^-$
  • 液再生： 電子在陰極還原電解液:
    $I_3^- + 2e^- \rightarrow 3I^-$

優點：製造成本低、可透光或半透明、具可撓性，適合結合大樓玻璃帷幕（BIPV）。

總結與展望

不同的電池利用不同的氧化還原半反應，為現代科技提供了穩定的動力來源。從早期的碳鋅電池，到強大的鉛蓄電池，再到輕巧的鋰聚合物與純淨的燃料電池、以及新世代的光電池。電池技術的進步正持續推動人類生活前進！
