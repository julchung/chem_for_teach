Rule 01

氧化數的定義

氧化數是為了便於計算電子轉移而「假定」的電荷數，並不代表真實電荷。

單原子離子 氧化數 = 離子價數 例：Na+ (+1), Cl- (-1)
Rule 02

電負度 (Electronegativity)

原子吸引共用電子的能力。電負度愈大，氧化數愈傾向為負值。

氟 ( F )   =   4.0
氧 ( O )   =   3.5
氮 ( N )   =   3.0
氯 ( Cl ) =   3.0
週期表趨勢：右上角電負度最高，左下角最低。
Rule 03

恆定規則 (優先順序高)

  • 單質 (如 O2, Fe)：恆為0
  • 氟 ( F )：恆為-1
  • 1A 族 (鹼金屬)：恆為+1
  • 2A 族 (鹼土金屬)：恆為+2
  • 鋁 ( Al )：恆為+3
Rule 04

氫 (H) 與 氧 (O) 的例外

氫 (H)

  • 一般：+1
  • 金屬氫化物：-1 (如 NaH, CaH2)

氧 (O)

  • 一般：-2
  • 過氧化物：-1 (如 H2O2)
  • 超氧化物：-1/2 (如 KO2)
  • 與 F 結合：為正值 (如 OF2 為 +2)
Rule 05

Rule 07

平均氧化數與過渡元素

若計算結果為分數，代表該元素在結構中有兩種以上的氧化數狀態。

鉛丹 (Pb3O4)

平均鉛(Pb)氧化數計算：
令 Pb 的平均氧化數為 x
3x + (-2)×4 = 0
3x = 8   ⇒   x = +8/3
實際上 Pb3O4 是由兩種氧化態的鉛組成：

2 個 Pb2+ (氧化數 +2)
1 個 Pb4+ (氧化數 +4)

平均 = [2×(+2) + 1×(+4)] ÷ 3 = +8/3

硫代硫酸根離子 (S2O32-)

平均硫(S)氧化數計算：
令 S 的平均氧化數為 x
2x + (-2)×3 = -2
2x = 4   ⇒   x = +2

Rule 08

分配原則：共用電子對完全歸屬於電負度較大的原子。若兩原子電負度相同（如 C-C），則平均平分。
