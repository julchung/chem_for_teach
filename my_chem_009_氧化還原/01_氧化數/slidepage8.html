9-1 氧化數 · Rule 08

🌿 有機結構碳原子個別氧化數

Individual Carbon Oxidation States in Organic Compounds
📐 有機碳原子氧化數分配法則
核心概念：
有機物中每個碳原子的化學環境不同。計算個別碳氧化數時，以碳原子的 4 個價電子為基準： \[\text{C 氧化數} = 4 - (\text{該 C 分配得到的所有共用電子數})\]
鍵結對象 電負度比較 電子分配 對 C 氧化數貢獻
\(\text{C - H}\) \(\text{C (2.5)} > \text{H (2.1)}\) 2 電子全歸 C -1
\(\text{C - C}\) \(\text{C (2.5)} = \text{C (2.5)}\) 雙方均分 1 電子 0
\(\text{C - O / C - N}\) \(\text{O (3.5)} > \text{C (2.5)}\) 電子全歸 O 或 N +1 (每單鍵)
\(\text{C = O}\) \(\text{O (3.5)} > \text{C (2.5)}\) 4 電子全歸 O +2
⚡ 速算心算法門：
一個碳原子的氧化數 = (接 O、N、鹵素之鍵數) - (接 H 之鍵數)！
🧪 經典化合物個別碳氧化數實例

醋酸 / 乙酸 (\(\text{CH}_3\text{COOH}\))

• 甲基碳 (\(\text{-CH}_3\))：
  接 3 個 H（貢獻 -3）、接 1 個 C（貢獻 0）
  👉 \(\text{C}_1 = \mathbf{-3}\)
• 羧基碳 (\(\text{-COOH}\))：
  接 1 個 \(\text{=O}\)（貢獻 +2）、接 1 個 \(\text{-OH}\)（貢獻 +1）、接 1 個 C（貢獻 0）
  👉 \(\text{C}_2 = (+2) + (+1) = \mathbf{+3}\)
• 分子平均碳氧化數：\(\frac{-3 + 3}{2} = \mathbf{0}\)！

3-羥基丙酸 (\(\text{HO-CH}_2\text{-CH}_2\text{-COOH}\))

• \(\text{C}_3\) (\(\text{-CH}_2\text{OH}\))：接 2 個 H (-2)、1 個 O (+1)、1 個 C (0) → \(\mathbf{-1}\)
• \(\text{C}_2\) (\(\text{-CH}_2\text{-}\))：接 2 個 H (-2)、2 個 C (0) → \(\mathbf{-2}\)
• \(\text{C}_1\) (\(\text{-COOH}\))：接 1 個 =O (+2)、1 個 -OH (+1) → \(\mathbf{+3}\)
• 平均碳氧化數：\(\frac{-1 + (-2) + (+3)}{3} = \mathbf{0}\)
