9-1 氧化數 · Rule 01

🎯 氧化數的本質與基本定義

Oxidation Number Definition & Monoatomic Ions
📖 核心定義與基本概念
氧化數 (Oxidation Number, ON)：
為便於追蹤與計算化學反應中電子轉移，依照「化學鍵中電子完全歸給電負度較大原子」之假定所指派的形式電荷數。
🔹 單原子離子 (Monoatomic Ions)

單原子離子的氧化數恆等於該離子真實所帶之電荷數（價數）。

\(\text{Na}^+\) → +1
\(\text{Ca}^{2+}\) → +2
\(\text{Al}^{3+}\) → +3
\(\text{Cl}^-\) → -1
\(\text{O}^{2-}\) → -2
\(\text{Fe}^{3+}\) → +3
🔹 元素態單質 (Elemental Substances)

任何未與其他元素結合之自由單質，其氧化數恆為 0。

\(\text{O}_2\) → 0
\(\text{N}_2\) → 0
\(\text{P}_4\) → 0
\(\text{S}_8\) → 0
\(\text{Fe}_{(s)}\) → 0
⚖️ 觀念辨析：氧化數 vs 真實電荷
比較項目 氧化數 (Oxidation State) 形式電荷 (Formal Charge)
鍵結電子分配 完全歸屬於電負度較大的原子 共用共價電子完全均分 (1/2)
用途目的 追蹤氧化還原、電子得失 預測路易斯結構的合理性
書寫規範 符號在前或在後，例：\(+2, -1\) 帶圈記號或正負數字
💡 觀念即時考：

在共價分子 \(\text{HCl}\) 中，\(\text{H}\) 和 \(\text{Cl}\) 原子的氧化數分別為何？這是真實電荷嗎？

✔ 解析：\(\text{Cl}\) 的電負度 (3.0) 大於 \(\text{H}\) (2.1)，假定共用電子對全歸 \(\text{Cl}\)，故 \(\text{H}\) 為 +1，\(\text{Cl}\) 為 -1。
注意：\(\text{HCl}\) 為極性共價鍵，並非完全電離，因此這不是真實電荷，而是極化假定下的「氧化數」！
