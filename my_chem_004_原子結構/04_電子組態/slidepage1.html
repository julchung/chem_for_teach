4-4 電子組態

奧夫堡規則 (Aufbau Principle)

構築原則 · 低能階優先填寫 · $(n+l)$ 能量判定
📖 原理定義與 $(n+l)$ 規則
奧夫堡規則（Aufbau Principle，構築原則）：
電子在原子核外的基態排列時，會優先填入能量最低的可用軌域，待該軌域填滿後，再循序填入較高能量的軌域。
⚡ 軌域能量高低判斷準則 (多電子原子)：
  1. $(n + l)$ 規則：
    主量子數 $n$ 與角量子數 $l$ 之和 $(n + l)$ 愈大者，軌域能量愈高。
    例如：4s ($n+l=4+0=4$) < 3d ($n+l=3+2=5$)，故電子先填 4s 再填 3d！
  2. $(n + l)$ 相等時：
    若兩軌域之 $(n + l)$ 總和相同，則 主量子數 $n$ 愈大者，能量愈高。
    例如：2p ($2+1=3$) 與 3s ($3+0=3$)，因 $n=3 > 2$，故能量 2p < 3s。
$$1s < 2s < 2p < 3s < 3p < 4s < 3d < 4p < 5s < 4d < 5p < 6s < 4f < 5d \dots$$
