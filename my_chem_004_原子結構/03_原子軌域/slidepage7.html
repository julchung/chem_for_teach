概念 07

電子軌域能階：單電子 vs 多電子對照

單電子原子（簡併態）vs 多電子原子（屏蔽效應與 (n+l) 規則交錯）
⚛️ (一) 單電子原子體系（如 H, He⁺, Li²⁺）
關鍵原則：能階完全只由主量子數 \(n\) 決定！
同一主殼層各軌域能量完全相等（簡併態 Degenerate）： $$1s < 2s = 2p < 3s = 3p = 3d < 4s = 4p = 4d = 4f$$
⚡ (二) 多電子原子體系（受電子間排斥與屏蔽）
\((n+l)\) 能階規則：
1. \((n+l)\) 數值愈大，能階愈高。
2. 若 \((n+l)\) 相同，則 \(n\) 較大者能階較高。
➔ 能階產生分裂與交錯： $$1s < 2s < 2p < 3s < 3p < \mathbf{4s < 3d} < 4p < \mathbf{5s < 4d} < 5p$$
