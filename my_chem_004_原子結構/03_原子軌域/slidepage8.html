範例 01

不存在的軌域判斷

主量子數 \(n\) 與角量子數 \(l\) 的數值限制關係
📝 題目內容
依量子力學之量子數規定，下列何種原子軌域不存在？
(A) 2s
(B) 4f
(C) 2d
(D) 7p
💡 詳解與步驟分析
💭 點擊左下方「顯示詳解答案」按鈕即可在此處檢視完整解析
步驟一：回顧主量子數與角量子數的限制
根據量子力學：
• 主量子數 \(n\) 為正整數（\(n = 1, 2, 3, \dots\)）。
• 角量子數 \(l\) 的取值範圍為 \(0, 1, 2, \dots, (n-1)\)，即 \(l\) 必須嚴格小於 \(n\)（\(l < n\)）。
步驟二：逐一檢驗各選項之 \((n, l)\) 組合
• (A) 2s 軌域：\(n = 2,\ l = 0\)。因 \(0 < 2\)，合乎規則，軌域存在。
• (B) 4f 軌域：\(n = 4,\ l = 3\)。因 \(3 < 4\)，合乎規則，軌域存在。
• (C) 2d 軌域：\(n = 2,\ l = 2\)。此時 \(l = n\)，違反 \(l \le n-1\) 之限制，故 2d 軌域絕不存在！
• (D) 7p 軌域：\(n = 7,\ l = 1\)。因 \(1 < 7\)，合乎規則，軌域存在。
🎯 正確答案：(C) 2d
