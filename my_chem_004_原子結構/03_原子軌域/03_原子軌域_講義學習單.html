一、現代量子力學原子模型與電子軌域核心概念 波函數與量子數體系

⚛️ 1. 波動力學觀點、測不準原理與電子軌域本質
• 電子軌道觀點之破除：依據海森堡（Heisenberg）測不準原理，微觀電子具有波粒二象性，無法同時精確測知其在空間中的「精準位置」與「運動量（速度）」，因此電子在核外絕非沿著如行星運行的固定幾何軌道（Orbit）運動。
• 薛丁格波函數與機率密度：薛丁格（Schrödinger）波動方程式解出的波函數 $\psi$ 代表電子的量子狀態，而波函數平方 $|\psi|^2$ 代表電子在原子核外某空間點單位體積內出現的機率密度（Probability Density）。
• 電子雲（Electron Cloud）與軌域（Orbital）：以點的疏密程度象徵機率高低所繪製出的三維空間機率分佈稱為「電子雲」。化學上將電子出現機率累積達 90%（或 95%） 的邊界表面所包絡出的空間區域，正式定義為該電子的原子軌域（Atomic Orbital）。

⚡ 3. 描述「一個軌域」與「一個電子狀態」之量子數差別
• 描述一個原子軌域（空間波函數 $\psi$）：需要 3 個量子數 $(n, l, m_l)$，例如 $(2, 1, 0)$ 代表 $2p$ 副殼層中沿特定軸向的某一個 $p$ 軌域。
• 描述一個電子的完整物理狀態：需要 4 個量子數 $(n, l, m_l, m_s)$，包含空間軌域分佈與其自身自旋方向。
• 包立不相容原理預告：同一原子中，絕不可能存在兩個量子數完全相同的電子；因此任一指定軌域 $(n, l, m_l)$ 最多只能容納 2 個自旋相反（$m_s = \pm\frac{1}{2}$）的電子。

二、原子軌域形狀、空間伸展方向與能階高低對照 幾何對稱與能階規則

🔮 1. 各副殼層軌域之幾何形狀、空間伸展與對稱特徵
• s 軌域（$l=0$）：呈完全的球形對稱（Spherical Symmetry），無空間方向性（$m_l=0$，每層僅 1 個 s 軌域）。電子在距離原子核等距離 $r$ 的任一點出現機率密度完全相同。主量子數愈大，球體半徑愈大（$1s < 2s < 3s$）。
• p 軌域（$l=1$）：呈雙瓣啞鈴形（Dumbbell-shaped），具有明確方向性。磁量子數 $m_l=-1, 0, +1$ 對應於三維坐標軸之 $p_x, p_y, p_z$ 三個相互垂直的軌域。穿過原子核存在一個電子出現機率為零的節面（Nodal Plane）（如 $p_x$ 之節面為 $yz$ 平面）。
• d 軌域（$l=2$）：共包含 5 個簡併軌域（$m_l=-2, -1, 0, +1, +2$）。其中 4 個呈四葉草花瓣形（$d_{xy}, d_{yz}, d_{zx}$ 瓣葉位於兩坐標軸夾角平分線上，$d_{x^2-y^2}$ 瓣葉精準沿 $x, y$ 軸）；1 個呈啞鈴形中央環繞甜甜圈環形（$d_{z^2}$，沿 $z$ 軸）。
• f 軌域（$l=3$）：空間構型更加複雜（多呈八葉形），共包含 7 個軌域（$m_l=-3\dots+3$），自 $n=4$ 起始出現。
📊 2. 電子殼層、副殼層、軌域總數與最大電子容量之數學規律
• 第 $n$ 主殼層規律：包含 $n$ 個副殼層；包含 $n^2$ 個軌域；最多可容納 $2n^2$ 個電子。
• 第 $l$ 副殼層規律：包含 $(2l+1)$ 個軌域；最多可容納 $2(2l+1) = (4l+2)$ 個電子。
主殼層 ($n$) 主層代號 所含副殼層種類 ($l$) 各副殼層軌域數 ($2l+1$) 該主層軌域總數 ($n^2$) 該主層最大電子容量 ($2n^2$)

$n=2$ L $2s, 2p$ ($l=0, 1$) 1 + 3 $2^2 = 4$ $2 \times 2^2 = 8$

⚡ 3. 軌域能階高低關鍵比較：單電子體系 vs 多電子體系
• 單電子原子體系（如 $\text{H}, \text{He}^+, \text{Li}^{2+}$）：無電子間之靜電排斥作用，能階完全僅由主量子數 $n$ 決定！同一主殼層中所有軌域能量完全相等（稱為簡併軌域 Degenerate Orbitals）： $$1s < 2s = 2p < 3s = 3p = 3d < 4s = 4p = 4d = 4f$$ • 多電子原子體系（原子序 $Z \ge 2$）：受內層電子「屏蔽效應（Shielding）」與各軌域「穿透效應（Penetration）」影響，同層能階發生分裂（$ns < np < nd < nf$）。能階順序依 $(n+l)$ 規則判定： $$\text{1. } (n+l) \text{ 總和愈大者，能階愈高；}\quad \text{2. 若 } (n+l) \text{ 相同，則主量子數 } n \text{ 較大者能階較高。}$$ $$\text{能階高低排列：} 1s < 2s < 2p < 3s < 3p < \mathbf{4s < 3d} < 4p < \mathbf{5s < 4d} < 5p < \mathbf{6s < 4f < 5d} \dots$$
