3-1 物質三態 · 範例 5：相圖加壓路徑分析

📋 範例 5

已知某物質在三相點的溫度為 $T_t$，臨界溫度為 $T_c$（$T_t < T_c$）。

將此物質在溫度 $T_t < T < T_c$ 時逐漸加壓，該物質的狀態變化為？

  • (A) 氣態 → 固態
  • (B) 氣態 → 液態
  • (C) 固態 → 液態 → 氣態
  • (D) 液態 → 固態 → 氣態
解答：(B)
分析路徑：
溫度 $T_t < T < T_c$：高於三相點溫度（有液態存在的可能），但低於臨界溫度（加壓可液化）。
起始（低壓）：
在此溫度且低壓下，位於氣液共存曲線下方→ 為氣態。
加壓過程：
垂直向上移動，壓力達到氣液共存曲線（沸點曲線），氣體開始液化 → 液態。
繼續加壓進入液態區域（若未超過臨界溫度，仍可維持液態）。

∴ 狀態變化為：氣態 → 液態，選 (B)。
