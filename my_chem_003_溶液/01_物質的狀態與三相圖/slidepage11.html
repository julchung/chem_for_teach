3-1 物質三態 · 範例 5：相圖等溫加壓動態路徑分析

📋 範例 5 · 相圖動態路徑推演

已知某純物質在三相點的溫度為 $T_t$，臨界溫度為 $T_c$（其中 $T_t < T_c$）。

將此純物質恆溫保持在 $T_t < T < T_c$ 的條件下，自極低壓環境開始逐漸增大外界壓力，則該物質歷經的相態變化為何？

  • (A) 氣態 → 固態
  • (B) 氣態 → 液態✓ 正確答案
  • (C) 固態 → 液態 → 氣態
  • (D) 液態 → 固態 → 氣態
📈 相圖等溫加壓路徑軌跡分析 垂直向上加壓軌跡
相圖坐標定位：
溫度保持在 $T_t < T < T_c$：此溫度介於三相點與臨界點之間，在相圖上呈現一條穿過「氣相區與液相區」的垂直等溫線。
起始狀態（極低外壓）：
在此固定溫度且壓力極低時，位於氣液平衡線（蒸氣壓曲線）下方的大體積低壓區 → 呈現 氣態。
持續加壓過程（垂直向上移動）：
外壓升高至氣液共存蒸氣壓時開始凝結；越過曲線後進入壓縮液相區 → 轉為 液態。

🎯 狀態變化結論：氣態 → 液態，故選 (B)。
