一、溶液微觀分散本質、分散系分類與廷得耳效應 核心觀念綜覽
📋 溶液定義、溶劑判別通則與微觀水合作用
•
溶液 (Solution)：由兩種或兩種以上純物質均勻混合而成之均相混合物，內部各處物理性質與化學組成均一。
•
溶質與溶劑判別通則：相態不同時，同相者為溶劑；相態相同時，量多者為溶劑；水溶液中無論水量多寡，一律視水為溶劑（如 98% 濃硫酸仍視水為溶劑）。
•
水合作用 (Hydration)：極性水分子藉由「離子-偶極力」或「氫鍵」包覆溶質粒子，破壞其晶格使其均勻分散於水中。
🔬 三大分散系（真溶液、膠體溶液、懸浮液）核心特徵嚴格對照表
分散系類別 微粒直徑 外觀透明度與穩定性 廷得耳效應與布朗運動 過濾性與實例
真溶液 < 1 nm 澄清透明，靜置永久不分層 無光徑；無明顯布朗運動 可透過去濾紙與透析膜（食鹽水）
膠體溶液 1 ~ 1000 nm 透明或均勻混濁，靜置不沉降 具明顯光柱；具劇烈布朗運動 可透過濾紙，不可透析膜（豆漿、牛奶）
懸浮液/懸濁液 > 1000 nm 不透明混濁，靜置迅速沉降分層 阻礙光線直射；重力沉降沉澱 無法透過去濾紙（泥水、石灰水）
✍️ 隨堂觀念自我檢核（溶液微觀本質與分散系特性） 自主檢核 · 課堂即時作答
1. 真溶液之分散質微粒直徑小於nm，在微觀上屬於熱力學穩定的相混合物。
2. 用雷射筆照射澱粉水溶液或豆漿可觀察到一條明亮的光柱，此微觀光散射現象稱為效應。
3. 在 98% 濃硫酸水溶液中，由於水具有高度極性與特殊溶解性，傳統化學上仍將視為溶劑。
4. 膠體粒子在顯微鏡下持續進行微觀不規則之折線運動，稱為運動，是膠體不易受重力沉降的主因。
二、固體與氣體溶解度特性、溫度影響與亨利定律 平衡與熱力學
⚖️ 固體溶解度定義、飽和狀態判斷與反應熱效應
•
溶解度 (Solubility, S)：在特定溫度下，定量溶劑所能溶解溶質的最大質量。化學上常以「每 100 g 水中溶解的溶質克數（g/100g 水）」表示。
•
飽和狀態微觀動態平衡：未飽和（溶質繼續溶解）、飽和（溶解速率 = 結晶速率）、過飽和（不穩定介穩狀態，搖晃或加入晶種立即析出）。
•
溫度對固體溶解度影響：大部分固體溶解為吸熱反應（ΔH > 0），溫度升高溶解度增大（如 KNO₃）；少數為放熱反應（ΔH < 0），溫度升高溶解度反而降低（如熟石灰 Ca(OH)₂、Ce₂(SO₄)₃）。
💨 氣體溶解度與亨利定律 (Henry's Law) 核心守則
•
定律內容：定溫下，微溶或難溶性氣體在定量液體中的溶解質量（或莫耳數），與液面上該氣體之平衡分壓成正比（數學式：m = k · P 或 S = k · P）。
•
關鍵體積特徵：在該測定壓力下所測得的溶解氣體體積維持恆定，不隨氣體分壓改變（依 V = (nRT)/P，加壓 n 倍時莫耳數亦增為 n 倍，兩者相除體積 V 恆定）。
•
適用限制條件：僅適用於難溶於水之氣體（如 O₂、N₂、H₂、He、CO）。極易溶於水且與水發生強烈反應或完全解離之氣體（如 HCl、NH₃、SO₂）絕不遵守亨利定律！
✍️ 隨堂觀念自我檢核（固體與氣體溶解度特性） 自主檢核 · 課堂即時作答
1. 化學上固體溶解度通常以每克溶劑中所能溶解溶質之最大克數來定量表示。
2. 固體物質溶解於水若為放熱反應（ΔH < 0），則當環境溫度升高時，其溶解度將會隨之。
3. 根據亨利定律，定溫定量液體中難溶氣體之溶解質量與液面上的該氣體成正比。
4. 氯化氫（HCl）與氨氣（NH₃）在水中溶解時伴隨強烈化學作用與解離，故（遵守 / 不遵守）亨利定律。
三、五大常用溶液濃度表示法、定義公式與比較 核心公式綜覽
📐 五大常用濃度表示法之物理意義與嚴格定義式（分子分母垂直排版）
濃度名稱與符號 數學定義式（垂直標準排版） 單位與基準 溫度依賴性
重量百分率 (W%) W% = W質W液 × 100% %（每 100 g 溶液） 不受溫度影響
體積莫耳濃度 (CM, M) CM = n質 (mol)V液 (L) = W質 / MwV液 (L) mol / L (M) 隨溫度改變（熱脹冷縮）
重量莫耳濃度 (Cm, m) Cm = n質 (mol)W劑 (kg) = W質 / MwW劑 (kg) mol / kg (m) 不受溫度影響（依數核心）
莫耳分率 (XA) XA = nAnA + nB + ...，Σ Xi = 1 無單位（純比例） 不受溫度影響
百萬分點 (ppm) ppm = W質W液 × 106 ≈ mg / L（水溶液） ppm (1 mg / kg) 不受溫度影響（微量基準）
🌡️ 濃度受溫度影響之唯一判據
• 判斷金律：定義式分母是否包含「體積」！
• 液體具熱脹冷縮性（升溫 V 膨脹增大 ⇒ CM 下降）。
• 質量 W 與莫耳數 n 在任何溫度下皆恆定守恆，故 W%、Cm、X、ppm 皆不受溫度改變。
⚡ 極速公式法 (W% ↔ CM 快速換算)
已知比重 d (g/cm³)、溶質分子量 Mw：
CM = 10 × d × W%Mw
口訣：「10 滴(d)水(W%)除以分子量」，大考換算最速解。
✍️ 隨堂觀念自我檢核（常用濃度表示法與比較） 自主檢核 · 課堂即時作答
1. 五大濃度表示法中，唯一會隨著環境溫度上升（受熱膨脹）而導致數值變小的是濃度。
2. 重量莫耳濃度（Cm）定義式中的分母為的公斤數，因此不隨溫度改變。
3. 某市售濃鹽酸比重 1.19，重量百分率 36.5%（HCl = 36.5），其體積莫耳濃度 CM 約為M。
4. 在微量水質檢驗中常用百萬分點表示，在稀薄水溶液中 1 ppm 約等於每公升水中含有 1溶質。
四、濃度換算假設基準法、稀釋質量守恆與溶解度曲線解析 解題樞紐法則
🔑 濃度互換「假設基準法」三大標準解題步驟
•
由 CM 出發：假設「取溶液 1.0 L = 1000 mL」⇒ 溶質莫耳數 n = CM mol；溶液總質量 W液 = 1000 × d 克；溶劑水重 = W液 - W質。
•
由 W% 出發：假設「取溶液 100 g」⇒ 溶質重 W質 = W% 克；水重 = (100 - W%) 克；溶質莫耳數 n = W% / Mw。
•
由 Cm 出發：假設「取溶劑水 1000 g = 1.0 kg」⇒ 溶質莫耳數 n = Cm mol；溶液總質量 = 1000 + n × Mw 克。
⚠️ 溶液配製、稀釋守恆與體積非加成性防雷原則
•
溶質守恆定律：加水稀釋時，溶質莫耳數與溶質質量始終保持不變（CM1V1 = CM2V2，W1P1% = W2P2%）。
•
體積非加成性防雷：濃酸加水稀釋時放熱伴隨分子間隙填充，導致體積收縮（V混 ≠ V酸 + V水）。計算所需水量時，絕不可直接體積相減，必須利用「溶液總質量守恆（水質量 = 稀溶液重 - 濃酸重）」求解！
📈 溶解度曲線圖形特徵解析三要素
•
狀態區域：溶解度曲線線上為飽和；曲線下方為未飽和；曲線上方為過飽和（介穩狀態）。
•
交點意義：兩物質溶解度曲線的交點，代表在該特定溫度下，兩物質具有完全相同的溶解度與飽和重量百分率。
•
轉折點意義：溶解度曲線若出現尖銳轉折點，代表固體晶體在此溫度發生結晶水脫去之相轉變（如芒硝 Na₂SO₄·10H₂O 在 32.4°C 轉變為無水 Na₂SO₄）。
✍️ 隨堂觀念自我檢核（濃度互換與配製稀釋關鍵） 自主檢核 · 課堂即時作答
1. 將體積莫耳濃度 CM 換算為其他濃度時，最推薦且不易出錯的萬能基準法是假設取該溶液體積為公升。
2. 濃硫酸加水稀釋時會釋放大量熱能伴隨體積收縮，計算加水量時必須依據守恆列式，不可直接體積相減。
3. 溶解度曲線圖中，曲線上方的任一點代表該溶液處於狀態，受擾動容易析出晶體。
4. 芒硝（Na₂SO₄·10H₂O）的溶解度曲線在 32.4°C 出現明顯轉折，是因為高於該溫度結晶水脫去轉變為。
