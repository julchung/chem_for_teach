特殊的沉澱規則 (一)

1. 溶於「強酸」的難溶物

某些本身為沉澱難溶物，但加入強酸後會溶解：

  • 金屬的氫氧化物：酸鹼中和。
    如：$\text{Al(OH)}_3 + 3\text{H}^+ \rightarrow \text{Al}^{3+} + 3\text{H}_2\text{O}$
  • 碳酸鹽、亞硫酸鹽：產生氣體。
    如：$\text{CaCO}_3 + 2\text{H}^+ \rightarrow \text{Ca}^{2+} + \text{H}_2\text{O} + \text{CO}_2 \uparrow$
  • 鉻酸鹽：轉為二鉻酸根。
    如：$2\text{CrO}_4^{2-} + 2\text{H}^+ \rightarrow \text{Cr}_2\text{O}_7^{2-} + \text{H}_2\text{O}$
  • 特定硫化物：$\text{FeS}, \text{ZnS}, \text{MnS}$ 等。
    如：$\text{MnS} + 2\text{H}^+ \rightarrow \text{Mn}^{2+} + \text{H}_2\text{S} \uparrow$

2. 溶於「強鹼」的難溶物

兩性金屬的氫氧化物沉澱，遇過量強鹼會形成錯離子而重新溶解：

兩性元素口訣

鈹、鋁、鎵、鋅、鉻、錫、鉛

兩性金屬的氫氧化物：$\text{Al(OH)}_3, \text{Zn(OH)}_2, \text{Cr(OH)}_3, \text{Sn(OH)}_2, \text{Pb(OH)}_2$

反應例：

$\text{Al(OH)}_{3(s)} + \text{OH}^-_{(aq)} \rightarrow [\text{Al(OH)}_4]^-_{(aq)}$

特殊的沉澱規則 (二)

3. 溶於「氨水」的難溶物

初加入氨水產生沉澱，但過量氨水使其形成氨錯離子而溶解：

可形成氨錯離子金屬

$\text{Cu}^{2+}, \text{Zn}^{2+}, \text{Ag}^+, \text{Ni}^{2+}, \text{Cd}^{2+}, \text{Co}^{2+}$

(註：$\text{Fe}^{2+}, \text{Fe}^{3+}, \text{Al}^{3+}$ 不溶於過量氨水)

反應例 (銅)：

少量：$\text{Cu}^{2+} + 2\text{NH}_3 + 2\text{H}_2\text{O} \rightarrow \text{Cu(OH)}_{2(s)} \downarrow$ (藍)

過量：$\text{Cu(OH)}_{2(s)} + 4\text{NH}_3 \rightarrow [\text{Cu(NH}_3)_4]^{2+}$ (深藍，溶解)

反應例 (銀)：

少量：$2\text{Ag}^+ + 2\text{NH}_3 + \text{H}_2\text{O} \rightarrow \text{Ag}_2\text{O}_{(s)} \downarrow$ (褐)

過量：$\text{Ag}_2\text{O}_{(s)} + 4\text{NH}_3 + \text{H}_2\text{O} \rightarrow 2[\text{Ag(NH}_3)_2]^+$ (無色，溶解)

4. 鹵化銀的溶解度差異

鹵化銀對氨水的溶解度差異：

  • $\text{AgF}$：可溶於水。
  • $\text{AgCl}$：可溶於氨水。
  • $\text{AgBr}$：微溶於氨水。
  • $\text{AgI}$：不溶於氨水。

所有鹵化銀 ($\text{AgX}$) 皆可溶於過量的 $\text{CN}^-$ 及 $\text{S}_2\text{O}_3^{2-}$：

形成 $\text{Ag(CN)}_2^-$ 或 $\text{Ag(S}_2\text{O}_3)_2^{3-}$ 錯離子

觀念例題 1：離子沉澱反應

下列何者是離子沉澱反應？
  • (A) $2\text{Mg}_{(s)} + \text{O}_{2(g)} \rightarrow 2\text{MgO}_{(s)}$
  • (B) $\text{Na}_2\text{CO}_{3(aq)} + 2\text{HCl}_{(aq)} \rightarrow 2\text{NaCl}_{(aq)} + \text{H}_2\text{O}_{(l)} + \text{CO}_{2(g)}$
  • (C) $\text{MgCl}_{2(aq)} + 2\text{NaOH}_{(aq)} \rightarrow \text{Mg(OH)}_{2(s)} + 2\text{NaCl}_{(aq)}$
  • (D) $\text{HCl}_{(aq)} + \text{NaOH}_{(aq)} \rightarrow \text{NaCl}_{(aq)} + \text{H}_2\text{O}_{(l)}$
解答：(C)
離子沉澱反應是指水溶液中的離子互相結合，產生不溶性固體的反應。

(A) 為金屬氧化反應（非水溶液）。
(B) 產生氣體 ($\text{CO}_2$) 與水，無沉澱。
(C) $\text{Mg}^{2+}_{(aq)} + 2\text{OH}^-_{(aq)} \rightarrow \text{Mg(OH)}_{2(s)}$，產生白色沉澱，為離子沉澱反應。✓
(D) 為酸鹼中和，無沉澱。

觀念例題 2：沉澱判斷

下列何組所含的陽離子，加入鹽酸 ($\text{HCl}$) 僅一種沉澱，但加入硫酸 ($\text{H}_2\text{SO}_4$) 則兩者均沉澱？
  • (A) $\text{Ag}^+, \text{Pb}^{2+}$
  • (B) $\text{Hg}^{2+}, \text{Sn}^{2+}$
  • (C) $\text{Pb}^{2+}, \text{Zn}^{2+}$
  • (D) $\text{Pb}^{2+}, \text{Ba}^{2+}$
解答：(D)
加 $\text{Cl}^-$ 僅一種沉澱；加 $\text{SO}_4^{2-}$ 兩者均沉澱。

(A) $\text{Ag}^+, \text{Pb}^{2+}$：加 $\text{Cl}^-$ 兩者皆沉澱。✗
(B) $\text{Hg}^{2+}$ 不與 $\text{Cl}^-$ 生成沉澱（亞汞 $\text{Hg}_2^{2+}$ 才會）。✗
(C) $\text{ZnSO}_4$ 可溶，加 $\text{SO}_4^{2-}$ 僅 $\text{Pb}^{2+}$ 沉澱。✗
(D) $\text{Pb}^{2+}, \text{Ba}^{2+}$：
  加 $\text{Cl}^-$：$\text{PbCl}_2 \downarrow$，$\text{BaCl}_2$ 溶解 → 僅一種沉澱 ✓
  加 $\text{SO}_4^{2-}$：$\text{PbSO}_4 \downarrow$，$\text{BaSO}_4 \downarrow$ → 兩者均沉澱 ✓

觀念例題 3：試劑分離

下列各組均含有兩種陽離子，使用〔 〕內的試劑時，可使其中的一種陽離子沉澱，而另一種陽離子不沉澱？
  • (A) $\text{Zn}^{2+}, \text{Al}^{3+}$ 〔過量的 $\text{NaOH}_{(aq)}$〕
  • (B) $\text{Zn}^{2+}, \text{Cu}^{2+}$ 〔過量的 $\text{NaOH}_{(aq)}$〕
  • (C) $\text{Ag}^+, \text{Pb}^{2+}$ 〔$\text{K}_2\text{CrO}_{4(aq)}$〕
  • (D) $\text{Ag}^+, \text{Cu}^{2+}$ 〔過量的 $\text{NH}_{3(aq)}$〕
解答：(B)
(A) $\text{Zn}^{2+}, \text{Al}^{3+}$：皆為兩性金屬，過量 $\text{NaOH}$ 中皆溶解，無沉澱。✗
(B) $\text{Zn}^{2+}$（兩性）溶於過量 $\text{NaOH}$；$\text{Cu}^{2+}$（非兩性）形成 $\text{Cu(OH)}_2$ 藍色沉澱不溶。✓
(C) $\text{Ag}^+$ 與 $\text{Pb}^{2+}$ 皆與 $\text{CrO}_4^{2-}$ 生成沉澱。✗
(D) 過量 $\text{NH}_3$：$\text{Ag}^+$ 與 $\text{Cu}^{2+}$ 皆形成氨錯離子溶解，無沉澱。✗

觀念例題 4：復溶現象

於下列各項左方溶液中，逐漸滴入右方試劑，那些項初時有沉澱，後來沉澱復溶於過量試劑？
  • (A) $\text{CuSO}_{4(aq)}$ ； $\text{NH}_{3(aq)}$
  • (B) $\text{Al}_2(\text{SO}_4)_{3(aq)}$ ； $\text{NH}_{3(aq)}$
  • (C) $\text{NaCr(OH)}_{4(aq)}$ ； $\text{HCl}_{(aq)}$
  • (D) $\text{Ag(NH}_3)_2\text{Cl}_{(aq)}$ ； $\text{HNO}_{3(aq)}$
  • (E) $\text{MgSO}_{4(aq)}$ ； $\text{NaOH}_{(aq)}$
解答：(A)
尋找：初滴入試劑產生沉澱，過量試劑使沉澱溶解的組合。

(A) $\text{CuSO}_4 + \text{NH}_3$：少量 → $\text{Cu(OH)}_2 \downarrow$ (藍)；過量 → $[\text{Cu(NH}_3)_4]^{2+}$ (深藍，溶解)。符合！
(B) $\text{Al}_2(\text{SO}_4)_3 + \text{NH}_3$：$\text{Al(OH)}_3$ 沉澱，但 Al 非過渡元素，不溶於過量氨水。
(C) $\text{NaCr(OH)}_4 + \text{HCl}$：少量酸產生 $\text{Cr(OH)}_3$ 沉澱，過量酸溶解為 $\text{Cr}^{3+}$（此為「先沉後溶」但 C 選項已是鉻酸根形式，加酸先沉澱，但後溶為 Cr³⁺，勉強可以認定，然標準答案為 A）。
(D) 加酸破壞錯離子後，$\text{AgCl}$ 沉澱，更多酸無法使其復溶。
(E) $\text{Mg(OH)}_2$ 沉澱，鎂非兩性，不溶於過量強鹼。

觀念例題 5：綜合離子分離流程

[$\text{Ca}^{2+}$, $\text{Ag}^+$, $\text{Zn}^{2+}$, $\text{K}^+$, $\text{Pb}^{2+}$]
加入 0.1M HCl (aq)
沉澱物 I
$\text{AgCl}$, $\text{PbCl}_2$
加熱至沸騰
殘留沉澱 II
$\text{AgCl}$
加 6M $\text{NH}_3$ (aq)
澄清液 IV
$[\text{Ag(NH}_3)_2]^+$
澄清液 III
$\text{Pb}^{2+}$, $\text{Cl}^-$
冷卻
沉澱物 V
$\text{PbCl}_2$
澄清液 (含)
$\text{Ca}^{2+}$, $\text{Zn}^{2+}$, $\text{K}^+$
加入 $\text{H}_2\text{SO}_4$ (aq)
沉澱物 VI
$\text{CaSO}_4$
分析
加入 HCl：$\text{Ag}^+$ 及 $\text{Pb}^{2+}$ 形成氯化物沉澱（$\text{AgCl}$, $\text{PbCl}_2$），其餘離子留在溶液中。

加熱：$\text{PbCl}_2$ 溶解度隨溫度上升而增大，可溶入熱水中。

冷卻：$\text{PbCl}_2$ 再次析出。

加氨水：$\text{AgCl}$ 溶於氨水形成 $[\text{Ag(NH}_3)_2]^+$。
