### 【Q1】密閉容器蒸氣壓平衡 · 溶劑遷移
- **來源**：`quiz.html` 原題 Q2
- **題幹**：將(甲)純水、(乙)$0.1\text{ m}$ 蔗糖水、(丙)$0.5\text{ m}$ 蔗糖水、(丁)$1.0\text{ m}$ 蔗糖水等四杯液面等高的液體，共置於一真空密閉容器中，同溫下蒸氣壓達平衡後，何者的**液面最高**？
- **選項**：
  - A. 甲
  - B. 乙
  - C. 丙
  - D. 丁
- **正確答案**：**D**
- **詳細解析**：
  1. **蒸氣壓與遷移方向：**在同溫密閉容器中，純水的蒸氣壓最高（$P_A^\circ$），蔗糖水溶液的蒸氣壓隨濃度增加而下降（$P = X_{水} P_A^\circ$）。水蒸氣會自蒸氣壓高處不斷揮發、冷凝流入蒸氣壓低處。
  2. **動態平衡條件：**達最終平衡時，空間內所有液面上方之水蒸氣壓必須相等。因蔗糖不揮發，純水（甲）蒸氣壓永遠高於溶液，純水將**完全蒸乾**（甲體積變為 0）。
  3. **乙、丙、丁最終濃度必相等：**蒸氣壓相等意謂著乙、丙、丁三杯糖水在平衡時的重量莫耳濃度相等。丁杯起始含有最多的蔗糖溶質莫耳數，故平衡時必須吸收最多的水方能稀釋至與其他杯濃度相同，**丁的最終體積與液面最高**！

### 【Q2】揮發性雙成分理想溶液 · 純質蒸氣壓推求
- **來源**：`quiz.html` 原題 Q3
- **題幹**：兩揮發性液態純質甲和乙混合可形成理想溶液。若 $50^\circ\text{C}$ 時，測得溶液的總蒸氣壓為 $400\text{ mmHg}$，而在蒸氣中甲的莫耳分率為 $0.25$，在溶液中甲的莫耳分率為 $0.40$，則 $50^\circ\text{C}$ 時下列敘述何者**正確**？
- **選項**：
  - A. 純甲的蒸氣壓為 $100\text{ mmHg}$
  - B. 純甲的蒸氣壓為 $200\text{ mmHg}$
  - C. 純乙的蒸氣壓為 $300\text{ mmHg}$
  - D. 純乙的蒸氣壓為 $500\text{ mmHg}$
- **正確答案**：**D**
- **詳細解析**：
  1. **依道耳吞分壓定律求氣相分壓：**
     - $P_{total} = 400\text{ mmHg}$。
     - 氣相中甲分壓 $P_A = P_{total} \times Y_A = 400 \times 0.25 = 100\text{ mmHg}$。
     - 氣相中乙分壓 $P_B = P_{total} - P_A = 400 - 100 = 300\text{ mmHg}$。
  2. **依拉午耳定律求純質飽和蒸氣壓：**
     - $P_A = X_A \cdot P^\circ_A \implies 100 = 0.40 \cdot P^\circ_A \implies P^\circ_A = 250\text{ mmHg}$。
     - $X_B = 1 - X_A = 0.60$。
     - $P_B = X_B \cdot P^\circ_B \implies 300 = 0.60 \cdot P^\circ_B \implies P^\circ_B = \dfrac{300}{0.60} = \mathbf{500\text{ mmHg}}$。
  故選項 (D) 正確。

### 【Q3】理想溶液蒸餾 · 氣液平衡組成比較
- **來源**：截圖擷取（`螢幕擷取畫面 2026-09-24 215023.png`） / `quiz.html` 原題 Q4
- **題幹**：有一理想溶液含有二成分，其莫耳分率為 $X_A$ 與 $X_B$，又知成分 A 之純蒸氣壓 $P_A^\circ$ 大於成分 B 之純蒸氣壓 $P_B^\circ$。定溫下，其蒸餾後的冷凝液（氣相冷凝）之莫耳分率分別為 $Y_A$ 與 $Y_B$，則下列關係中何者**正確**？
- **選項**：
  - A. $X_A > Y_A$ 且 $X_B > Y_B$
  - B. $X_A < Y_A$ 且 $X_B > Y_B$
  - C. $X_A > Y_A$ 且 $X_B < Y_B$
  - D. $X_A < Y_A$ 且 $X_B < Y_B$
- **正確答案**：**B**
- **詳細解析**：
  1. **氣相莫耳分率公式：**$Y_A = \dfrac{P_A}{P_{total}} = \dfrac{X_A P_A^\circ}{X_A P_A^\circ + X_B P_B^\circ}$。
  2. **易揮發成分富集原理：**已知 $P_A^\circ > P_B^\circ$，成分 A 較易揮發。拉午耳定律指出，氣相中較易揮發成分的莫耳分率必定大於液相，即 **$Y_A > X_A$（亦即 $X_A < Y_A$）**。
  3. **莫耳分率總和為 1：**因 $X_A + X_B = 1$ 且 $Y_A + Y_B = 1$；當 A 在氣相富集時，B 在氣相中的比例必相對減少，即 **$Y_B < X_B$（亦即 $X_B > Y_B$）**。
  故選 **(B)**。

### 【Q4】氣流法蒸氣壓測定 · 未知溶質分子量計算
- **來源**：截圖擷取（`螢幕擷取畫面 2026-09-24 215047.png`） / `quiz.html` 原題 Q5
- **題幹**：某不具揮發性、不易解離之溶質 $10\text{ 克}$，溶解於 $78.0\text{ 克}$ 苯中，以空氣通過此溶液，使通過的空氣充滿此溶液之飽和蒸氣壓，發現溶液之重量減少 $1.000\text{ 克}$；若同溫時，以同量空氣對純苯作同樣實驗，而純苯所減少重量為 $1.073\text{ 克}$，則此物之分子量為多大？（苯 $\text{C}_6\text{H}_6 = 78$）
- **選項**：
  - A. 128
  - B. 138
  - C. 148
  - D. 158
- **正確答案**：**B**
- **詳細解析**：
  1. **氣流飽和法原理：**定溫下相同體積空氣帶出的苯蒸氣莫耳數與飽和蒸氣壓成正比。
     $$\dfrac{P_{溶液}}{P^\circ} = \dfrac{\Delta W_{溶液}}{\Delta W_{純苯}} = \dfrac{1.000\text{ g}}{1.073\text{ g}}$$
  2. **套用拉午耳定律：**
     $$P_{溶液} = X_{苯} \cdot P^\circ \implies X_{苯} = \dfrac{1.000}{1.073}$$
  3. **莫耳數計算：**
     - 苯莫耳數 $n_{苯} = \dfrac{78.0}{78.0} = 1.00\text{ mol}$。
     - 設溶質分子量為 $M$，溶質莫耳數 $n_{溶質} = \dfrac{10}{M}$。
     $$X_{苯} = \dfrac{1.00}{1.00 + \frac{10}{M}} = \dfrac{1.000}{1.073} \implies 1.00 + \dfrac{10}{M} = 1.073 \implies \dfrac{10}{M} = 0.073$$
     $$M = \dfrac{10}{0.073} \approx \mathbf{137} \approx \mathbf{138}$$
  故選 **(B)**。

### 【Q5】理想溶液判定 · 體積可加成性與分子間力
- **來源**：截圖擷取（`螢幕擷取畫面 2026-10-07 234648.png`）
- **題幹**：純液體 A 的蒸氣壓為 $300\text{ mmHg}$，純液體 B 的蒸氣壓為 $100\text{ mmHg}$，今 A 與 B 各取 $1.0\text{ 莫耳}$ 混合形成之溶液，測得蒸氣壓為 $200\text{ mmHg}$，則此溶液形成時，下列敘述何者**正確**？
- **選項**：
  - A. 混合時分子間無作用力
  - B. 混合時分子間引力變大
  - C. 混合時吸收熱量
  - D. 混合時體積具有可加成性
- **正確答案**：**D**
- **詳細解析**：
  1. **檢驗是否遵守拉午耳定律：**
     - $X_A = \dfrac{1.0}{1.0 + 1.0} = 0.5$，$X_B = 0.5$。
     - 若為理想溶液，理論總蒸氣壓 $P = X_A P_A^\circ + X_B P_B^\circ = 0.5 \times 300 + 0.5 \times 100 = 200\text{ mmHg}$。
     - 實測蒸氣壓正好為 $200\text{ mmHg}$，與理論預測值完全吻合，因此該溶液為**理想溶液**。
  2. **理想溶液本質剖析：**
     - **分子間作用力：**液態物質分子間必然存在凡得瓦力或偶極引力，理想溶液指 A-B 引力等於 A-A 與 B-B 引力，並非「無作用力」（只有理想氣體假設無引力），故 A、B 錯誤。
     - **反應熱效應：**形成新吸引力釋放的熱量等於破壞原吸引力吸收的熱量，$\Delta H_{混} = 0$（既不吸熱也不放熱），故 C 錯誤。
     - **體積加成性：**分子間距離不變，$\Delta V_{混} = 0$，體積完全具可加成性（$V_{混} = V_A + V_B$），故 **D 正確**。

### 【Q6】密閉容器蒸氣壓平衡 · 水移動量計算
- **來源**：截圖擷取（`螢幕擷取畫面 2026-10-07 234659.png`）
- **題幹**：在 $1000\text{ 克}$ 的水中溶解 $15\text{ 克}$ 尿素（$\text{CO(NH}_2\text{)}_2$）後之溶液（A 液），與在 $500\text{ 克}$ 的水中溶解葡萄糖 $30\text{ 克}$ 所成的溶液（B 液）。將此二溶液同置於密閉容器中，使其達成蒸氣壓平衡，水由哪一溶液移至哪一溶液？共移動多少克？（尿素分子量 $= 60$，葡萄糖分子量 $= 180$）
- **選項**：
  - A. B $\to$ A，移動 $50\text{ 克}$
  - B. A $\to$ B，移動 $50\text{ 克}$
  - C. B $\to$ A，移動 $100\text{ 克}$
  - D. A $\to$ B，移動 $100\text{ 克}$
- **正確答案**：**D**
- **詳細解析**：
  1. **起始濃度與蒸氣壓：**
     - A 液（尿素）：$n_A = \dfrac{15}{60} = 0.25\text{ mol}$，水 $1.0\text{ kg} \implies C_{m,A} = 0.25\text{ m}$。
     - B 液（葡萄糖）：$n_B = \dfrac{30}{180} = \dfrac{1}{6} \approx 0.167\text{ mol}$，水 $0.5\text{ kg} \implies C_{m,B} = \dfrac{1/6}{0.5} = \dfrac{1}{3} \approx 0.333\text{ m}$。
     - 因 $C_{m,A} < C_{m,B}$，故蒸氣壓 $P_A > P_B$。水蒸氣由高蒸氣壓之 A 液揮發冷凝至低蒸氣壓之 B 液，移動方向為 **A $\to$ B**。
  2. **平衡水量分配：**
     - 達平衡時兩杯濃度必相等，水量與溶質莫耳數成正比：
       $$W_{水,A} : W_{水,B} = n_A : n_B = 0.25 : \dfrac{1}{6} = \dfrac{1}{4} : \dfrac{1}{6} = 3 : 2$$
     - 容器中總水重 $= 1000 + 500 = 1500\text{ 克}$。
     - 平衡時 A 液水重 $= 1500 \times \dfrac{3}{3 + 2} = 900\text{ 克}$。
     - 平衡時 B 液水重 $= 1500 \times \dfrac{2}{5} = 600\text{ 克}$。
     - 水移動量 $= 1000 - 900 = \mathbf{100\text{ 克}}$（由 A 移至 B）。故選 **D**。

### 【Q7】非理想溶液 · 正偏差與分子間引力
- **來源**：截圖擷取（`螢幕擷取畫面 2026-10-07 234308.png`）
- **題幹**：某混合液含 $7.36\text{ 克}$ 乙醇（分子量 $46$）及 $4.78\text{ 克}$ 氯仿（分子量 $119.5$），在 $35^\circ\text{C}$ 下測得溶液總蒸氣壓為 $190\text{ mmHg}$。已知 $35^\circ\text{C}$ 時純乙醇與純氯仿之飽和蒸氣壓依次為 $100\text{ mmHg}$ 與 $300\text{ mmHg}$。下列關於此混合溶液之敘述，何者**正確**？
- **選項**：
  - A. 若二者混合為理想溶液，則理論蒸氣壓應為 $140\text{ mmHg}$
  - B. 此混合溶液配製時為放熱反應，混合後液溫上升
  - C. 混合液中分子間的吸引力大於純物質各自分子間的引力
  - D. 此溶液實測蒸氣壓小於拉午耳定律理論值，呈現負偏差
- **正確答案**：**A**
- **詳細解析**：
  1. **莫耳數與莫耳分率計算：**
     - 乙醇莫耳數 $= \dfrac{7.36}{46} = 0.16\text{ mol}$。
     - 氯仿莫耳數 $= \dfrac{4.78}{119.5} = 0.04\text{ mol}$。
     - 總莫耳數 $= 0.20\text{ mol} \implies X_{乙醇} = 0.80$，$X_{氯仿} = 0.20$。
  2. **理想溶液理論蒸氣壓：**
     $$P_{理} = 0.80 \times 100 + 0.20 \times 300 = 80 + 60 = \mathbf{140\text{ mmHg}} \quad \text{（A 正確）}$$
  3. **正偏差非理想特性：**
     - 實測蒸氣壓 $190\text{ mmHg} > 140\text{ mmHg}$，呈現**正偏差**（故 D 錯誤）。
     - 正偏差原因：氯仿分子插入乙醇分子間，部分打斷了乙醇原有的強氫鍵，導致 A-B 分子間引力小於同種分子間引力，分子間引力**變小**（C 錯誤）。
     - 因破壞強引力需吸收熱量，混合時為**吸熱反應**（$\Delta H_{混} > 0$，液溫下降，故 B 錯誤）。

### 【Q8】苯-甲苯理想溶液相圖 · 氣液平衡組成計算
- **來源**：截圖擷取（`螢幕擷取畫面 2026-10-07 234203.png`）
- **題幹**：已知 $20^\circ\text{C}$ 純苯（$\text{C}_6\text{H}_6$）及純甲苯（$\text{C}_7\text{H}_8$）的飽和蒸氣壓依次為 $70\text{ mmHg}$ 與 $20\text{ mmHg}$，兩者混合遵守拉午耳定律。若 $20^\circ\text{C}$ 某濃度之苯-甲苯溶液與其蒸氣達平衡時，測得蒸氣中苯的莫耳分率為 $0.70$，則該溶液中苯的莫耳分率（液相莫耳分率）應為多少？
- **選項**：
  - A. 0.30
  - B. 0.40
  - C. 0.50
  - D. 0.60
- **正確答案**：**B**
- **詳細解析**：
  1. 設液相中苯莫耳分率為 $X$（則甲苯為 $1 - X$）。
  2. 由拉午耳定律：
     - $P_{苯} = 70 \cdot X$
     - $P_{甲苯} = 20 \cdot (1 - X)$
     - 溶液總壓 $P_{總} = 70X + 20(1 - X) = 50X + 20\text{ mmHg}$
  3. 由道耳吞分壓定律：
     $$Y_{苯} = \dfrac{P_{苯}}{P_{總}} = \dfrac{70X}{50X + 20} = 0.70$$
     $$70X = 0.70(50X + 20) \implies 70X = 35X + 14 \implies 35X = 14 \implies X = \mathbf{0.40}$$
  故該溶液中含苯之液相莫耳分率為 **0.40**，選 **B**。

### 【Q9】連續汽化冷凝 · 分餾蒸氣壓與莫耳分率

  - A. 溶液甲中 B 的莫耳分率為 $0.20$
  - B. 溶液甲之總蒸氣壓為 $150\text{ mmHg}$
  - C. 蒸氣乙中 B 的莫耳分率為 $0.25$
  - D. 溶液丙（冷凝液）之總蒸氣壓為 $200\text{ mmHg}$

- **詳細解析**：

     - $P_甲 = 0.90 \times 100 + 0.10 \times 300 = 90 + 30 = 120\text{ mmHg}$（B 錯誤）。
  2. **蒸氣乙之組成（氣相莫耳分率）：**
     - $Y_{B,乙} = \dfrac{P_{B,甲}}{P_甲} = \dfrac{30}{120} = \mathbf{0.25}$（**C 正確**！易揮發物質 B 比例由 0.10 大幅上升至 0.25）。
  3. **溶液丙（冷凝液）之蒸氣壓：**
     - 蒸氣乙冷凝後成為液體丙，故 $X_{B,丙} = 0.25$，$X_{A,丙} = 0.75$。
     - $P_丙 = 0.75 \times 100 + 0.25 \times 300 = 75 + 75 = \mathbf{150\text{ mmHg}}$（D 錯誤）。

### 【Q10】密閉三杯平衡 · 電解質凡特何夫因子與水重分配
- **來源**：截圖擷取（`螢幕擷取畫面 2026-10-07 234350.png`）
- **題幹**：若某溫度下水之飽和蒸氣壓為 $557\text{ mmHg}$，在一密閉容器中放置三杯不同液體：A 杯盛 $0.01\text{ mol}$ 葡萄糖 $+ 200\text{ g}$ 水；B 杯盛 $0.02\text{ mol}$ 蔗糖 $+ 300\text{ g}$ 水；C 杯盛 $0.03\text{ mol } \text{NaCl} + 400\text{ g}$ 水。同溫下蒸氣壓達平衡後，下列敘述何者**正確**？
- **選項**：
  - A. 剛置入容器時，各杯水蒸發速率大小順序為 C $>$ B $>$ A
  - B. 未達平衡前，B 杯的蒸發速率小於 C 杯
  - C. 達最終平衡時，A 杯中的水重量減少為 $100\text{ 克}$
  - D. 達最終平衡時，C 杯中水的重量變為 $300\text{ 克}$
- **正確答案**：**C**
- **詳細解析**：
  1. **起始有效粒子濃度分析：**
     - A 杯（葡萄糖，$i=1$）：$0.01\text{ mol} / 0.2\text{ kg} = 0.05\text{ m}$。
     - B 杯（蔗糖，$i=1$）：$0.02\text{ mol} / 0.3\text{ kg} \approx 0.067\text{ m}$。
     - C 杯（$\text{NaCl}$ 強電解質，$i=2$）：有效莫耳數 $= 0.03 \times 2 = 0.06\text{ mol}$，有效濃度 $= 0.06 / 0.4\text{ kg} = 0.15\text{ m}$。
  2. **蒸發速率比較：**
     - 濃度愈小者，水蒸氣壓愈大，蒸發速率愈快。因起始濃度 A $<$ B $<$ C，故蒸發速率 **A $>$ B $>$ C**（A、B 選項錯誤）。
  3. **平衡水量分配計算：**
     - 密閉容器平衡時各杯有效濃度必相等，水量分配與有效溶質莫耳數成正比：
     - 總水重 $= 200 + 300 + 400 = 900\text{ 克}$。
     - 總有效溶質莫耳數 $= 0.01 + 0.02 + 0.06 = 0.09\text{ mol}$。
     - 平衡時 A 杯水重 $= 900 \times \dfrac{0.01}{0.09} = \mathbf{100\text{ 克}}$（原 200g 減少 100g，**C 正確**）。
     - 平衡時 B 杯水重 $= 900 \times \dfrac{0.02}{0.09} = 200\text{ 克}$。
     - 平衡時 C 杯水重 $= 900 \times \dfrac{0.06}{0.09} = \mathbf{600\text{ 克}}$（原 400g 增至 600g，故 D 錯誤）。

### 【Q11】拉午耳定律微觀機制 · 蒸發與凝聚動態平衡
- **來源**：單元核心觀念（溶質分子表面覆蓋與動態平衡機制）
- **題幹**：當非揮發性、非電解質溶質溶於純溶劑中形成稀薄溶液時，溶液之蒸氣壓會低於純溶劑之蒸氣壓（拉午耳定律）。下列從微觀分子動力學角度對此現象之解釋，何者**最為正確**？
- **選項**：
  - A. 不揮發性溶質分子佔據液面部分表面積，使溶劑分子每秒蒸發逃逸數減少
  - B. 溶質分子在氣相中阻擋溶劑蒸氣分子凝結返回液面
  - C. 溶質分子加入後大幅降低了溶劑分子的平均動能
  - D. 溶質分子與溶劑分子間產生化學鍵結，使溶劑完全無法揮發
- **正確答案**：**A**
- **詳細解析**：
  1. **表面積覆蓋假說：**蒸發現象主要發生在氣液交界面。純溶劑表面 $100\%$ 為溶劑分子；溶入非揮發性溶質後，部分表面積被溶質分子佔據，導致單位時間逸出液面的溶劑分子數減少（蒸發速率降低）。
  2. **新動態平衡達成：**凝結速率與氣相中蒸氣分子分壓成正比。為使凝結速率降至與減少後的蒸發速率相等，氣相中的蒸氣分壓必須隨之下降，直至兩者速率再度相等達成動態平衡。故選 **A**。
