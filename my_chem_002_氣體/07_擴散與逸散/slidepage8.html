範例 5

溫度與分子量對運動速率的影響

進階綜合題

已知氮氣 $\text{N}_2$ 之分子量為 28，氧氣 $\text{O}_2$ 之分子量為 32：

(1) $\text{N}_2$ 在 $27^\circ\text{C}$ 時的方均根速率為 $v_1$，在 $327^\circ\text{C}$ 時的方均根速率為 $v_2$，試求 $v_1 : v_2$。

(2) 在 $27^\circ\text{C}$ 下，$\text{N}_2$ 與 $\text{O}_2$ 的方均根速率比 $v_{\text{N}_2} : v_{\text{O}_2}$ 為何？

詳細解析

正解：(1) $1 : \sqrt{2}$；(2) $2\sqrt{2} : \sqrt{7}$

⚡ (1) 同種氣體、溫度改變之速率比：
⚠️ 關鍵提醒：務必轉換為絕對溫度凱氏溫標（$\text{K}$）！
$T_1 = 27 + 273 = 300\text{ K}$
$T_2 = 327 + 273 = 600\text{ K}$
$$\frac{v_1}{v_2} = \sqrt{\frac{T_1}{T_2}} = \sqrt{\frac{300}{600}} = \sqrt{\frac{1}{2}} = \frac{1}{\sqrt{2}}$$ $$\mathbf{\therefore v_1 : v_2 = 1 : \sqrt{2}}$$
⚡ (2) 同溫、不同分子量之速率比：
在同溫 $27^\circ\text{C}$（$300\text{ K}$）下，$T$ 相等： $$\frac{v_{\text{N}_2}}{v_{\text{O}_2}} = \sqrt{\frac{M_{\text{O}_2}}{M_{\text{N}_2}}} = \sqrt{\frac{32}{28}} = \sqrt{\frac{8}{7}} = \frac{2\sqrt{2}}{\sqrt{7}}$$ $$\mathbf{\therefore v_{\text{N}_2} : v_{\text{O}_2} = 2\sqrt{2} : \sqrt{7} \approx 1.07 : 1}$$
🔍 觀念深化：
$\text{N}_2$ 分子量（28）略輕於 $\text{O}_2$（32），因此同溫下氮氣分子熱運動速率略快於氧氣。
