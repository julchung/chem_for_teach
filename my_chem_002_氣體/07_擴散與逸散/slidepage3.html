微觀假設

氣體動力論 (KMT) 基本假設

Clausius / Maxwell / Boltzmann
  • 粒子自身體積可忽略：與容器空間相比，分子如同質點。
  • 無規則熱運動：隨機直線運動，遵守牛頓力學定律。
  • 分子間無作用力：除碰撞瞬間外，彼此無吸引力或排斥力。
  • 完全彈性碰撞：碰撞器壁與彼此無動能損失（系統總動能守恆）。
  • 平均動能僅與絕對溫度成正比：$\overline{E_k} = \dfrac{3}{2}kT$。
📐 氣體壓力微觀公式推導：
• 單分子對器壁碰撞力：$F = \dfrac{\Delta p}{\Delta t} = \dfrac{mv_x^2}{L}$
• $N$ 個分子均方根速度三維空間投影（$\overline{v^2} = 3\overline{v_x^2}$）：
$$P = \frac{1}{3}\frac{Nm\overline{v^2}}{V} \implies PV = \frac{2}{3} N \left(\frac{1}{2}m\overline{v^2}\right)$$
• 與理想氣體方程式 $PV = Nk_B T$ 比對，立得：$\mathbf{\overline{E_k} = \dfrac{3}{2}kT}$！
⚠️ 理想氣體 vs 真實氣體：
在高溫、低壓時，分子間距極大且動能極高，最符合動力論假設；反之在低溫、高壓時偏離理想氣體。

⚡ 三種速率精確大小順序（必背）：
$$v_p < \overline{v} < v_{rms}$$

• 最可能速率 $v_p = \sqrt{\frac{2RT}{M}}$ (1.414)
• 平均速率 $\overline{v} = \sqrt{\frac{8RT}{\pi M}}$ (1.596)
• 方均根速率 $v_{rms} = \sqrt{\frac{3RT}{M}}$ (1.732)
