擴散與逸散

格銳目定律及其應用

擴散與逸散的概念

擴散 (Diffusion)

氣體分子因自身運動而由高濃度向低濃度擴展，最終達到均勻分布。

例如：香水味在室內傳播、氨氣擴散到空氣中。

📌 特點：

需要介質（如空氣），速率受到碰撞干擾，比逸散慢。

▼ 擴散動態演示

逸散 (Effusion)

氣體分子穿過微小孔徑進入另一空間（或真空）的過程。

例如：氣球慢慢洩氣、鈾濃縮中 UF₆ 的分離。

📌 特點：

在真空中進行，速率僅受分子量影響，格銳目定律直接適用。

▼ 逸散動態演示

格銳目定律 (Graham's Law)

定律內容

在同溫同壓下，氣體的逸散速率（$r$）與其分子量（$M$）的平方根成反比。

$r \propto \dfrac{1}{\sqrt{M}}$
$\dfrac{r_1}{r_2} = \sqrt{\dfrac{M_2}{M_1}}$

速率的多種表達方式

  • 莫耳數比：$\dfrac{n_1}{n_2}$（相同時間內）
  • 體積比：$\dfrac{V_1}{V_2}$（相同時間、同溫同壓）
  • 移動距離比：$\dfrac{L_1}{L_2}$（相同時間）
  • 時間反比：$\dfrac{t_2}{t_1}$（相同距離）

平均動能與均方根速率

相同溫度下，各氣體分子的平均動能相等：

$\overline{E_k} = \dfrac{3}{2}kT$

均方根速率（方均根速率）：

$v_{rms} = \sqrt{\dfrac{3RT}{M}}$

📌 格銳目定律的時間形式：

$\dfrac{t_1}{t_2} = \sqrt{\dfrac{M_1}{M_2}}$

（相同距離下，分子量大的需要更長時間）

氣體動力論 (Kinetic Molecular Theory)

五大基本假設 (Postulates)

  • 氣體由大量粒子組成，粒子本身體積可忽略。
  • 分子呈隨機運動，遵守牛頓力學。
  • 分子間無作用力（除碰撞瞬間外）。
  • 碰撞為完全彈性碰撞（無能量損失）。
  • 平均動能僅與絕對溫度 ($T$) 有關。

📌 理想氣體 vs 真實氣體

真實氣體在低溫高壓時偏離理想氣體行為，因分子體積與分子間引力不可忽視。

壓力公式推導

1. 單個分子碰撞器壁的力（一維）：

$F = \dfrac{\Delta p}{\Delta t} = \dfrac{mv_x^2}{L}$

2. $N$ 個分子總壓力（考慮三維 $\overline{v^2} = 3\overline{v_x^2}$）：

$P = \dfrac{1}{3}\dfrac{Nm\overline{v^2}}{V}$

3. 結合理想氣體方程式 $PV=nRT$：

$\dfrac{1}{2}m\overline{v^2} = \dfrac{3}{2}kT \implies \overline{E_k} = \dfrac{3}{2}kT$

分子速率分布曲線（$T_2 > T_1$）

從圖形讀出的重點

  • 溫度升高 → 曲線向右移動且變寬平。
  • 最可能速率 ($v_p$) 隨溫度升高而增大。
  • 曲線下面積恆等於 1（代表所有分子）。
  • 高溫時，高速分子比例明顯增多。

📌 三種速率比較：

$v_p < \overline{v} < v_{rms}$（最可能速率 < 平均速率 < 均方根速率）

例題 1 逸散速率比

在同溫同壓下，試比較下列各組氣體的逸散速率比 $r_1 : r_2$（括號內為分子量）：

  • (1) $H_2$（$M=2$）與 $O_2$（$M=32$）
  • (2) $CH_4$（$M=16$）與 $SO_2$（$M=64$）
  • (3) $N_2$（$M=28$）與 $CO_2$（$M=44$）
解答與解析：

利用格銳目定律：$\dfrac{r_1}{r_2} = \sqrt{\dfrac{M_2}{M_1}}$

(1) $H_2$ vs $O_2$：

$\dfrac{r_{H_2}}{r_{O_2}} = \sqrt{\dfrac{32}{2}} = \sqrt{16} = 4$

∴ $r_{H_2} : r_{O_2} = 4 : 1$

(2) $CH_4$ vs $SO_2$：

$\dfrac{r_{CH_4}}{r_{SO_2}} = \sqrt{\dfrac{64}{16}} = \sqrt{4} = 2$

∴ $r_{CH_4} : r_{SO_2} = 2 : 1$

(3) $N_2$ vs $CO_2$：

$\dfrac{r_{N_2}}{r_{CO_2}} = \sqrt{\dfrac{44}{28}} = \sqrt{\dfrac{11}{7}} \approx 1.25$

∴ $r_{N_2} : r_{CO_2} = \sqrt{11} : \sqrt{7}$

例題 2 逸散時間計算

在同溫同壓下，$H_2$ 擴散通過一小孔需要 $t_1 = 10$ 分鐘。同條件下，某未知氣體 X 需要 $t_2 = 40$ 分鐘才能通過同一小孔。試求氣體 X 的分子量。

解題思路：

逸散時間的格銳目定律為：$\dfrac{t_1}{t_2} = \sqrt{\dfrac{M_1}{M_2}}$

解答與解析：

已知：$M_{H_2} = 2$，$t_{H_2} = 10$ min，$t_X = 40$ min

代入公式：

$\dfrac{t_{H_2}}{t_X} = \sqrt{\dfrac{M_{H_2}}{M_X}}$

$\dfrac{10}{40} = \sqrt{\dfrac{2}{M_X}}$

$\dfrac{1}{4} = \sqrt{\dfrac{2}{M_X}}$

$\dfrac{1}{16} = \dfrac{2}{M_X}$

$\therefore M_X = 32$

∴ 氣體 X 的分子量為 32，可能是 $O_2$（$M=32$）。

例題 3 選擇題 — 逸散速率應用

在同溫同壓下，以下各種說法何者正確？

  • (A) 分子量越大，逸散速率越快
  • (B) 相同溫度下，所有氣體分子的平均速率相同
  • (C) $H_2$ 與 $O_2$ 的逸散速率比為 $4:1$
  • (D) 提高溫度，氣體分子速率分布曲線向左移並變窄
  • (E) 在同溫下，分子量大的氣體平均動能也較大
解答與解析：

正確答案：(C)

(A) 錯誤：分子量越大，逸散速率越慢（$r \propto 1/\sqrt{M}$）。

(B) 錯誤：相同溫度下，分子量不同，平均速率也不同（$v_{rms} \propto 1/\sqrt{M}$）。

(C) 正確：$\dfrac{r_{H_2}}{r_{O_2}} = \sqrt{\dfrac{32}{2}} = 4$。

(D) 錯誤：提高溫度，曲線向右移並變寬。

(E) 錯誤：在同溫下，所有氣體平均動能相等，均為 $\dfrac{3}{2}kT$。

例題 4 擴散距離比較

在同溫同壓下，將 $NH_3$（$M=17$）與 $HCl$（$M=36.5$）分別由一根密閉長管兩端同時通入，兩種氣體相遇反應生成白色固體 $NH_4Cl$（氯化銨）。若管長為 $L$ 公尺，試求白色固體出現的位置。

💡 提示：兩氣體逸散距離之比等於速率之比。

解答與解析：

設 $NH_3$ 行進距離為 $d_{NH_3}$，$HCl$ 行進距離為 $d_{HCl}$：

$d_{NH_3} + d_{HCl} = L$

由格銳目定律：

$\dfrac{d_{NH_3}}{d_{HCl}} = \dfrac{r_{NH_3}}{r_{HCl}} = \sqrt{\dfrac{M_{HCl}}{M_{NH_3}}} = \sqrt{\dfrac{36.5}{17}}$

$\approx \sqrt{2.147} \approx 1.465$

設 $d_{HCl} = x$，則 $d_{NH_3} = 1.465x$：

$1.465x + x = L \implies x = \dfrac{L}{2.465}$

$\therefore$ 白色固體出現在距 $HCl$ 端約 $\dfrac{L}{2.465} \approx 0.406L$ 處

或距 $NH_3$ 端約 $0.594L$ 處（更靠近 $HCl$ 端）。

例題 5 速率比較與溫度

同種氣體 $N_2$（$M=28$）：

(1) 在 $27°C$ 時的均方根速率為 $v_1$，在 $327°C$ 時的均方根速率為 $v_2$，試求 $v_1 : v_2$。

(2) 在 $27°C$ 時，$N_2$ 與 $O_2$（$M=32$）的均方根速率比為何？

解答與解析：

(1) 同種氣體，溫度改變：

$v_{rms} = \sqrt{\dfrac{3RT}{M}}$，分子量相同時 $v \propto \sqrt{T}$

$T_1 = 27 + 273 = 300\text{ K}$，$T_2 = 327 + 273 = 600\text{ K}$

$\dfrac{v_1}{v_2} = \sqrt{\dfrac{T_1}{T_2}} = \sqrt{\dfrac{300}{600}} = \sqrt{\dfrac{1}{2}} = \dfrac{1}{\sqrt{2}}$

$\therefore v_1 : v_2 = 1 : \sqrt{2}$


(2) 同溫，不同分子量：

$\dfrac{v_{N_2}}{v_{O_2}} = \sqrt{\dfrac{M_{O_2}}{M_{N_2}}} = \sqrt{\dfrac{32}{28}} = \sqrt{\dfrac{8}{7}}$

$\therefore v_{N_2} : v_{O_2} = \sqrt{8} : \sqrt{7} = 2\sqrt{2} : \sqrt{7}$
