一、波以耳定律 (Boyle's Law) 的核心內涵與 J 型管實驗 等溫等量先決條件 · 反比常數乘積 · J 型管等壓面分析
觀念 01 定律陳述與先決條件

1662 年英國科學家波以耳 (Robert Boyle) 發表：在絕對溫度固定 ($T$ 為定值) 且氣體莫耳數固定 ($n$ 為定值) 之密閉條件下，定量氣體呈現體積 ($V$) 與其所受壓力 ($P$) 成反比。

乘積守恆： $$P \times V = k \quad (\text{常數，} k = nRT)$$
前後狀態轉移： $$P_1 V_1 = P_2 V_2$$
圖 2-4 波以耳 J 型玻璃管實驗原型與水銀等壓面分析
波以耳經典驗證：當水銀高出 $76\,\mathrm{cm}$ ($P=2\,\mathrm{atm}$) 時，閉口端氣體體積縮小為初長的一半！
J 型管水銀面狀態 等壓面力學平衡方程式 閉口端封閉氣體壓力 ($P_{\text{gas}}$)
(1) 兩管水銀面等高 $P_{\text{gas}} = P_0$（左右液柱無落差） $P_{\text{gas}} = P_0$（剛好等於外界大氣壓力）
(2) 開口端高於閉口端 $h\,\text{cm}$ $P_{\text{gas}} = P_0 + P_{\text{Hg}}$（開口水銀向下施壓） $P_{\text{gas}} = P_0 + h\,\mathrm{(cmHg)}$
(3) 開口端低於閉口端 $h\,\text{cm}$ $P_{\text{gas}} + P_{\text{Hg}} = P_0$（閉口端水銀向下壓） $P_{\text{gas}} = P_0 - h\,\mathrm{(cmHg)}$
觀念檢核 波以耳定律核心條件與 J 型管自我評量
基礎觀念精熟

(2) 定量氣體在等溫下，壓力由 $1.5\,\mathrm{atm}$ 提升至 $6.0\,\mathrm{atm}$，則體積變為原來的幾倍？
(3) 外壓為 $76\,\mathrm{cmHg}$，J 型管開口端液面高於閉口端 $24\,\mathrm{cm}$，管內氣體實際承受氣壓為若干 $\mathrm{cmHg}$？

觀念 03 氣體壓力的微觀物理機制：碰撞衝量與頻率

巨觀測得之壓力 $P$，本質上為億萬微觀粒子高速撞擊器壁施加於單位面積之平均衝量 (正向力)： $$P = \frac{F}{A} \propto \left( \frac{\text{分子數 } N}{\text{容器體積 } V} \right) \times (\text{分子碰撞頻率 } f) \times (\text{平均動量變化 } \Delta p)$$

圖 2-6 微觀動力論：等溫活塞壓縮之分子數密度與碰撞頻率加倍機制
體積縮減為 $1/4$ $\implies$ 分子數密度 $4\times$、撞壁頻率 $4\times$ $\implies$ 壓力增為 $4\times$（$0.80\,\mathrm{atm}$）
