🔬 碰撞頻率與壓力的物理起源

1. 氣體壓力的微觀本質

宏觀測得的壓力 $P$，來自數以億萬計氣體分子持續撞擊容器壁面施加於單位面積上的平均衝量：

$$P = \frac{F}{A} \propto \left( \frac{\text{分子數 } n}{\text{體積 } V} \right) \times (\text{碰撞頻率 } f) \times (\text{動量變化 } \Delta p)$$

2. 分子碰撞頻率方程式

分子碰撞器壁的頻率 $f$ 與數密度 $(n/V)$ 及根均方速率 $v_{\text{rms}} \propto \sqrt{T/M}$ 成正比：

$$f \propto \frac{n}{V} \sqrt{\frac{T}{M}} \quad \xrightarrow{\text{定溫 } T \text{ 定量 } n} \quad f \propto \frac{1}{V}$$

💡 定溫條件下，分子平均速率固定，碰撞頻率純粹與容積大小成反比。

3. 體積減半時的微觀連鎖推導

  • 空間縮小：體積 $V \to \frac{1}{2}$ 倍 $\implies$ 分子空間密度 $\left(\frac{n}{V}\right)$ 增為 $2$ 倍。
  • 行程減半：分子往返兩壁行程減半 $\implies$ 撞擊器壁頻率 $f$ 增為 $2$ 倍。
  • 衝量加倍：單位面積每秒承受之總衝力增為 2 倍 $\implies$ 壓力 $P$ 變為 $2$ 倍！
