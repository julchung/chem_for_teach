範例 3：氣體反應與分壓平衡

範例 3

碳與氧燃燒平衡

聯立方程題

在 $\text{O}_2$ 與 $\text{N}_2$ 莫耳比為 $1:4$ 的混合氣體中加入碳粉，加熱使其完全反應產生 $\text{CO}$ 及 $\text{CO}_2$。反應後的混合氣體於 同溫同體積 時壓力增加 $10\%$。若 $\text{O}_2$ 完全耗盡，則反應後氣體中分壓比 $\mathbf{P_{CO} : P_{CO_2}}$ 為何？

  • (A) $1 : 2$
  • (B) $2 : 1$
  • (C) $1 : 1$
  • (D) $3 : 2$
詳細解析

正解：(B) 2 : 1

1. 假設初莫耳數：
設初狀態有 $\text{O}_2 = 1\text{ mol}$，$\text{N}_2 = 4\text{ mol}$。
初總莫耳數 $n_1 = 1 + 4 = \mathbf{5\text{ mol}}$。
2. 求末狀態氣體總莫耳數：
同溫同容下，$P \propto n$，總壓增加 $10\%$：
$$n_2 = 5 \times (1 + 0.10) = \mathbf{5.5\text{ mol}}$$ 由於 $\text{N}_2$ 莫耳數仍為 $4\text{ mol}$，故生成的氣體 $(\text{CO} + \text{CO}_2)$ 總莫耳數為：
$$n_{\text{CO}} + n_{\text{CO}_2} = 5.5 - 4 = \mathbf{1.5\text{ mol}}$$
3. 聯立氧原子守恆：
設生成 $\text{CO} = a\text{ mol}$，$\text{CO}_2 = b\text{ mol}$：
① 總分子數：$a + b = 1.5$
② 氧原子守恆：$a(1) + b(2) = 1 \text{ mol } \text{O}_2 \times 2 = 2\text{ mol O}$
由 ② - ① 得：$b = 0.5\text{ mol } (\text{CO}_2)$
代入 ① 得：$a = 1.0\text{ mol } (\text{CO})$
4. 分壓比計算：
在同容器中，分壓比等於莫耳數比：
$$P_{\text{CO}} : P_{\text{CO}_2} = a : b = 1.0 : 0.5 = \mathbf{2 : 1}$$ 故正確答案選 (B)。
