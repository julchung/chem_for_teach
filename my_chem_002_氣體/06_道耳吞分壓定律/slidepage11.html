範例 5：排水集氣法綜合計算

範例 5

排水集氣與狀態方程式換算

水面差校正題

$27^\circ\text{C}$ 時以排水集氣法收集氧氣一瓶 $600\text{ mL}$，瓶口在水面下 $5.44\text{ cm}$。若瓶外大氣壓力為 $752.5\text{ mmHg}$，已知 $27^\circ\text{C}$ 時水的飽和蒸氣壓為 $26.5\text{ mmHg}$，求：
(a) 瓶內乾燥氧氣的分壓為多少 mmHg？
(b) 此乾燥氧氣在 $127^\circ\text{C}$、$365\text{ mmHg}$ 時，體積為多少 mL？

詳細解析

正解：(a) 730 mmHg；(b) 1600 mL

📌 (a) 計算乾燥氧氣的分壓：
1. 水柱高度換算水銀柱高：瓶口在水面下 $5.44\text{ cm } \text{H}_2\text{O}$，水柱加壓：
$$\Delta P = \frac{5.44\text{ cm } \text{H}_2\text{O}}{1.36} = \mathbf{4\text{ mmHg}}$$ 2. 瓶內總壓：$P_{total} = P_{atm} + \Delta P = 752.5 + 4 = \mathbf{756.5\text{ mmHg}}$
3. 扣除飽和水蒸氣壓：
$$\mathbf{P_{O_2}} = P_{total} - P_{H_2O} = 756.5 - 26.5 = \mathbf{730\text{ mmHg}}$$
⚡ (b) 組合氣體定律換算體積：
此純乾燥氧氣在兩狀態間定量轉移，套用 $\dfrac{P_1 V_1}{T_1} = \dfrac{P_2 V_2}{T_2}$：
• 初狀態：$P_1 = 730\text{ mmHg}$，$V_1 = 600\text{ mL}$，$T_1 = 27 + 273 = 300\text{ K}$
• 末狀態：$P_2 = 365\text{ mmHg}$，$V_2 = ?$，$T_2 = 127 + 273 = 400\text{ K}$
$$\frac{730 \times 600}{300} = \frac{365 \times V_2}{400}$$ $$1460 = \frac{365 \times V_2}{400} \implies V_2 = \frac{1460 \times 400}{365} = 4 \times 400 = \mathbf{1600\text{ mL}}$$
💡 概念核心：
換算乾燥氣體體積時，絕不可用濕氣體總壓（756.5 mmHg）代入，必須先精確扣除水蒸氣壓取得純氧分壓（730 mmHg）！
