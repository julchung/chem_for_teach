一、氣體的四大巨觀通性與分子動力論微觀本質 巨觀現象 · 微觀假說 · 動能溫度正比
觀念 01 氣態物質的四大巨觀通性
🗜️ 易壓縮性 (Compressibility)

氣體分子間距離極大（容器絕大部分空間為真空）。受外壓增加時分子間隙急劇縮小，體積顯著縮減。

🎈 易膨脹性 (Expansibility)

無固定形狀與固定體積。氣體分子高速無規則熱運動，永遠自發均勻充滿密閉容器之所有空間。

🌊 快速擴散性 (Diffusion)

不同氣體相遇時能自發穿透互相均勻混合，形成均勻之氣態溶液（氣體混合物恆為真溶液）。

⚖️ 極低密度性 (Low Density)

同物質氣態密度約為液態或固態之 $1/1000$（常溫常壓下常用 $\mathrm{g/L}$ 表示）。

觀念 02 氣體分子動力論 (Kinetic Molecular Theory) 微觀假說
  1. 質點模型：氣體由質量極小之分子組成，分子自身體積相較於氣體總體積微小可忽略。
  2. 完全彈性碰撞：分子持續高速直線熱運動，撞擊器壁與分子互撞皆為完全彈性碰撞（無總動能損耗）。
  3. 無作用力假說：分子間無任何引力或斥力（理想氣體無分子位能，內能全部為動能）。
💡 平均動能與絕對溫度正比公理： $$\bar{E}_k = \frac{1}{2}m\bar{v}^2 = \frac{3}{2}kT \propto T \quad (\text{絕對溫度 } T \text{ 單位為 } \mathrm{K})$$ 在同溫下，任何氣體（如 $\mathrm{H_2, He, O_2, CO_2}$）分子之「平均動能必相等」！分子量 $M$ 愈小者，平均速率 $\bar{v}$ 愈快。

二、氣體壓力的物理定義與托里切利氣壓計 流體靜壓力 · 托里切利真空 · 傾斜變因分析
觀念 03 壓力的物理定義與液柱靜壓力公式

壓力 (Pressure, $P$)：受力表面上單位面積所承受之垂直正向力。SI 制標準單位為帕斯卡 ($\mathrm{Pa = N/m^2}$)。

正向力定義： $$P = \frac{F}{A} = \frac{\text{垂直正向力 } (\mathrm{N})}{\text{受力表面積 } (\mathrm{m^2})}$$
靜止液柱壓強： $$P = h \times d \quad (\text{垂直高度 } h \times \text{液體密度 } d)$$
圖 2-1 托里切利水銀氣壓計原理（直立管 vs 傾斜管垂直高度對照）
管子傾斜時管內水銀柱長度 $L$ 伸長，但垂直高度差 $h$ 恆保持 $76\,\mathrm{cm}$ 不變
實驗變因操作 水銀柱垂直高度差 $h$ 物理原理與力學解析
玻璃管傾斜（管口未出液面） 恆不變（仍為 $76\,\mathrm{cm}$） 管內水銀長度 $L = 76/\cos\theta$ 增長，但垂直高度受大氣壓決定。
換粗管或細管 恆不變（仍為 $76\,\mathrm{cm}$） 液柱總重量與截面積等比例增減，單位面積受壓 $P=F/A$ 完全相同。
將管往上提（管口未離液面） 恆不變（真空部分拉長） 大氣壓力所能支撐的水銀柱極限垂直高度未改變。
頂端漏入微量空氣 ⚠️ 下降（小於 $76\,\mathrm{cm}$） 頂端不再為真空，管內氣體產生向下壓力推擠水銀柱 ($P_{\text{atm}} = P_{\text{air}} + h$)。

三、壓力單位多重換算與不同液體高度折算 標準大氣壓基準 · 液體密度反比折算 · 深度計算
觀念 04 標準大氣壓 ($1\,\mathrm{atm}$) 之多重單位換算公理
$$1\,\mathrm{atm} = 76\,\mathrm{cmHg} = 760\,\mathrm{mmHg} = 760\,\mathrm{torr} = 1033.6\,\mathrm{gw/cm^2} = 1.013 \times 10^5\,\mathrm{Pa} = 1013.25\,\mathrm{hPa}$$
壓力單位名稱 $1\,\mathrm{atm}$ 對應數值 物理意義與應用情境
$\mathrm{cmHg / mmHg}$ $76 / 760$ 以水銀柱垂直高度表示之壓力（$1\,\mathrm{mmHg} = 1\,\mathrm{torr}$，托耳）。
$\mathrm{gw/cm^2}$ $1033.6$ $P = h \times d = 76\,\mathrm{cm} \times 13.6\,\mathrm{g/cm^3} = 1033.6\,\mathrm{gw/cm^2}$。
$\mathrm{Pa / hPa}$ (百帕) $1.013 \times 10^5 / 1013$ SI 制公制標準（$1\,\mathrm{Pa} = 1\,\mathrm{N/m^2}$）；氣象學廣泛採用百帕。
水柱高 ($\mathrm{mH_2O}$) 約 $10.336\,\mathrm{m}$ 以純水取代水銀時之高度，約等於十公尺深（約 3 層樓）之水壓。
觀念 05 不同液體柱高度之等效折算定律：$h_1 d_1 = h_2 d_2$

若採用其他液體（如水、油、酒精）量測壓力，由於同一壓力下液壓相等，液柱高度與液體密度成反比：

$$P = h_1 \times d_1 = h_2 \times d_2 \implies h_1 = h_2 \times \frac{d_2}{d_1}$$

四、開口式水銀壓力計的量測原理與等壓面法 等壓面基準 · 開口端大氣壓修正 · 三大平衡狀態
觀念 06 等壓面法 (Equipressure Level) 找平衡之黃金法則

在連通管中，「同一種靜止連通之液體，在同一水平高度面上，其承受之靜壓力必嚴格相等」！在 U 形管壓力計中，取兩管中較低的水銀液面作為等壓基準面，兩端向下壓強必定相等。

圖 2-2(A) 開口計：右高左低 ($P_{\text{gas}} > P_{\text{atm}}$)
平衡公式：$P_{\text{gas}} = P_{\text{atm}} + h$
圖 2-2(B) 開口計：左高右低 ($P_{\text{gas}} < P_{\text{atm}}$)
平衡公式：$P_{\text{gas}} = P_{\text{atm}} - h$
狀態分類 兩管水銀面特徵 氣室氣壓 $P_{\text{gas}}$ 公式 物理力學圖解分析
(A) $P_{\text{gas}} > P_{\text{atm}}$ 右管高、左管低（右高左低） $$P_{\text{gas}} = P_{\text{atm}} + h$$ 氣體推力勝過大氣壓，將水銀推向開口端。
(B) $P_{\text{gas}} = P_{\text{atm}}$ 兩管水銀面完全等高 ($h=0$) $$P_{\text{gas}} = P_{\text{atm}}$$ 氣室氣體壓力與外界大氣壓力大小完全相同。
(C) $P_{\text{gas}} < P_{\text{atm}}$ 左管高、右管低（左高右低） $$P_{\text{gas}} = P_{\text{atm}} - h$$ 外界大氣壓強於氣室，大氣將水銀推向氣室端。

觀念 07 閉口式水銀壓力計構造與絕對壓力判定

閉口式壓力計外端封閉且抽成真空 ($P \approx 0$)。連接氣室時，兩管垂直高度差 $h$ 直接代表氣體的絕對壓力 (Absolute Pressure)，完全不受外界大氣壓力波動影響：

$$P_{\text{gas}} = h \quad (\text{單位為 } \mathrm{cmHg} \text{ 或 } \mathrm{mmHg})$$
圖 2-3(A) 閉口式壓力計原理（頂端真空）
高度差即絕對氣壓：$P_{\text{gas}} = h$
圖 2-3(B) 水銀總量守恆推導模型（充入 A 氣體 vs 換充 B 氣體）
守恆關係：總水銀 $4h = 5h' \implies h' = 0.8h$
比較項目 開口式水銀壓力計 閉口式水銀壓力計
外端狀態 連通外界大氣（承受 $P_{\text{atm}}$） 封閉且高度真空（壓力為 $0$）
量測所得數值 相對差值（待測壓與大氣壓之差 $P_{\text{gas}} - P_{\text{atm}}$） 絕對壓力（直接等於液面高度差 $h$）
適用範圍 待測氣壓與外界大氣壓相近之場合 低壓氣體或需精準量測絕對值場合
