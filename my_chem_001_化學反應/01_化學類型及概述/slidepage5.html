範例 2

銅與稀硝酸反應之代數法聯立求解

一題一頁 · 代數法演練

題目說明：
銅金屬溶於稀硝酸中，生成硝酸銅藍色溶液、無色一氧化氮氣體與水： $$a\,\mathrm{Cu} + b\,\mathrm{HNO_3} \longrightarrow c\,\mathrm{Cu(NO_3)_2} + d\,\mathrm{NO} + e\,\mathrm{H_2O}$$ 試利用「代數法」求解最簡整數係數比 $(a, b, c, d, e)$，並求出反應物之係數比值 $\dfrac{b}{a}$ 為何？

💡 為何此題適合使用代數法？

反應物中只有一種含氮物質 ($\mathrm{HNO_3}$)，但生成物中氮元素分散於 $\mathrm{Cu(NO_3)_2}$ 與 $\mathrm{NO}$ 兩處，且氧元素分散於三種生成物中！
此類化學式若以觀察法易陷入反覆試誤，列出元素原子守恆聯立方程組，能確保精準無誤定解。

✓ 完整代數法聯立求解步驟

$b/a = 8/3$
Step 1：依四大元素原子守恆列聯立方程式
反應式：$a\,\mathrm{Cu} + b\,\mathrm{HNO_3} \rightarrow c\,\mathrm{Cu(NO_3)_2} + d\,\mathrm{NO} + e\,\mathrm{H_2O}$
  • (1) $\mathrm{Cu}$ 守恆：$a = c$
  • (2) $\mathrm{H}$ 守恆：$b = 2e$
  • (3) $\mathrm{N}$ 守恆：$b = 2c + d$
  • (4) $\mathrm{O}$ 守恆：$3b = 6c + d + e$
Step 2：令基準變數 $a = 1$
由 (1) 式可得：$c = a = \mathbf{1}$。
Step 3：代入求解其餘未知數
將 $b = 2e$ 與 $c = 1$ 代入 (3) 式： $$2e = 2(1) + d \implies d = 2e - 2$$ 將 $b = 2e, c = 1, d = 2e - 2$ 一併代入 (4) 式： $$3(2e) = 6(1) + (2e - 2) + e$$ $$6e = 4 + 3e \implies 3e = 4 \implies \mathbf{e = \frac{4}{3}}$$ 代回求出 $b$ 與 $d$： $$b = 2e = 2 \times \frac{4}{3} = \mathbf{\frac{8}{3}}$$ $$d = 2\left(\frac{4}{3}\right) - 2 = \mathbf{\frac{2}{3}}$$
Step 4：通分消去分母化簡
各係數比為： $$(a, b, c, d, e) = \left(1, \frac{8}{3}, 1, \frac{2}{3}, \frac{4}{3}\right)$$ 同乘分母 3 得最簡整數比： $$\mathbf{(a, b, c, d, e) = (3, 8, 3, 2, 4)}$$ 平衡後之完整方程式為： $$\mathbf{3\,Cu + 8\,HNO_3 \longrightarrow 3\,Cu(NO_3)_2 + 2\,NO + 4\,H_2O}$$ 所求比值： $\dfrac{b}{a} = \dfrac{8}{3}$。
